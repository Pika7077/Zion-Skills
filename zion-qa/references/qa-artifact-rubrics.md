# 分类型验收矩阵

四种 QA 模式决定“怎样检查”，本档按交付物决定“检查什么”。只选择当前材料和用户目标相关的栏，不把完整矩阵套给单个文件。项目规格优先；没有来源的阈值、禁令和风格偏好不补入。

## 一、剧本

### 场次与因果

- 每场能否说明进入与退出之间的信息、关系、处境、物理状态或观众预期差值。
- 当场目标是否可验证，策略是否为可见行动，阻力是否真正作用于策略。
- 升级、转向和结果是否被混写；转向是否有可见或可听证据。
- 相邻场次能否用因果、未决问题或明确的信息关系连接；换序是否会改变理解。
- 氛围、等待或观察场即使没有冲突，是否仍改变体验或后续状态。

### 类型承诺

只在项目类型明确时检查：

- 悬疑/推理：答案能否回指已给事实；误导是否真实但不完整；红鲱鱼是否仍有叙事价值。
- 喜剧：笑点是否有可读前提、具体偏差、反应和升级，而非可互换金句。
- 恐怖/惊悚：威胁规则是否可追踪；惊吓是否留下处境、关系或物理余波。
- 爱情/关系：推进是否有行动证据；长期误会是否有不问、不说或不信的理由。
- 动作/冒险：胜负条件是否清楚；阶段是否改变空间、资源、伤情、信息或策略。
- 群像：主要人物是否都对共同事件造成不可替代的影响，不按戏份均分判断。

开放结尾、非类型作品或实验结构不因缺少上述类型机制失败；按其明确表达目标检查。

## 二、资产

### 共同项

- 身份锚点、可变状态、版本、真实文件和目标入口引用是否分开且可追溯。
- 所需角度、尺度、结构或声音覆盖实际镜头用途；缺口是否明确。
- 原文事实、推断、设计补全与未知是否分层。
- 制作状态与权利状态是否分开；外部素材来源、允许用途与待确认项是否有证据。

### 分类项

| 类别 | 重点验收 |
|---|---|
| 人物 | 跨角度身份、体态与服装状态；相似角色是否符合原作且在镜头中可辨 |
| 场景 | 拓扑、出入口、受保护锚点、观察方向、主光来源、状态痕迹与可通行性 |
| 道具/服装 | 尺寸、结构、材质、归属、使用/损坏/换装阶段及跨镜继承 |
| 生物 | 肢体与关节、支撑点、尺度、动作能力和变形时的不变量 |
| 载具/机械 | 前后识别、出入口、可动结构、人物尺度、活动范围与损坏状态 |
| 图形文字 | 视觉身份与准确内容分离；可编辑路径、语言变体和载体透视 |
| 特效 | 发生源、发展、交互、遮挡、交互光、结束与残留，及所需合成层 |
| 声音身份 | 跨台词稳定的音域、质感、语速和重音；真实文件与用途映射 |

## 三、导演分镜

- 剧本事实、揭示顺序与补充权限没有被镜头选择改写。
- 空间、轴线、视线、动作阶段、持物、伤情、光源和声音连续。
- 时长容纳实际对白、动作、反应和视觉读取；能并行的内容没有机械累加。
- 切镜、运动、灯光、色彩、声音与调度服务当前叙事任务，不以技术词数量代替质量。
- 高风险关键镜头是否有与风险对应的覆盖、余量、分层素材、可替换区域或降级路径；不要求每镜都有备用。
- 有字幕、本地化、无声观看、色觉可读、闪烁风险或多平台要求时，设计是否预留可执行路径。

## 四、生成提示词

除 [投喂前检查](qa-feedability.md) 外，再核对：

- 导演分析、工作流备注和模型执行指令是否分开。
- 精确文字、合成层、本地化版本和后期动作是否被错误塞进模型正文。
- 多版本共用部分与变量部分是否可追踪，差异不会静默覆盖主版本。
- 目标入口不支持所需参考、遮罩、透明层或局部编辑时，是否给出可实际执行的替代路径。

## 五、图片与视频结果

### 图片

- 在最终用途尺寸检查身份、结构、手部/接触、文字、材质、构图、边缘与遮挡。
- 设定图检查身份信息是否可读；动作海报按动作瞬间与用途判断，不套静态身份板标准。
- 需要合成时检查边缘、透明区域、阴影、反射、交互光与背景匹配。

### 视频时间域

- 正常播放判断整体可用性，疑点处再逐帧；记录发生区间，不用单帧代表整段。
- 检查身份、服装、道具、背景和光色是否随时间漂移；运动速度、方向和动作阶段是否突变。
- 记录无叙事动机的闪烁、纹理沸腾、边缘抖动、画面撕裂或镜头交界跳变。
- 接触、遮挡、反射、文字和复杂动作在风险区间加密检查。

### 声音与音画

- 说话者、画内/画外归属和口型依赖是否正确；不同步定位到时间段。
- 对白是否可懂，是否被音乐、音效、削波、突变或重复遮蔽。
- 声源方向、距离变化、环境底噪和跨剪辑连续性是否与画面匹配。
- 响度、峰值、声道和编码只有在目标交付规范与真实文件可用时才能判通过。

## 六、技术交付与版本

- 分辨率、画幅、帧率、编码、码率、封装、色彩空间、音频、文件命名和时长按实际交付规范检查。
- 字幕安全区、样式、语言、时间轴和画内准确文字按最终播放条件检查。
- 颜色承担状态或操作信息时，是否另有形状、位置、文字、纹理或动作通道。
- 高对比闪烁、快速图案或强震动先定位风险；是否合规必须使用目标规范和真实成片检测。
- 缺少文件、元数据、平台模板或规范时标为未验证，不用导演稿声明替代成片检测。

## 七、来源与权利证据

本项只检查登记完整性，不作法律判断：

- 外部图片、字体、音乐、声音、人物形象、品牌或作品片段是否能追溯来源。
- `confirmed`、`user-asserted`、`pending`、`restricted`、`unknown` 是否与现有证据一致。
- 参考、编辑、生成、发布、商业使用及第三方转交是否被错误合并成一个“可用”。
- 派生文件是否保留父来源；替换来源后，下游引用是否同步复核。

制作状态 `approved/uploaded` 不证明权利已确认。缺少证据时报告待确认对象和所需材料，不给出法律结论。

## 八、选择与交付

先报告阻断当前用途的问题，再报告明显损害质量的问题，最后给可选优化。每条包含材料类型、模式、位置、证据、影响、最小建议和未验证范围；没有问题的类别不为凑矩阵重复输出。
