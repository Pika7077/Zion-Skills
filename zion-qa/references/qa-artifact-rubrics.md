# 分类型验收矩阵

四种 QA 模式决定“怎样检查”，本档按交付物决定“检查什么”。只选择当前材料和用户目标相关的栏，不把完整矩阵套给单个文件。项目规格优先；没有来源的阈值、禁令和风格偏好不补入。

## 一、剧本

### 场次与因果

- 每场能否说明进入与退出之间的信息、关系、处境、物理状态或观众预期差值。
- 当场目标是否可验证，策略是否为可见行动，阻力是否真正作用于策略。
- 升级、转向和结果是否被混写；转向是否有可见或可听证据。
- 相邻场次能否用因果、未决问题或明确的信息关系连接；换序是否会改变理解。
- 氛围、等待或观察场即使没有冲突，是否仍改变体验或后续状态。

### 类型承诺

只在项目类型明确时检查：

- 悬疑/推理：答案能否回指已给事实；误导是否真实但不完整；红鲱鱼是否仍有叙事价值。
- 喜剧：笑点是否有可读前提、具体偏差、反应和升级，而非可互换金句。
- 恐怖/惊悚：威胁规则是否可追踪；惊吓是否留下处境、关系或物理余波。
- 爱情/关系：推进是否有行动证据；长期误会是否有不问、不说或不信的理由。
- 动作/冒险：胜负条件是否清楚；阶段是否改变空间、资源、伤情、信息或策略。
- 群像：主要人物是否都对共同事件造成不可替代的影响，不按戏份均分判断。

开放结尾、非类型作品或实验结构不因缺少上述类型机制失败；按其明确表达目标检查。

### 开场与连载

多集项目或需要留下观众的作品检查；单集独立作品按 `zion-script` 的「故事设计与输出范围」档的结局与时长判断。

- 开场是否给出明确的**观看理由**——具体对立或具体未知，观众能说出"接下来要看的是什么"；只交代环境、状态或情绪而没有可指向的问题，不算完成。按功能判断，不按秒数刻度判断。
- 每集结尾的切口是否**被下一集接着**，并交代接上的方式；切口类型是否在使用中轮换，而非每集同一手法。
- 集与集之间的人物状态、信息掌握与关系状态**三张表是否对得上**：上一集的结果在下一集有可见延续，没有静默恢复。
- 单集内部是否做完该集的事（进入、推进、切口），而非把一集拆成两半各自不完整。

判据来源为 `zion-script` 的「受众期待与情绪回报」与「连载结构：集与集之间」两档；本档只列验收问法，不重述创作规则。

## 二、资产

### 共同项

- 身份锚点、可变状态、版本、真实文件和目标入口引用是否分开且可追溯。
- 所需角度、尺度、结构或声音覆盖实际镜头用途；缺口是否明确。
- 原文事实、推断、设计补全与未知是否分层。
- 制作状态与权利状态是否分开；外部素材来源、允许用途与待确认项是否有证据。

### 分类项

| 类别 | 重点验收 |
|---|---|
| 人物 | 跨角度身份、体态与服装状态；相似角色是否符合原作且在镜头中可辨 |
| 场景 | 拓扑、出入口、受保护锚点、观察方向、主光来源、状态痕迹与可通行性 |
| 道具/服装 | 尺寸、结构、材质、归属、使用/损坏/换装阶段及跨镜继承 |
| 生物 | 肢体与关节、支撑点、尺度、动作能力和变形时的不变量 |
| 载具/机械 | 前后识别、出入口、可动结构、人物尺度、活动范围与损坏状态 |
| 图形文字 | 视觉身份与准确内容分离；可编辑路径、语言变体和载体透视 |
| 特效 | 发生源、发展、交互、遮挡、交互光、结束与残留，及所需合成层 |
| 声音身份 | 跨台词稳定的音域、质感、语速和重音；真实文件与用途映射 |

## 三、导演分镜

先查保真与连续，再查表达是否成立。分组与制作侧交付前检查（`zion-storyboard` 的交付前检查档）对应，按当前材料选用，不要求逐条填满。

**保真与连续**

- 剧本事实、揭示顺序与补充权限没有被镜头选择改写。
- 空间、轴线、视线、动作阶段、持物、伤情、光源和声音连续。
- 时长容纳实际对白、动作、反应和视觉读取；能并行的内容没有机械累加。

**标尺与重点**

- 这组镜头除"发生什么"外是否完成"感受到什么"；把顺序换一遍，意思是否会变。
- 本场是否存在观众能说出的**有意义变化**（信息、关系、处境、态度或力量对比至少一项），且能指出它由哪个可见动作带来。
- 是否整场只有保底手段（全景交代＋正反打）——用替换性检验：换成任意两人在任意房间做同样的事是否照样成立。
- 记忆锚是否唯一、时长是否显著长于铺垫；铺垫是否已合并或省略，没有镜头平均分配。

**节奏与预期**

- 等待属于"不知会不会发生"还是"知道一定会发生"；后者的每个延长细节是否新增了"它更近了"，画面是否只给这一件事。
- 延迟期间是否另有新悬念；插入项是否在本场或下集得到回应。
- 用环境预示时"铺预期→揭示→释放"是否齐全；把人物动作换成同类动作后预示是否仍成立。

**关系、视角与空间**

- 空间关系与人物关系是否在事件之前可见；危险暗示的载体是否在后续兑现（只暗示不兑现＝欺骗观众）。
- 每处客观↔主观的切换能否说出观众获得了什么；是否出现与内容无关的机械交替。
- 空间是否在承担情绪：能否指出哪条物理事实（净空与体量／密度与朝向／遮挡与开口）在施压或掩护；换到中性空间后情绪是否仍成立。

**手法与主题**

- 用替代画面处理不宜直拍内容时，意象是否同时通过与人物处境的**关联性**和观众的**可读性**；替代是否吃掉了必要信息。
- 重复是否有情绪任务、落点是否为同一任务、是否超过"观众能预判下一轮"的上限。
- 隐喻是否避开通用符号且已写成镜头语言；配色情绪是否由面积主次、明暗深浅或光源来源中**明确的一个变量**承担。
- 母题表登记项是否真的出现：建立点、复现点、回收点可查，载体为已登记的 `asset_id`，每次复现带来新信息；只出现一次的意象不按母题验收。

**技术与交付**

- 切镜、运动、灯光、色彩、声音与调度服务当前叙事任务，不以技术词数量代替质量。
- 高风险关键镜头是否有与风险对应的覆盖、头尾余量、分层素材、可替换区域或降级路径（有效覆盖＝提供不同的剪辑出口，不是多生成一次）；不要求每镜都有备用。
- 有字幕、本地化、无声观看、色觉可读、闪烁风险或多平台要求时，设计是否预留可执行路径，且未把导演稿声明当成片检测。

## 四、生成提示词

除 [投喂前检查](qa-feedability.md) 外，再核对：

- 导演分析、工作流备注和模型执行指令是否分开。
- 精确文字、合成层、本地化版本和后期动作是否被错误塞进模型正文。
- 多版本共用部分与变量部分是否可追踪，差异不会静默覆盖主版本。
- 目标入口不支持所需参考、遮罩、透明层或局部编辑时，是否给出可实际执行的替代路径。
- 被排除的概念是否已改写为正向描述，而不是在主指令里堆否定式；否定式只允许出现在有来源的负面段或规范明确要求处。
- 生成粒度是否与内容跨度匹配：跨越时间／空间／概念的部分是否已分开生成；一段多镜只用于同一连续世界内的切换，且组内写清了切点。

## 五、图片与视频结果

### 图片

- 在最终用途尺寸检查身份、结构、手部/接触、文字、材质、构图、边缘与遮挡。
- 设定图检查身份信息是否可读；动作海报按动作瞬间与用途判断，不套静态身份板标准。
- 需要合成时检查边缘、透明区域、阴影、反射、交互光与背景匹配。

### 视频时间域

- 正常播放判断整体可用性，疑点处再逐帧；记录发生区间，不用单帧代表整段。
- 检查身份、服装、道具、背景和光色是否随时间漂移；运动速度、方向和动作阶段是否突变。
- 记录无叙事动机的闪烁、纹理沸腾、边缘抖动、画面撕裂或镜头交界跳变。
- 接触、遮挡、反射、文字和复杂动作在风险区间加密检查。

### 声音与音画

- 说话者、画内/画外归属和口型依赖是否正确；不同步定位到时间段。
- 对白是否可懂，是否被音乐、音效、削波、突变或重复遮蔽。
- 声源方向、距离变化、环境底噪和跨剪辑连续性是否与画面匹配。
- 响度、峰值、声道和编码只有在目标交付规范与真实文件可用时才能判通过。
- 声景是否成立并可继承：空间与表面造成的混响与遮挡、时间状态、听取位置，是否随距离、方向和镜头视点合理继承。
- 听觉前景是否随叙事焦点变化：承担关键信息的对白可懂度是否保证；有明确叙事目的时脚步、倒计时、呼吸或环境可进入前景，且写明了目的。
- 客观与心理声场是否分开：偏离物理真实的放大、过滤、重复或替换，是否写清归属、触发、范围、退出方式与叙事目的；观众仍需听懂关键信息时，不能用情绪意图掩盖不可懂。
- J-cut 与 L-cut 的进入与结束点是否能在时间线上定位；声音桥是否不重复、不误配口型。

## 六、技术交付与版本

- 分辨率、画幅、帧率、编码、码率、封装、色彩空间、音频、文件命名和时长按实际交付规范检查。
- 字幕安全区、样式、语言、时间轴和画内准确文字按最终播放条件检查。
- 颜色承担状态或操作信息时，是否另有形状、位置、文字、纹理或动作通道。
- 高对比闪烁、快速图案或强震动先定位风险；是否合规必须使用目标规范和真实成片检测。
- 缺少文件、元数据、平台模板或规范时标为未验证，不用导演稿声明替代成片检测。

## 七、来源与权利证据

本项只检查登记完整性，不作法律判断：

- 外部图片、字体、音乐、声音、人物形象、品牌或作品片段是否能追溯来源。
- `confirmed`、`user-asserted`、`pending`、`restricted`、`unknown` 是否与现有证据一致。
- 参考、编辑、生成、发布、商业使用及第三方转交是否被错误合并成一个“可用”。
- 派生文件是否保留父来源；替换来源后，下游引用是否同步复核。

制作状态 `approved/uploaded` 不证明权利已确认。缺少证据时报告待确认对象和所需材料，不给出法律结论。

## 八、选择与交付

先报告阻断当前用途的问题，再报告明显损害质量的问题，最后给可选优化。每条包含材料类型、模式、位置、证据、影响、最小建议和未验证范围；没有问题的类别不为凑矩阵重复输出。

## 九、批量与抽样

材料成批时（多集、每轮数十张图或数十条视频）按**风险分层**抽样，不设固定抽检比例：

- **必查**：关键记忆锚与人物登场；高风险关键镜头（复杂接触、多人、反射、文字、时空变化）；跨生成组的接缝；上一轮已判定修复的位置。
- **批内分散抽样**：同一批次按位置分散取（批首、批中、批尾各有覆盖），不用连续几条代表整批。
- **以批次为单位核一致性**：跨批次的身份、服装、光色、道具与背景漂移，用批次作抽样单位比逐条看更容易暴露系统性偏差。
- **结论边界**：未抽到的部分写"未验证"，不用抽检结果推断整批通过；静帧、低清预览或无音频材料只就可观测量给结论。
- **发现系统性问题时转全批**：同一类问题在抽样中重复出现，把它转成整批检查项再复跑，不只报抽样位置的个例。
