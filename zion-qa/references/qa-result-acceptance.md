# 图片与视频生成结果验收

基于实际图片、片段或可见帧作出使用与返工判断。先继承用户指定的用途、必须保留内容和交付规格；不从提示词推定画面已经实现。

## 结果处置

| 判定 | 适用条件 | 下一步 |
|---|---|---|
| Keep | 已满足用途和关键要求，余下瑕疵不影响交付 | 保留并记录适用范围 |
| Fix in post | 核心画面可用，缺陷可通过调色、字幕、混音、裁切、剪辑或调速解决 | 指明后期动作及需保留内容 |
| Edit | 当前生成入口支持目标区域或时间段的局部编辑，其他内容可保留 | 明确编辑范围、要改内容和不变量 |
| Re-roll | 设计和指令可行，现有证据更支持单次样本失败 | 在已有授权与预算内重试，记录比较条件 |
| Rewrite | 证据指向提示词冲突、资产不足、时间/空间设计或模型适配问题 | 先修正原因，再决定生成 |

同类缺陷反复出现是诊断线索，不按“两次”直接认定系统问题；不同缺陷也不自动证明应批量重摇。综合样本、提示词、资产、入口及预算判断。是否支持 seed 或局部编辑按实际入口核验，不设延展次数、批量数量或只留一条的通用配额。建议重试不代表已获准调用外部生成或消耗费用。

## 证据与检查

- 图片：检查全图与关键区域，记录身份、结构、文字、材质、构图等实际可见问题；单张图片不适用时间连续性检查。
- 视频：结合正常播放、关键帧和疑点附近逐帧检查，定位时间段或帧。接触、遮挡、反射、文字、镜头交界和音画关系按风险加密检查。
- 只有缩略图、少量抽帧或无音频时，说明可判定范围；不得声称全片、最终分辨率或声音已经通过。
- 最终输出尺寸下复核会受分辨率影响的脸部、手部和文字细节。草稿结果只能证明该样本中观察到的行为，不能保证再次生成相同。
- 必需内容或身份失败时，明确该范围不可直接交付；同时判断局部修复或可用片段是否能保住镜头目的，不采用“一帧坏就整条废”。
- 可用片段标记起止时间和接缝条件。仅报告任务给出剪取建议；用户已授权修复时才实际导出或编辑，并复验连续性。

## reject_reason 受控词表

| 所见问题 | 值 |
|---|---|
| 身份偏离参考 | `identity-drift` |
| 服装或颜色偏移 | `wardrobe-contamination` |
| 非预期剪辑或断场 | `extra-cuts` |
| 走位、空间调度错误 | `blocking-broken` |
| 表演不符合要求 | `performance` |
| 摄影机行为错误 | `camera-wrong` |
| 物理或解剖错误 | `physics` |
| 画内文字错误 | `text-render` |
| 字幕错误、不可读或时间轴问题 | `subtitle` |
| 对白、音效、混音或音画同步问题 | `audio` |
| 无动机闪烁、纹理沸腾或时域漂移 | `temporal` |
| 边缘、遮挡、影子、反射或交互光合成错误 | `compositing` |
| 实际文件不符合已提供的交付规格 | `delivery-spec` |
| 实际发生内容过滤拦截 | `filter-flagged` |
| 构图未实现目标 | `composition` |
| 无精确归属或其他时域问题 | `other`，附证据 |

值用于报告字段，不暗示存在特定命令行工具。可用的备选素材不因“未选中”而被虚构技术拒绝理由。

## 按症状诊断与修复

先核对生成前的明确冲突，必要时读取 [投喂前检查](qa-feedability.md)。按交付物读取 [分类型验收矩阵](qa-artifact-rubrics.md)，再从主体、动作、摄影机、风格、声音、合成和输出规格中选择与证据有关的变量，不强制六轮试生成或凭轮数要求重写。

| 症状 | 核对点与可能改法 |
|---|---|
| 续接起点与实际结尾不符、动作重来 | 以父片段实际末态描述开场，明确已经完成的动作 |
| 未来事件提前出现、任务过多 | 去掉不属于本段的事件，按可继承状态重新分组 |
| 身份逐段漂移 | 对照原始批准参考重锚，不以已漂移帧替代规范身份 |
| 方向或机位运动重置 | 写清世界方向、摄影机当前阶段及连续运动意图 |
| 道具状态、持物手或音频重复 | 对照真实交接状态与已交付对白，修正续接信息 |
| 延展后质量下降 | 比较相邻段与规范参考；按损失选择重锚、剪辑或重设计，无固定链深上限 |
| 多参考图互相污染 | 明确每张图的身份/风格/空间职责和需要保留、忽略的内容 |

## 记录与交付

每项给出处置、位置/时间段、证据、`reject_reason`（存在问题时）和下一步。单张或单段验收无需完整批次报表；批量任务再汇总分布、可用率及比较条件，草稿与最终档分开统计，不使用通用成功率或成本比作通过门槛。

已有登记工具时沿用其真实接口；没有工具时用简表：`素材 | 模型/入口 | 提示词与资产版本 | 判定 | 证据位置 | 原因 | 下一步`。不要求未提供的 ledger、`amend-gen`、`--draft` 或其他工具。

已授权并完成修复后，报告实际修改和复验结果；未实施或证据不足的部分明确标注。
