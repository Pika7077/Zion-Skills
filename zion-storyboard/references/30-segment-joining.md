# 跨生成组的接缝

本档处理**上一生成组的末镜 → 下一生成组的首镜**这一刀。组内的镜头切接按 [剪辑与转场](22-editing-and-transitions.md) 与 [剪辑逻辑、时长与切点](29-cut-logic-and-timing.md)；本档只管生成边界上的那道缝。

## 一、为什么要单独处理

单次生成之间没有记忆。上一组结尾的人物站位、姿态、持物与互动，下一组一概不知道。同一个连续场次被拆成若干组分别生成时，不补这条记忆链，接缝处必然出现位置回退、动作断层、对白无气口。

这也是接缝与组内剪辑的根本差别：组内切镜是同一个连续世界里的选择，接缝是**两个互不知情的世界要对上**，所以它需要额外的显式交代，不能只靠“剪得顺”。

## 二、三种接缝方式

三种可以叠加使用，按段落性质选。

### ① 末态具体化

把上一组的结尾写成**下一组可以直接开拍的画面**：谁、在哪、什么姿态、持什么物、与谁处于什么互动状态。一句话，能画出一帧。

- 禁止套话式写法（“角色动作与空间位置严格继承”）——它是工作流口吻，不承载任何画面信息，下一组继承不到东西。
- 末态要写与下一组相关的项：下组首镜要用的那个人站在哪、朝向哪、手在做什么。与本组末镜无关的人物状态不必罗列。
- 终组按段落需要写终帧，但不用黑屏或渐暗收尾。

### ② 换机位硬切

即便末态锁死，同机位直接接仍会有割裂感——两段会读成“一个镜头被截成两段”。接缝两侧**至少换机位或换景别其一**，把接缝做成两个镜头之间的剪辑关系。

- 禁同机位、同景别硬接：上一组末镜中景平视，下一组首镜不再起中景平视。
- 选哪一种，按段落性质：连贯动作被拆开时用动作接续（下组从上一组停住的动作进度继续）；情绪顶点收段时用反应镜头（下组开头切在场者的反应）；追逐位移跨段时用动势匹配（接缝两侧动量守恒）。
- 也可以用**同比例构图**接：两端保持相同比例的构图并共享一个元素（同一物件、同一动作相位），直接硬切即可读成连贯。选型与两端锚点的写法见 [剪辑与转场](22-editing-and-transitions.md) 的同比例构图转场一节；两端构图规范要在本组开工前就定下来，不能等两组都生成完再找接点。

### ③ 空镜过渡

在接缝处插入 1–2 秒的环境镜头（不出现人物或人物退为背景），把两段在情绪或听觉上缝住。三类正当用法：

| 用法 | 做法 | 任务 |
|---|---|---|
| 情绪空镜 | 上一段情绪落地后接环境镜头，配乐延续 | 给上一段的情绪留发酵空间 |
| 声音桥空镜 | 下一段的声音先入（对白半句、脚步、开门声），或上一段的关键音效延续 | 让耳朵先过缝、眼睛后过缝，接缝感最低 |
| 时空转场空镜 | 日夜交替、地点切换、时间流逝的物件（钟表、日历、季节） | 交代时空跳跃 |

## 三、空镜的边界

空镜不是缺陷，也不是填充物。

- 每个空镜必须能说出它的戏剧任务（上面三类之一）。说不出任务的空镜删掉——它是靠画面凑时长。
- 空镜必须写得出现实画面：景别、视角、运动、声音都写清，台词写“无”。不写“氛围空镜一片”这类懒写。
- 空镜不得替代冲突。该有攻防或对峙的戏用空镜带过，那是结构问题，不是转场。
- 空镜占用本组时长预算，计入总时长。

## 四、接缝参考图

文字末态之外，跨段连续剧情宜配一张**接缝参考图**：按上一组结尾的人物状态出图，作为下一组首镜的画面依据。图锁比文字可靠，尤其在姿态和持物上。

- 接缝参考图由资产流程出图，在素材清单里标明用途（锁定接续姿态与站位），并占用素材名额。
- 常见错误做法：直接拿上一组的尾帧截图当下一组首帧。上一组尾帧是**成片画质且带本组构图**的，直接当首帧会导致画面跳切与动作粘连。正确做法是按末态重新出参考图，或在同一次生成内用首尾帧能力锁定起止。
- 参考图尚未提供时，在导演稿标为待制作，不用文字描述冒充已锁定。

## 五、计划状态与成片状态

全剧分镜可先按计划连续编排，不必等每组生成后才交付下一组。跨批次时分别保留计划末态和已验收成片末态；后者标明视频片段、末帧或用户反馈等实际依据及其覆盖范围。写完提示词只能更新计划，末帧也不能证明整段动作、声音或口型已经通过。

实际接续生成前，用已验收结果核对下一组入口。源稿未限定、且不改变剧情的呈现差异，可在制作接受后调整计划并检查受影响的后续继承链；源稿明确的持物手、动作、伤情、信息顺序或结果出错，应修复或另行取得改稿授权，不因画面被接受就自动改写源稿。待修复与被拒片段不作为正式连续状态。

纯文本交付缺少成片时，按计划完成接缝设计并标明未验证范围，不把成片验收变成编写下一组的前提。

## 六、复核

- [ ] 每组末态写成了可开拍的画面，无“严格继承”类套话
- [ ] 接缝两侧换机位或换景别，无同机位硬接
- [ ] 接缝方式与本段性质匹配（动作／反应／动势／空镜）
- [ ] 跨组连续剧情已安排接缝参考图，或标明待制作
- [ ] 每个空镜能说出戏剧任务，且写得出现实画面
- [ ] 空镜未替代冲突，且计入本组时长
- [ ] 末态与下一组首镜的人物、姿态、持物、朝向相互对得上
- [ ] 计划末态与已验收成片末态分开，实际依据与验证范围明确；接续调整未把错误结果升级为源事实
- [ ] 无黑屏、渐暗或淡入淡出收尾
