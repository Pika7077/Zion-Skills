# 镜头语言：按叙事目的选型

按 [导演决策标准](directing-policy.md) 使用；本词库没有轮换配额。先确定镜头要让观众看懂什么、感受什么，再选择景别、观看位置/角度、观察关系、构图和运动。

这些维度独立记录：**景别**是观众离主体多远；**观看位置/角度**是观众站在哪里看；**观察关系**是镜头与人物/信息的关系；**运动**是这些状态如何在时间中变化。运镜轴与具名运动见 [13-camera-and-texture.md](13-camera-and-texture.md) §三。

## 观察方式

**写提示词时直接写观察方式本身，不用代号。** 例：`过肩，保持在两人关系轴上`、`前景遮挡，门框占画面前景三分之一`。

| 观察方式 | 适用目的 |
|---|---|
| 客观正面 | 清晰交付表演、直面关系 |
| 过肩 | 保持人物关系、匹配正反打 |
| 正侧面 | 同框关系、行动轮廓 |
| 侧背 | 跟随与引领 |
| 正背 | 保留未知表情、朝向空间 |
| 主观视角 | 让观众看人物所见，需匹配视线 |
| 反射中介 | 有意的间接信息；评估生成稳定性后选择 |
| 前景遮挡 | 受限观察、空间层次；不挡关键信息 |
| 插入细节 | 物理反馈、物件信息、行为细节 |
| 弧线观察 | 连续揭示关系；明确路径和可用空间 |

观察方式之间不互斥，也不是分类体系：一个镜头可以过肩、低位仰拍且同时跟随。不设轮换配额。新数据不再把“高角度/低角度”填进 `pov_family`；分别写入 `camera_height` 与 `camera_angle`。

把主观视角**作为一个段落**使用（进入、保持、解除，以及在场感与声音次序）见 [主观性与 POV](33-subjectivity-and-pov.md)。

## 景别

| 景别 | 画面范围 | 适合读清 |
|---|---|---|
| 大远景 / 环境级远景 | 环境占主导，人物很小 | 世界、地点、规模、氛围与人的渺小 |
| 大全景 | 人物与完整环境同时可见 | 人物在空间中的位置、比例与处境 |
| 全景 | 完整人物与主要动作范围 | 全身动作、体态、走位与多人调度 |
| 中景 | 腰或大腿以上，仍保留手部和部分环境 | 状态、对话关系、表演节奏与动作过程 |
| 中近景 | 胸以上 | 表演、关系、情绪起点 |
| 近景 | 胸/肩以上，环境信息明显减少 | 面部反应、眼神、决定与关系变化 |
| 特写 | 脸、手、接触点或关键物件 | 必须被看见的情绪、线索、物理反馈或信息 |
| 大特写 | 极局部 | 细节信息、强调 |

不同教材可能把环境级镜头称为“远景”或“大远景”，也可能将“远景”用于人物全身与大量环境。继承用户术语，但要同时写清**人物占比、身体裁切和环境范围**，不靠名称猜画面；同一份交付只用一套命名。

环境级交代路径和人物关系，关系级看见互动，细节级读清关键反馈。可以逐渐收紧，也可以从细节揭示全貌；不强制往返三档。景别由**焦段、机距与主体尺度**共同决定：透视关系来自拍摄距离，焦段只决定视角宽窄，不用固定焦段映射景别（见 [摄影机与质感词库](13-camera-and-texture.md) §2.0）。

### 景别变化

| 变化 | 常见叙事效果 |
|---|---|
| 远 → 近 | 从世界/处境进入人物、决定或细节 |
| 近 → 远 | 从个体退回整体处境，可用于离开、失去、孤立或真相揭示 |
| 全景 → 特写 | 先看清行动，再落到关键反馈或物件 |
| 特写 → 全景/大全景 | 先给线索或局部，再重建人物与空间 |

这些是可选的叙事路径，不是必须套用的镜头模板。推进/后拉是景别变化的时间过程；分镜中应写清起始景别、落幅景别与落点信息。

## 观看位置与角度

`camera_height` 记录机位物理高度，`camera_angle` 记录俯仰/滚转角度。高机位可以平拍，低机位也可以上仰；不要用一个字段替代另一个。

| 角度/组合 | 可产生的叙事效果 | 判断提醒 |
|---|---|---|
| 平视 | 对等、自然、稳定，让人物和事件自己说话 | 平视不是“无设计”，而是不主动施加力量判断 |
| 高位俯拍 | 可以是弱小、受压、监视，也可以是布局、全局感或掌控感 | 先看主体是人物、群体、建筑还是行动路线，不自动等于“弱者” |
| 低位仰拍 | 可以强化力量、压迫、高度、重要性或动作冲击 | 效果强，需有明确镜头任务；不自动等于“英雄” |
| 鸟瞰/正上方 | 全局、抽离、几何、战略关系或人的渺小 | 组织空间与群体运动，不保证自动产生压迫感 |
| 虫视/贴地大仰角 | 夸张高度、陌生、怪异或极端速度 | 透视变形明显，仅在效果对内容有用时采用 |
| 斜角/荷兰角 | 不稳定、危险、失衡或秩序崩坏 | 这是滚转（roll），不是高低机位；不把轻微倾斜当通用“电影感” |

选角度前先问：它要展示空间、关系、动作、情绪还是关键细节？再问观众应离主体多远、站在哪里看。相同角度因主体、构图和上下镜不同可产生相反意义，所以输出时同时写明任务与结果，不只写“仰拍/俯拍”。

## 构图与景深

三分、对称、偏框、负空间、框中框、对角线和纵深分层按具体作用选择。连续同构图可用于前后对照。**人物之间的关系构图**（对位、对峙、压制、疏离、亲密、监视、受审等）见 [21-relationship-composition.md](21-relationship-composition.md)。关键的接触点或道具要处于可读区域和清晰焦平面；不一律浅景深。

**建立镜要建立关系，不只是拍得远。** 环境级镜头至少交付一项后续会用到的空间信息（入口、人物位置、行动路线、遮挡或群体关系），并给观众一个明确视觉焦点。若人物和关键动作淹没在无主次的全景里，画面会像舞台记录；缩短、换构图或改用关系级景别。

| 景深选择 | 适合 | 必须同时解决 | 常见失手 |
|---|---|---|---|
| 深焦／多层清晰 | 前景、中景、背景的同时关系都参与叙事；观众需要自行比较或发现 | 调度、高低/大小、明暗、色彩或遮挡仍有主次，关键层在最终画幅可读 | 把“都清楚”误当“都有重点”，造成信息拥堵与平面化 |
| 选择性焦点／浅景深 | 收束注意、隔离主体、暂时隐藏背景信息或完成同框焦点交接 | 清晰层是谁、虚化层为何可暂不读、何时重新交代空间 | 把背景虚化当作电影感标签，丢失空间与关系证据 |

背景虚化只是**组织或延迟信息**的一种方法，不等于电影感；深焦也不等于信息越多越高级。深焦的成立不只靠小光圈，还依赖灯光、焦平面、人物调度、层间对比、主体尺度与交付分辨率。最终判断始终是：本镜哪些层必须同时被读清，哪些层应退出注意中心。

## 固定、运动与焦点

> 本表给每类手段的**目的与必写项**；各类运动的**表意与使用纪律**（推进、拉远、横移、跟拍、环绕、摇摄、手持、固定、下降）见 [13-camera-and-texture.md](13-camera-and-texture.md) §3.2。

| 手段 | 有效目的 | 需写清 |
|---|---|---|
| 固定 | 看清调度、等待或对峙 | 保持什么构图，画内怎样变化 |
| 推/拉 | 收束注意或揭示环境 | 起点、距离变化、停在哪个信息上 |
| 横移/升降 | 跟随、越过遮挡、重建关系 | 路径、速度与主体关系、落点 |
| 跟随 | 保持行动可读 | 跟谁、从何方向、结束位置 |
| 弧线 | 逐步揭示新关系 | 弧线方向、轴线与场景空间 |
| 手持 | 特定主观或纪实质感 | 幅度和用途，不随情绪一律乱晃 |
| 焦点转移 | 同框信息交接 | 由谁到谁、触发时刻；机位可固定 |

慢运动要有足够时间体现速度；小幅校正无需硬凑三秒。复合运动要让主体、接触和信息可追踪，不要求每组必须有运动。

### 短长镜头

短长镜头是**时长相对紧凑、但保持一个真实镜头编号和连续时空**的镜头。它适合表现一段变化过程：动作、关系或注意力如何从起态过渡到落态；不是“时间不长的普通镜头”，也不因不切镜自动更高级。

写法按三个部分展开：`起始状态 → 连续路径（走位／摄影机／焦点的阶段变化）→ 落幅状态`。内部可以标拍点或阶段，但不得伪装成多个镜头。若中间只是在完成互不相关的任务、连续运动没有新增信息，或单次生成难以稳定维持身份和空间，就切开处理。

### 低机位弧形英雄镜头

“迈克尔·贝运镜”只作为用户沟通中的风格简称；导演稿与生成提示词应改写成可见、可执行的摄影机路径，不把导演姓名当成模型指令。常见结构是：**低机位广角起幅 + 围绕主体的弧形位移 + 可选升降或推进 + 明确落幅**。它适合人物登场、力量关系翻转、对峙升级或动作后的定势，不是所有高能段落的默认拍法。

设计时依次确认：

1. **戏剧落点**：镜头结束时新增什么——认清人物、显出对手、揭示装备、建立规模，或读到表情变化。没有新增信息就不环绕。
2. **起幅与落幅**：写清起始机位高度、角度、人物占比和前景；再写结束机位、景别与信息焦点。低机位不自动等于英雄，需由姿态、行动结果、构图和上下镜共同成立。
3. **弧线范围**：优先选能完成揭示的最短弧线。约 60°–180° 通常比完整 360° 更易保持身份、轴线和背景连续；完整环绕只在场地、时长和四周美术都支持时使用。
4. **复合路径**：弧线、升降、推进若同时发生，应被描述为一条连续轨迹，并指定哪个变化主导。写速度曲线和落点，不把“环绕、升起、推进、变焦、摇摄”堆成并列动作。
5. **广角透视**：广角与近距离会放大前后景尺度和速度；先检查脸、四肢、车辆及建筑直线能否接受变形。需要力量感时可保留受控透视夸张，不默认添加鱼眼或随机桶形畸变。
6. **灯光与时间**：逆光、轮廓光、硬顶光或高反差按 [光影系统](20-lighting-system.md) 给出真实来源与面部可读性。慢动作只在动作姿态、冲击反馈或表情确实需要延长读取时使用；它不是英雄镜头的固定组成。

写法骨架（不是可直接套用的成片模板）：

```text
从[起始高度/角度/景别]开始，摄影机沿主体[左/右]侧作[角度范围]弧形位移，同时[升高/降低/靠近，若需要]；[主体或前景]保持可追踪，[背景关系]逐步显露；速度[匀速/先慢后快/先快后慢]，最终停在[落幅景别、机位与新增信息]。
```

分辨率、渲染引擎、PBR、颗粒、青橙调、配乐与字幕分别按已确认的交付规格、美术、材质、声音需求决定，不因采用此运镜自动添加。

### 权力群像接力揭示长镜头

网络上常称“权谋运镜”的一类拍法，本质是：**摄影机沿一条连续可实现的路径移动，人物依次接管前景、焦点或画面占比，最后重建完整群像关系**。它适合权力排序、阵营亮相、谈判前定势或多人关系揭示；不绑定都市天台、黑西装、冷蓝调、年轻精英或任何固定题材。

#### 连续性定义

- 一镜到底只有一个真实镜头编号。内部按时间写“阶段/拍点”，不得写成“分镜1、分镜2”或“拉焦切镜”。
- 拉焦是焦点平面从人物 A 交给人物 B，不是剪辑；人物从画面盲区进入是调度，不是切镜。
- 摄影机路径、人物站位和焦点变化可以同时发生，但每一阶段只安排一个清楚的视觉主导权交接。
- 若实际发生硬切、隐藏剪辑或从地面机位跳到航拍视点，就不再声称纯一镜到底；隐藏剪辑按 [剪辑与转场](22-editing-and-transitions.md) 标注遮挡与切点。

#### 设计顺序

1. **先画空间图**：记录每个人的世界坐标、朝向、高低、前后层次、遮挡物、护栏/墙/桌等边界，以及摄影机可走路径。人物不能为了下一次显露而瞬移。
2. **分配权力信息**：每次交接必须新增关系信息，例如谁观察谁、谁挡住谁、谁让位、谁最后统摄全局。不同人物不应只重复抬眼、冷笑、整理衣领等同义“气场动作”。关系构图按 [人物关系构图](21-relationship-composition.md) 处理。
3. **锁定主导轨迹**：可采用横移或短弧逐人揭示，再后撤/升高重建群像；所有变化应构成一条连续曲线，不能每两秒换一个互不相干的运镜轴。
4. **安排焦点交接**：写清起始焦点、触发动作、交给谁、交接时长和交接后保持多久。要求多次拉焦时不能同时声明“全程焦点锁死某人”。
5. **校准速度**：用户要求匀速或无突然加速时，摄影机物理速度保持连续，用人物入画、前景遮挡解除、焦点转移和画面占比变化制造冲击；不得同时写“极速后拉、猛然推进、视野极速拓宽”。
6. **设计最终落幅**：结尾群像要重新交代全部人物的站位、占比、视线与权力中心。若要加入直升机、车队或城市规模，只能作为连续路径能够自然揭示的背景/环境事件；切换到远处航拍视点需要另镜或有依据的隐藏剪辑。

#### 时间与生成负荷

人物每次接管画面都需要足够时间完成“出现—被辨认—给出新信息—交出焦点”。15 秒内连续揭示四人并要求多次大幅位移、贴脸特写、复杂表演和最终大全景，可能超过可读性或生成稳定性；应根据实际模型与内容减少人物、简化路径、延长时长，或拆成有动机的镜头。不能因模板写了五个时间段就假定它可生成。

写法骨架（只表示结构）：

```text
单镜头连续运动，摄影机从[起幅位置/景别]沿[方向与路径]以[速度特征]移动。
[阶段一时间]：[人物A的可见动作与关系信息]，焦点在A。
[阶段二时间]：[前景/调度触发]使人物B进入主导位置，焦点由A平滑交给B；摄影机路径不断。
[后续阶段]：每次只交接一个主导主体，保持人物世界位置连续。
[结束阶段]：摄影机[后撤/升高/转向]至[最终景别]，全部人物站位与权力关系可读，停在[新增信息]。
```

年龄、服装、地点、灯光、质感和声音从项目资产及场次继承。`8K`、`UE5`、`PBR`、胶片颗粒、无配乐、无字幕等不是这种运镜的组成部分。

## 切镜复核

可切向动作接触、反馈结果、视线对象、听者选择或新空间信息。正反打正常编号，不能把单个镜头写成多个观察点突变。180 度关系和视线匹配保持清楚；越轴要有可理解的重建过程。**变化量是否足够（30° 判据）与切点落在动作哪一阶段**见 [剪辑逻辑、时长与切点](29-cut-logic-and-timing.md)。

横移、推进、摇摄或越过前景后显露主体，可能只是同一镜头内的信息揭示；只有实际切到另一个镜头才叫转场。匹配剪辑、物件媒介、遮挡切换和声音桥的两端锚点与切点规则见 [剪辑与转场](22-editing-and-transitions.md)。

判定单调时先读内容：同一表情换五种拍法仍然单调；同机位内行动、阻力和选择连续发展可以有效。不要以镜头参数相似度自动否决。
