# 三步引导法：变化、重点、预期、关系

分镜不是把动作机械切碎，而是**引导观众**——先让观众看到一个值得在意的变化，再用重点锚定记忆、用节奏操控预期、用关系预埋张力。本档先立标尺（§一），再给一套逐场次自检的三步流程（§二–§四），三步适用于任何场次，**悬疑与反转类场次优先级最高**。

三步不是三种镜头的分类，而是**同一场戏的三个设计动作**，按顺序做：先定重点，再排预期，最后埋关系。

## 一、标尺：观众关心的有意义变化

分镜要完成的不只是"把剧情讲清楚"，而是**让观众看到一个有意义的变化发生**——信息、关系、处境、态度或力量对比发生了改变，观众才会产生对应的情绪。所以每一镜都要能回答两问：

- **这一镜带来了什么变化？**
- **观众在意这个变化吗？**——它与人物想要的东西有关系吗？

两问都答不上来，这一镜就只是在"把剧情交代过去"。

**常规镜头的局限**：全景交代空间 + 正反打推进对话，是保证因果可读最省事的组合——**逻辑通顺，但不产生变化**。它们不会写错，也不会让人有反应。检验办法是**替换性检验**：把这组镜头换成任意两个人在任意房间做同样的事，是否照样成立？成立就说明它只完成了"清晰呈现"，还没开始讲故事。

这不是禁用全景与正反打：它们是**保底手段**，一镜的职责只是交代或接续时用它们是对的（同 [directing-policy.md](directing-policy.md)）。问题出在**整场只有保底手段**——该发生的变化一处也没发生。

**顺序：先定表达目标，再找画面。** 开工前先写一句话——**这场戏要让观众产生什么感受**，以及**这个感受由哪个可见变化带来**。然后才去挑承载它的画面。跳过这一步直接按动作顺序分镜，就会平均分配镜头，得到一场逻辑通顺、没人在意的戏。

**核心与次要**：

- **强化核心**：承载变化的那一两个动作或反应，加篇幅、用更近的景别、必要时单独成镜（分配规则见 §二）。
- **弱化次要**：铺垫动作放到更松的景别、更短的时长，或合并成一镜带过——景别越松、时长越短，观众越不会把它当重点。
- **不平均分配**：全场镜头等长、等景别，等于没有重点。

**把情绪落在"没做成的动作"上**：不舍、犹豫、克制这类内在状态，写成**该做的动作没做、或做到一半停住**（协议放在桌上等对方拿，而不是主动推过去；视线避开那个不愿看的动作；拿起钥匙又放下），比写成表情更可靠——动作有起态也有中断点，观众看得见"她本来要做，但停住了"。表情是结论，未完成的动作是过程；两者的强度与时序见 `zion-script` 的物理表演档。

## 二、找重点：一场戏一个记忆锚

**判定问题**：这场戏结束后，观众必须记住的那一条是什么？把它写成一句话，然后检查镜头时长分配是否与它一致。

| 镜头性质 | 处理 | 时长 |
|---|---|---|
| **记忆锚**（核心信息） | 给足读取时间，可以单独成镜 | 拉长；观众要能读完表情、线索或决定的完整变化 |
| **铺垫动作**（进门、关门、坐下、拿起、走过） | 快速过渡，合并或省略 | 短；能交代"发生了"即可 |
| **无效堆砌** | 删 | — |

**常见错误**：把"进门 + 关门 + 走到桌边 + 坐下"四个铺垫动作各给一镜一秒钟，而"得知中奖的震惊"只给半秒。观众记得住的不是镜头数最多的那段，而是**停得最久的那一段**。

**记忆锚的三种形态**：

- **可见信息**：观众必须看到的事实（手机屏幕的字、桌上的信封）
- **可见反应**：人物的完整情绪变化过程（从无表情到理解到失控）
- **可见决定**：一个动作的开始（手伸向门把、把杯子推开）

另有一种强化做法是**反常反应**——人物在承受极端处境时做出与处境不匹配的反应（受伤后笑、被羞辱时道歉、被追赶时停下）。它比同向的情绪爆发更容易被记住，但必须与人物处境有真实关联，且后面要给出解释。用法与纪律见 [开场与结尾设计](25-opening-and-ending.md) 的开篇功能一节。

**要点**：

- 一场戏**只有一个记忆锚**。有两个时，先定主次，次要的降为铺垫或移到下一场。
- 铺垫可以**合并成一镜**（一个横移带过进门与入座），不必逐个交代。
- "拉长"不等于加慢动作。拉长的正确方式是**给够表演时间**，让反应有起承转合；用慢动作延长会读成风格化处理，不是强调。

### 与既有配额的边界

本档**不设时长配额**（不规定"记忆锚必须 X 秒"）。判据是**相对时长关系**：记忆锚必须显著长于开场以来的铺垫镜头，且足够让观众读完。这与 [directing-policy.md](directing-policy.md) 的"无配额"原则一致——重点是分配比例，不是绝对秒数。

## 三、找节奏：控制观众想知道答案的时间

节奏的本质是**信息时序**，不是快慢本身。快切与慢切都是手段，目的是控制观众"我什么时候能知道"。

对悬疑、反转、揭秘类和任何有"答案"的场次，先写出**本场的信息时序**：

```text
强化项：观众此刻期待什么（本场在等的那个答案）
延迟项：用什么手段把答案推迟
插入项：延迟过程中插入什么新悬念（把等待升级，而不是单纯拖时间）
```

**只延迟、不插入新悬念 = 拖时间**。观众会感到被耍。延迟的正确代价是**换一个新的、更高的期待**——等待期间观众开始担心另一件更严重的事。

### 3.1 强化期待

用多角度、快切、局部细节累积同一目标，放大观众的焦虑。适用于"找东西""赶时间""躲避"这类过程性动作。

- 多角度**必须每次都新增信息**（换个位置、换个遮挡、露出新的局部），否则只是重复同一信息。
- 快切的时长必须足够认出锚点（见 [22-editing-and-transitions.md](22-editing-and-transitions.md) §三）。
- 增强的是**同一件事的逼近感**，不制造第二件事。

### 3.2 延迟所依赖的两类装置

**第一类：信息流控制**——控制观众何时知道。

| 手法 | 用法 |
|---|---|
| 切断在揭示前 | 在答案出现前 1–2 秒切换或收尾（分集切口规则见 [25-opening-and-ending.md](25-opening-and-ending.md) §四） |
| 听者反应先于真相 | 先给反应，真相留到下一拍 |
| 局部先行 | 先给证据的一角：扣住的手、压住的纸边、只露出一半的物件 |
| 视线转移 | 人物看向画外，观众被引向尚未拍到的东西 |
| 声音先入 | 声音先行交代，画面延后（见 [15-audio-and-lipsync.md](15-audio-and-lipsync.md)） |

**第二类：中景介质与反射**——在人物与观众之间加一层载体。

| 载体 | 效果 |
|---|---|
| 水面／杯子／镜面／玻璃窗／屏幕反射 | 观众经反射看到本不该看到的东西：身后的动静、另一侧的人、被遮挡的表情 |
| 门缝、帘幕、格的局部 | 观众只看到局部，主动去补全 |
| 前景遮挡 | 观众感到有人在看（见 §四） |

**关键用途**：这类载体的价值不是"好看"，而是**在不切换空间的前提下插入另一个维度的信息**。例如人物低头找东西时，用杯中水面倒影带出身后多出的人影——镜头没换空间、没换人物，但观众获得了第二个悬念。

**插入项必须有后续**。插入的悬念必须在本场或下集得到回应，不能只是勾一下就不管。

### 3.3 节奏的三条纪律

1. **切换快慢要有理由**。同一场戏内，快与慢的对比要对应"信息密度"的变化：铺垫密、记忆锚疏。
2. **给足认出锚点的时间**。快切不合法地跳过锚点，会让观众丢失因果。压缩只能压铺垫。
3. **快慢不改变因果**。压缩铺垫可以，切掉动作因果、关键反馈或对白不行（见 [22-editing-and-transitions.md](22-editing-and-transitions.md) §三）。

### 3.4 两种等待：不知会不会／知道一定会

观众的等待有两种，写法不同：

| 等待 | 观众在等什么 | 制造压力的手段 | 失手 |
|---|---|---|---|
| **不知会不会发生** | 结果——会不会出事、会不会被识破 | 隐藏结果，用局部先行、听者反应先于真相这类装置（§3.2） | 提前泄底 |
| **知道一定会发生** | 时间——什么时候动手、什么时候被抓住 | 明知观众能预判，仍把过程拉长，让细节持续推进"它更近了"——慢镜头、局部特写、危险环境反复出现 | 细节不再新增信息，退化成拖时长 |

第二种最容易与"拖时间"混。区别在于：**每个延长的细节都要新增一层"更近了"**——脚步更响、门缝的光更窄、手里的东西握得更紧。只在原地打转（同一表情、同一角度重复）就是拖时间，判据见本节开头的"只延迟不插入新线索"。

**为什么知道结果还会紧张**：观众焦虑的对象不是"会不会"，而是"我被迫看着它发生"。这类段落靠**强制关注**成立——画面只给这一件事，不留别的出路；一旦插入无关信息，压迫感就散了。

## 四、找关系：预埋张力

**关系必须在事件发生之前建立。** 反转之所以有效，不是因为它意外，而是因为观众事后能回想起早就给出的暗示。

### 4.1 预埋三件事

| 预埋对象 | 具体做法 |
|---|---|
| **空间关系** | 谁在画面外、出口在哪、人物背对什么方向——这些决定了后面能发生什么 |
| **人物关系** | 谁在看谁、谁掌控空间、谁被动（取景语法见 [21-relationship-composition.md](21-relationship-composition.md)） |
| **危险暗示** | 用前景遮挡、反射、背景中的人影、被压住的物件，让观众提前感知 |

### 4.2 前景遮挡的主观视角

这是悬疑场次最经济的手法：**前景给出遮挡物，后景是人物活动，构图上让观众感觉自己在偷看**。

具体做法：

- 前景有具体遮挡物（门框、货架、帘幕、玻璃），**不挡关键动作**。
- 遮挡物与人物之间留出可见通道，观众通过它看人物。
- 遮挡物可以是"有人躲在后面"的暗示，也可以只是空间层次；两者**写法不同**：
  - 只作层次 → 写"前景帘幕占画面左侧三分之一，人物在中景活动"。
  - 暗示偷窥 → 还需写出**暗示的依据**：遮挡物有轻微位移、画面边缘多出的一小截人、极近的呼吸声、或下一镜直接给出观察者。

**纪律**：暗示必须能在后续得到兑现。**只暗示不兑现，是欺骗观众；不暗示直接反转，是观众不服。** 两者都由 [zion-qa](../SKILL.md) 的盲读检查判定。

### 4.3 与视觉母题的分工

本档的预埋是**场次内**的关系建立；跨场次反复出现的道具／色彩／构图意象属**视觉母题**，见 [24-visual-motifs.md](24-visual-motifs.md) 并登记母题表。同一物件既作场内预埋又作跨场母题时，母题表登记一次即可，场次内说明它在**本场**承担什么。

### 4.4 环境预示：铺预期 → 揭示 → 释放

危险不必等人做出来才被感知。把注意力从人物的动作移到**他正走向的环境**上，环境本身就能完成预示：

| 步 | 做什么 |
|---|---|
| **铺预期** | 镜头聚焦环境的危险属性（闭塞、无出口、被人围住、光线不对），而不是人物的动作。人物越坦然，环境越危险，落差越大 |
| **揭示** | 让观众预料的那件事发生——或换成更糟的一件 |
| **释放** | 给出结果与人物反应，让攒起来的压力落地。没有这一步，压力只是被掐断，不是被处理 |

**动作只是载体**：人物此刻的目的与真实意图可以完全不交代，他的行走／动作只负责把观众带进这个环境。观众先感到危险逼近，再看到结果——紧张来自环境，不来自表演。

**判据**：把人物的动作换成任意一个同类动作（走路换成开车、换成推门），这道预示是否仍然成立？成立，说明压力确实由环境承担；不成立，说明压力其实挂在动作上，动作一变弱整场就塌。

预期的铺与收要与色彩、光影的安排一致——预渲染的色调若与后面真实发生的事对不上，观众会读成调色失误（见 [色彩的结构功能](36-color-as-structure.md)）。

## 五、三步自检表

对每一场戏逐项过。答不上来的项即修改点：

| 步 | 检查 |
|---|---|
| **标尺** | 本场要让观众产生什么感受？这个感受由哪个可见变化带来？ |
| | 每一镜带来了什么变化？观众在意吗？ |
| | 有没有整场只有保底手段（全景交代 + 正反打）——逻辑通顺但一处变化也没发生？ |
| **找重点** | 本场的记忆锚是哪一条？是否只有一条？ |
| | 记忆锚的时长是否显著长于铺垫镜头？ |
| | 铺垫动作是否已合并或省略，没有无效堆砌？ |
| | 记忆锚是可见信息、可见反应还是可见决定？ |
| **找节奏** | 本场观众在等的答案是什么？ |
| | 等待属于“不知会不会发生”还是“知道一定会发生”？后者每个细节是否新增了“它更近了”？ |
| | 已知结果时，画面是否只给这一件事、没插入无关信息？ |
| | 用什么手段延迟？延迟期间**插入了什么新悬念**？ |
| | 强化期待的多角度／快切是否每次都新增信息？ |
| | 快切的时长是否仍够认出锚点？ |
| | 插入的悬念在本场或下集有无回应？ |
| **找关系** | 空间关系（谁在画外、出口在哪）是否已建立？ |
| | 人物关系（谁在看谁、谁掌控）是否在事件前可见？ |
| | 危险暗示用的是什么载体？后续是否兑现？ |
| | 用环境预示时，“铺预期→揭示→释放”三步是否齐全？把人物动作换成同类动作后，预示是否仍成立？ |
| | 前景遮挡有没有挡住关键动作？ |

## 六、常见失败

| 失败 | 症状 | 修复 |
|---|---|---|
| 只有保底镜头 | 整场都是全景交代与正反打，逻辑通顺但没人有反应 | 先写表达目标，找出承载变化的那一两个动作并加强，其余弱化 |
| 镜头平均分配 | 全场镜头等长、等景别，分不出重点 | 定主次：核心加篇幅、收近景别；铺垫合并、缩短或放远 |
| 信息替代变化 | 该交代的都交代了，但处境、关系或态度没有前后差值 | 找出这场戏结束时与开始时不同的是什么，把它写成可见动作 |
| 情绪写成结论 | 用"不舍""难过"这类表情或形容词承担情绪 | 改成没做成的动作：该做没做、做到一半停住、伸手又收回 |
| 铺垫膨胀 | 进门关门各给一镜，关键反应一闪而过 | 合并铺垫，把时长让给记忆锚 |
| 记忆锚过多 | 一场戏三个重点，观众一个都没记住 | 定主次，次要降级或移场 |
| 只为拖时间 | 反复切同一目标，不新增信息 | 每次切必须新增信息；或改用插入项换期待 |
| 已知结果的等待退化成拖时间 | 明知会出事，但延长段里的细节只在原地打转 | 每个细节新增一层"它更近了"；画面只给这一件事 |
| 预示没有释放 | 环境铺了一路危险，结果草草带过 | 补结果与人物反应，让压力落地；否则只是被掐断 |
| 插入项无回应 | 勾了一下就不管 | 本场或下集兑现，否则删除该插入 |
| 反转无预埋 | 结局意外但观众不服 | 补关系预埋与危险暗示，且暗示必须可追溯到具体画面 |
| 暗示不兑现 | 反复暗示某人可疑，结局毫无交代 | 兑现，或删掉暗示 |
| 慢动作代替强调 | 关键反应靠降速延长 | 给够表演时间，让反应有起承转合 |
| 前景挡住关键动作 | 遮挡物压掉手部或表情 | 调整构图，遮挡只占边缘与局部 |

## 七、适用范围

§一 的标尺与核心/次要分配**对所有场次适用**，包括纯氛围段落与动作高潮段落（后者另有 [action-choreography-rules.md](action-choreography-rules.md)）。

三步（重点／节奏／关系）的适用面：

- **必用**：悬疑、揭秘、反转、复仇、犯罪，以及任何有"答案"的场次（找物、找人、等结果、对峙前）。
- **推荐**：家庭、情感、职场等以关系和情绪为主的场次，重点与关系两步收益明显，期待的延迟可弱化。
- **不适用**：纯氛围段落、空镜组、动作打斗的高潮段落（后者按 [action-choreography-rules.md](action-choreography-rules.md) 处理）。

三步是**自检流程**，不是输出字段。除用户明确要求，不把三步写成交付物里的三个标题。
