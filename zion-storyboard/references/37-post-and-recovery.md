# 37 · 后期可救性与合成交接

本档在镜头需要复杂合成、精确文字、可替换表演、高风险生成或明确后期修复时读取。目标不是为每镜增加备用覆盖，而是让关键镜头在失败、裁切、替换或组合时仍有可行路径。

## 一、先判断哪里需要可救性

满足任一项时规划后期或替代路径：

- 镜头承担不可重拍的关键信息、表演或转折；
- 身份、接触、文字、反射、群体动作或复杂特效生成风险高；
- 画面需跨版本替换语言、品牌、屏幕内容或音乐；
- 前景、主体、背景或特效需要独立调整；
- 时长、节奏、画幅或平台版本尚可能改变。

普通、低风险且容易重做的镜头不必强制增加主镜头、保护镜头或 clean plate。

## 二、覆盖不是数量配额

按剪辑问题选择覆盖：

| 需要解决的问题 | 可选覆盖 |
|---|---|
| 保住整段空间与表演关系 | 主观察镜头或连续双人镜头 |
| 替换某句对白或反应 | 对应单人、反应镜头或声音桥 |
| 隐藏动作/生成接缝 | 插入物件、环境反馈或有任务的空镜 |
| 保留关键动作可读性 | 能看清起因、接触和结果的功能镜头 |
| 为裁切或画幅改编留余地 | 主体周围保留真实可用空间，关键内容不贴边 |

覆盖必须带来替换价值。两个镜头若构图、信息和时长作用完全相同，只是多生成一次，不算有效覆盖。

## 三、镜头头尾与接缝余量

- 需要剪辑、溶解、变速或音桥时，在动作和台词之外保留可用的稳定起手与落幅。
- 余量按具体后期任务规划，不设通用秒数；静止余量过长也会增加生成漂移风险。
- 重要台词开头、接触点、表情峰值和动作结果不要紧贴生成块边界。
- 跨生成组仍以实际末态为准，余量不能代替连续状态记录。

## 四、合成分层

复杂镜头按需要拆出：

| 层或素材 | 用途 |
|---|---|
| clean plate | 无人物/无可变元素的背景底板，用于移除、补洞或替换 |
| 主体层 | 人物、生物、载具或关键道具，明确边缘、遮挡和接触面 |
| 前景/遮挡层 | 门框、玻璃、烟尘、植物等承担深度或遮挡的元素 |
| 特效层 | 火、雾、光、粒子、屏幕内容等；说明发生源和交互 |
| shadow/reflection | 与主体运动同步的影子、反射或交互光 |
| matte/mask | 需要局部调整、换色、替字或合成的区域 |

分层不是要求模型直接输出所有专业通道。若当前入口不支持透明层或遮罩，就把它登记为后期素材需求，选择可实际获得的拍法，例如分开生成背景与主体、固定机位、减少遮挡或保留干净区域。

## 五、跟踪与屏幕替换

- 需要替换屏幕、招牌或包装文字时，载体平面、透视、遮挡、反光和运动模糊应可追踪。
- 可编辑内容与画面质感分开交付；准确文字由后期或可验证入口完成。
- 跟踪点、边框或高对比特征必须属于画面合理结构，不能凭空污染成片；若仅用于工作版，登记移除方式。
- 镜头中载体剧烈弯折、快速遮挡或离开画面时，提前给替代方案，而不是把无法替换的问题留到后期。

## 六、失败后的选择顺序

1. 当前素材是否已有可用时间段或可裁区域。
2. 缺陷能否用剪辑、调色、字幕、混音、稳定、遮罩或局部合成修复。
3. 是否能替换单层、单镜或反应镜头，保留其余内容。
4. 是否需要重生成当前镜头。
5. 只有设计或分组本身不成立时，才回到分镜或剧本重写。

不得为了“保险”默认把所有问题都推给后期；也不得因单帧瑕疵直接放弃可用主体。

### 组接修复的边界

- 缩放、裁切与平移只能在源分辨率、最终画幅、安全区和主体完整性允许时使用；放大后细节不足、关键动作被裁掉或构图失衡，就不是可用修复。
- 同一连续空间的曝光、白平衡、对比和色彩可做匹配；若差异来自时间、地点、主观状态或叙事色彩脚本，不为表面统一抹掉它。
- 插入反应、物件、手脚、视点或环境镜必须有现成可用素材或已规划的补拍/补生成，并保持原有因果。后期不能凭空假设观众没看见的事件。
- 水平翻转会同时改变文字、左右手、伤情/服装非对称、道具方向、驾驶位置、光向、地标和轴线，只在逐项验证均不受损时采用，并在交接记录中列出验证项。
- 关键身份、道具状态、接触点或表演结果错误时，优先局部替换、重生成或重拍；不要用快剪、梦境标签或情绪强度掩盖事实错误。

## 七、交接记录

每个需要后期的镜头按需记录：

- `post_intent`：后期要完成什么，不写泛泛“优化”。
- `edit_handles`：需要怎样的起手、落幅或声音余量。
- `required_layers`：需要的底板、主体、前景、特效、影子/反射、遮罩。
- `replaceable_regions`：文字、屏幕、品牌或可换区域。
- `fallback_shots`：可替代哪项信息或动作，使用条件是什么。
- `unverified_risks`：必须等实际生成或合成后才能判断的部分。

## 八、自检

- [ ] 高风险关键镜头有与风险对应的修复或替代路径
- [ ] 覆盖镜头带来真实替换价值，不是重复生成
- [ ] 头尾余量服务具体剪辑任务，关键时刻未贴边
- [ ] 合成层的遮挡、影子、反射和交互光关系可说明
- [ ] 精确文字与画面质感分开，载体具备可替换条件
- [ ] 缩放、裁切、调色、插入镜或水平翻转未改变身份、状态、动作因果、空间关系或叙事色彩差异
- [ ] 后期需求有具体动作、素材和未验证风险
