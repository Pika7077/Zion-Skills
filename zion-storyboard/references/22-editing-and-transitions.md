# 剪辑与转场：叙事边界、镜内揭示与镜间衔接

本档处理镜头内信息揭示、镜头间衔接和场次过渡。先判断是否真的发生剪辑，再选择手段；“斯皮尔伯格式转场”等导演姓名或网络俗称只作为沟通入口，正式导演稿与生成提示词改写为可见机制。

## 〇、先判断叙事层级与边界任务

**不是每次切镜都叫场次转场，也不是只有淡出、叠化才算转场。** 先判断这次变化位于哪个层级：

| 边界 | 当前任务 | 优先检查 |
|---|---|---|
| 同场内镜头 A → B | 改变观察位置而保持同一时空与戏剧任务 | 动作、视线、方向、因果和声音是否连续 |
| 场 A → 场 B | 让观众进入新的时间、空间、人物焦点或戏剧任务 | 旧场怎样结束，新场先让观众知道什么 |
| 序列/大段落 A → B | 标记阶段性问题、行动方向或情绪章节发生变化 | 边界是否需要停顿、强调、字幕或视听重置 |

镜头—场—序列—幕的结构判据见 `zion-script` 的分场结构档。分镜只负责把已成立的边界拍清楚，不为使用某种转场手段擅自重组剧本层级。

### 什么时候需要让边界可读

以下变化要求观众能够重新定位，但不等于必须添加显性特效：

- **空间变化**：地点、空间关系或行动区域改变；连续长镜头或同一调度已把路径演清楚时，可以不切。
- **时间变化**：同地点跨过一段时间、进入回忆/未来、平行时间线或省略过程；可由实体状态、光线、季节、声音、字幕或镜头关系建立。
- **叙事任务变化**：主要人物焦点、阶段目标、问题或情绪章节发生足以重置理解的改变；即使时空不变，也可能需要新的场或段落边界。

判断句：**如果直接把 A 接到 B，观众会把它们误读成同一时间、地点或任务吗？** 会，则补定位锚点或强化边界；不会，硬切也可以完成转场。

### 连贯与分隔是两项功能

| 功能 | 观众体验 | 常见做法 |
|---|---|---|
| 连贯 | 感觉前后仍属于同一条行动、因果或情绪线 | 动作/视线/图形匹配、因果切换、声音桥、方向延续 |
| 分隔 | 意识到时间、空间、阶段或语气已经改变 | 停顿、硬切反差、淡出/淡入、叠化、字幕、视听基线重置 |

两者不是二选一。一次转场可以用声音承接保持连贯，同时用画面反差标记分隔。序列内部通常更重连贯，序列或大段落边界通常更重分隔，但项目节奏与表达目标优先，不能把这条倾向写成固定规则。

“无技巧/有技巧”只描述实现方式，不代表质量等级：逻辑硬切、动作切和声音桥可以高度设计；淡出、叠化、遮罩或字幕也可能只是装饰。选择标准是边界任务，不是特效多少。

## 一、先分清两类结构

### 1. 镜内运动揭示

摄影机横移、推进、摇摄或越过前景后，人物、地点或关键物件才进入画面。整个过程没有切镜，因此本质是**镜内揭示或重构图**，不是镜头间转场。

必须写清：

- 起幅已有信息与暂时被遮住的信息；
- 摄影机是平移、原地摇摄、推进，还是主体自行入画；
- 前景/障碍物如何退出画面，主体在何时显露；
- 显露后停在什么景别、构图和新信息上。

“突然显露”可以来自主体入画、遮挡解除或运动速度变化，不等于必须猛甩镜头。环境铺垫应建立地点、方向或悬念；若移开前景后没有新增信息，删掉这段运动。

### 2. 镜头间转场

从镜头 A 切到镜头 B 时，用动作、形状、运动方向、声音、遮挡或因果关系维持注意力。两个镜头必须独立编号，并分别写 A 的结束锚点与 B 的起始锚点；不能把跨时空切换伪装成一个连续镜头指令。

| 手段 | 保持什么连续 | 必写项 | 常见风险 |
|---|---|---|---|
| 动作匹配 / 接动作 | 同一动作阶段、方向和速度 | A 在动作哪一刻切；B 从哪个进度接续 | 动作被重复一次或跳过接触点 |
| 图形/物件匹配 | 轮廓、位置、颜色、运动或语义 | A 末帧锚点；B 首帧对应锚点；两者差异 | 只说“match cut”，构图并不对应 |
| 因果切换 | 刺激与结果 | A 给出原因；B 给出可辨结果 | 结果早于原因，或新增无依据物件 |
| 遮挡/隐藏剪辑 | 全画幅遮挡及运动方向 | 遮挡物进入、覆盖、离开；切点 | 遮挡不完整，切后方向或速度突变 |
| 声音桥 | 同一声音跨越画面或场次 | 声源、提前/延续区间、画内外关系 | 声音重复、无来源，或要求错误口型 |
| 溶解/相似叠化 | 形状、亮度、烟雾、时间感 | A 与 B 的对应区域、叠化目的和时长 | 用模糊掩盖不匹配，拖慢节奏 |

硬切本身不是失败。对白、冲突或动作需要清楚反应时，硬切、视线切或动作切往往比装饰性转场更有效。

本档只给手段与两端锚点；**变化量够不够、每镜该多长、切点落在动作哪一阶段**（30°/180°、视觉变化量、动势匹配、读取时长、3:7 出接动作、跳剪）见 [剪辑逻辑、时长与切点](29-cut-logic-and-timing.md)。

上表六类都是**镜间**手段。跨越时间的切换还要先判断这次的跨越该不该发生在**同一个镜头内**（色彩与质感演变、调度隐藏），以及嵌套进入画面、固定机位时态叠化这两条跨时空专有手段——见 [跨时空转场](31-cross-time-transition.md)。

## 二、物件媒介必须参与叙事

物件只有满足至少一项才值得做转场锚点：推动因果、提示下一场信息、承载人物选择、建立时间/地点联系，或形成有意义的反差。不能为了“电影感”临时添加杯子、门框、烟雾或摆件。

检查物件的身份、位置、持有者、运动方向与末态。跨时空匹配允许物件发生变化，但观众应能辨认被保留的形状、运动、声音或语义关系。若匹配依赖精确首尾帧，导演稿给出构图规范，实际结果留到生成后或后期剪辑校准。

## 三、节奏与声音

- 转场时长由信息读取、运动距离、情绪停留和目标模型稳定性决定，不固定为 1–2 秒。快节奏也要给观众认出锚点的时间。
- 高潮可以缩短铺垫或改硬切，但不能切掉动作因果、关键反馈或对白。
- 卡鼓点只在已确认使用配乐且节拍承担结构作用时采用。也可以由脚步、关门、铃声、呼吸、环境声或对白形成声音桥。
- 胶片颗粒、运动模糊、浅景深、青橙调和低饱和属于质感与调色选择，不是转场成立条件；不能用模糊遮盖主体或连续性错误。

声音桥按 [音频、对白与物理声响](15-audio-and-lipsync.md) 保持声源、时间线和口型归属。原文没有音乐时不为“卡点”擅自添加音乐。

## 四、AI 生成落地

场景、时间或人物身份发生明显变化时，优先分别生成镜头 A 与 B，再在剪辑中完成切换。只有目标模型能力已经核验且变化本身必须连续可见时，才把复杂时空变换写进单次生成。

跨生成组的接缝（同一连续场次被拆成多次生成）是另一层问题：两次生成之间没有记忆，末态、机位与空镜过渡按 [跨生成组的接缝](30-segment-joining.md) 单独处理。

导演稿按以下结构记录，不把括号内容机械复制进提示词：

```text
镜头 A 结束：主体/物件的动作阶段、画面位置、运动方向、声音与末帧锚点。
切换机制：硬切 / 动作匹配 / 图形或物件匹配 / 遮挡 / 声音桥 / 溶解；触发时点。
镜头 B 开始：对应的首帧锚点、动作进度、画内外声音和首先新增的信息。
```

生成提示词只写各镜可见、可听的内容；剪辑说明留在镜头间的转场字段。诸如“电影感转场”“大师运镜”“自然丝滑”不能替代两端锚点和切点。

## 五、复核

- [ ] 已判断同场切镜、场次边界还是序列/大段落边界，没有把所有切镜都叫转场
- [ ] 已检查空间、时间与叙事任务是否要求观众重新定位；连续调度能讲清时没有强加切换
- [ ] 已明确本次更重连贯、分隔或两者兼顾，手段与边界任务一致
- [ ] 已区分镜内揭示与真实切镜，每次真实切镜独立编号
- [ ] 转场服务信息、因果、情绪或时空变化，不是装饰性运动
- [ ] A 末帧与 B 首帧的匹配依据可见或可听
- [ ] 动作阶段、运动方向、物件状态和声音时间线连续
- [ ] 前景简洁但有场景依据，不为转场凭空增加道具
- [ ] 时长足以认出锚点，且没有拖慢当前节奏
- [ ] 配乐、颗粒、模糊、色调和浅景深均按项目需要选择，未与转场捆绑
