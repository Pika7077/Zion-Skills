# 主观性与 POV：视点作为叙事手段

[镜头语言](camera-vocabulary.md) 里的“主观视角”是**一个镜头**的观察关系选择；本档处理的是**一段**的主观性——让观众进入某人的感知、记忆或内在状态，并知道什么时候该出来。

POV 的运动写法（FPV、Handheld、Head Tracking、Snorricam）与主观/异质时空的色调 register 见 [摄影机与质感词库](13-camera-and-texture.md)。

## 一、两种主观

| 类型 | 观众的位置 | 手段 |
|---|---|---|
| 视点主观（POV） | 观众就是某人的眼睛 | 摄影机取代人物；这个人物不出现在画面里 |
| 心理主观 | 观众进入某人的内在状态 | 梦境、幻觉、记忆变形、不可靠叙述 |

两者可以叠加：一个 POV 段落里出现幻觉，观众既在他的眼睛里，也在他的错觉里。

## 二、POV 段落

### 2.1 建立与解除

- **进入**：先给一个视线来源——人物看向某处，或人物入画后镜头转向他所看的方向。让观众知道这是谁的眼睛。
- **保持**：整段不出现这个人物。他一出现，视点就破了（用镜面、反光、影子是允许的中介）。
- **解除**：切到能看到这个人物的镜头，或让他入画。
- **判据**：观众在任何时刻都应该能说出“这是谁在看”。说不出来就是视点漂移——比破功更常见，也更难察觉。

### 2.2 在场感（防悬浮）

POV 最容易读成“无人机飘”，因为缺了身体的在场。三样东西缺一不可：

| 要素 | 写法 |
|---|---|
| 呼吸起伏 | 画面随呼吸有极缓的起伏；紧张时变快变浅，屏息时静止 |
| 脚步与身体节奏 | 移动时有落点的顿挫，转身时有重心的转移与滞后 |
| 手持的轻微不稳 | 幅度小，**有来源**（呼吸、脚步、重心），不是随机晃动 |

- **只写“加抖动”不行**：没有来源的抖动会变成随机乱晃与画面变形。要写出抖动由什么产生。
- 静止时 POV 也有微动（呼吸、心跳、视线的微调）。完全静止会读成固定机位，而不是人的眼睛。

### 2.3 人称选择

| 人称 | 效果 | 适合 |
|---|---|---|
| 第一人称（我） | 沉浸、共感 | 回忆、体验、跟随 |
| 第二人称（你） | 引导、被指向、压迫 | 惊悚、恐怖、指令式叙述 |

第二人称的用法是让画外声以“你”称呼观众，把观众从旁观者变成被叙述者。它的力量来自被指向，用多了会变成说教。

同一段里人称要稳定；需要切换时要有叙事理由（例如从“你”回到“我”，表示人物重新夺回了自己）。

### 2.4 声音在 POV 里的优先次序

POV 的在场感主要由声音承载，次序与常规段落不同：

1. **身体声**——呼吸、心跳、吞咽、脚步（最近、最先）
2. **与身体接触的环境声**——雨打在伞上、手碰到的物件、衣料摩擦
3. 环境底噪
4. 配乐（最后）

常规段落里对白优先（见 [音频与对白](15-audio-and-lipsync.md)）；POV 段落里身体声的在场感优先于对白，对白此时听起来应当像“从外面传进来的”。

### 2.5 瑕疵真实感

轻微的不完美反而增强在场：对焦的迟疑、曝光的轻微滞后、画面边缘的轻微模糊、非匀速的转头。

纪律：瑕疵要**有来源且幅度小**。刻意制造的大量瑕疵会读成制作事故，而不是真实感。这条与 [视频提示词卫生](12-prompt-hygiene.md) 的具象判据不冲突——瑕疵也是可写出来的可见事实。

### 2.6 构图与写法

**身体局部要入画。** 在场感不只来自运动（§2.2），也来自构图：画面里必须有属于这个人的东西——手、手臂、脚、肩、正在操作的物件。只有环境、没有任何身体局部，观众读到的是一台漂在空中的摄影机，而不是一个人的眼睛。

| 局部 | 用在 |
|---|---|
| 手与手臂 | 操作、触碰、拿取、推开 |
| 脚与腿 | 行走、奔跑、站立位置 |
| 肩与衣料边缘 | 转头、呼吸、被靠近 |
| 手中的物件 | 递出、握紧、打开 |

身体局部在画面里的**位置要稳定**（手在下缘、肩在一侧），不要一会儿出现在画面中央一会儿消失——位置跳动会破坏“这是一个人的身体”的感觉。

**提示词写法。** 按可见事实写，不靠术语：

```text
第一人称视点：画面下缘可见我的双手（或手中的物件），镜头高度接近站立者视线，
{我在做什么}，{看到什么}，视角随头部转动。
```

- 组织顺序：**视点声明 → 身体局部 → 动作 → 看到的景象 → 风格与氛围**。
- **不要依赖“POV”“第一人称”这类术语被模型识别。** 能识别是加分，识别不了要靠可见事实兜底——所以那四条可见事实（视点声明、身体局部在画面、人眼高度、视角随头动）比一个术语可靠。
- 术语是否有效按实际入口验证；本档不宣称任何词必然生效（与 [视频提示词卫生](12-prompt-hygiene.md) 一致）。

**情感物。** POV 最适合让一件日常物件承载情绪：一份皱了的病历、一张磨白的车票、一个打火机。它随时间变化——边角磨损、字迹变淡、表面划痕增加——不用台词就说明了过了多久、人物经历了什么。

用法：让这件物件**反复出现在 POV 里**，每次状态不同。它与 [视觉母题与呼应](24-visual-motifs.md) 是同一种手法，但载体更小、更私人：母题是作品级的呼应，情感物是人物级的细节。

**与客观镜头交替。** 整段都是 POV 会累，也交代不了人物的表情与处境。交替有两种用法：

- **对话场**：过肩建立两人的位置，切 POV 让观众“成为”其中一方。压力来自被看与被说的位置差，交替会让对话显得更逼近、更暧昧。
- **动作与追逐**：POV 推进，穿插客观镜头交代位置与威胁——观众需要知道他在哪、威胁在哪。

POV 段落不宜过长，“我在看”的感觉会疲劳；交替是让视点有呼吸。

### 2.7 段落的节奏：先建立常态

悬念与惊悚类 POV 的常用结构是**先建立常态，再打破**。

- 常态要有足够时长让观众安顿下来。常态越稳，打破时的落差越大。
- 打破要给出可见依据（声音、光线、物件位置的变化），不能靠镜头突然乱晃来代替事件。
- 与 `zion-script` 的故事设计档（张力分布）、[三步引导法](27-guidance-three-steps.md) 的期待节奏衔接。

### 2.8 AI 生成下的 POV

- **优势**：摄影机就是人物的眼睛，主体不出现在画面——**不依赖人脸一致性**，正好绕开生成最不稳的部分。
- **代价**：手上动作、身体局部若入画，仍然要按资产一致性要求管（见 `zion-assets` 的资产一致性档）。
- 手持抖动必须写成有来源的可见运动；只写“抖动”容易得到随机晃动。
- 一段 POV 通常整段生成；跨镜的 POV 段落要保证视线方向、空间关系与光源一致（见 [光影系统](20-lighting-system.md) 的跨镜继承）。

## 三、客观与主观的组合：为叙事选视角

客观镜头与主观镜头各有任务，组合的依据是**这一段要让观众获得什么**，不是拍法要轮换。

| 视角 | 给观众什么 | 常见用途 |
|---|---|---|
| 客观 | 世界与事实：空间规模、人物位置、处境、结果 | 交代环境、建立关系、给出事实与结果 |
| 主观 | 某人的感知与情绪 | 让观众进入他的位置、承受他的注意力落点 |

**每一处切换都要能说出观众获得了什么。** 说不出来就是轮换拍法。

**机械套用的症状**：客观交代 → 主观反应 → 客观 → 主观……按固定节奏交替，与内容无关。观众读到的是“镜头一直在换拍法”，而不是“我正处在这个人所在的处境里”——后者才是主观视角的用处。

### 3.1 三种组合任务

| 任务 | 组合方式 | 观众读到 |
|---|---|---|
| **建立关系张力** | 两人互相注视时，用互相的主观或过肩内反拍，让双方都“被看” | 他们在关注彼此——这次相遇不是偶然路过 |
| **强调被环境压住** | 先给客观的环境（规模、净空、人群、延长的空镜），再切人物主观 | 先感到空间在压人，再感到人怎么承受 |
| **揭晓关联** | 主观段之后切回客观，让观众看见两人、人或物的位置关系 | 之前的张力有了来源 |

三种任务都能写成一句话；写不出来的交替就不要交替。

### 3.2 顺序：先建立可感的场域，再用视角进入

先客观建立一个能被感到的空间（规模、压迫、路径、人群密度），再用主观把观众放进去。顺序反了会怎样：

- **先给主观**：观众还不知道自己在哪，进入感落空——观众进入一个不认识的空间，只能看见零碎局部。
- **只给客观**：观众知道在哪，但全程旁观，没被放进去。

空间如何承担情绪（净空与体量、密度与朝向、遮挡与开口）见 [画面内容设计](visual-storytelling.md) §三。**延长环境镜是把压迫感铺开的手段，不是空镜凑时长**——它必须持续新增空间信息（更窄、更深、更无处可退），否则只是拖。

### 3.3 与 §二 的分工

本节管**何时用哪种视角、为什么用**；一段 POV 怎么建立与解除、在场感、人称、声音次序、构图与身体局部，见 §二。一段 POV 是否成立由 §二 判，该不该切由本节判。

## 四、主观性状态

### 3.1 建立：让观众知道这是主观

观众必须能分辨“真实发生的”与“人物以为或梦见的”。三种标记：

| 标记 | 做法 |
|---|---|
| 进入的物理触发 | 闭眼与睁眼、倒地、水没过头顶、光的骤变、被击晕 |
| 视觉基线偏移 | 色调、质感、锐度、运动表现与主叙事不同（register 见 [摄影机与质感词库](13-camera-and-texture.md)） |
| 逻辑越界 | 出现主叙事不可能有的元素，或时空跳接不讲道理 |

- 至少用一种。用两种以上时要有主次，三样全堆会读成花哨而不是主观。
- **标记要在片内稳定**：“这部片里的梦境长什么样”应当固定，不能每次不同——否则观众无法建立识别。

梦境与幻觉的**具体落地写法**（视觉标签的四种类别与优先级、内容该指向什么、抽离方式与节奏参考）见 [梦境与幻觉](35-dream-and-hallucination.md)。

### 3.2 解除：让观众知道回到了现实

- 触发物与进入呼应（睁开眼、被叫醒、被声音打断）。
- 视觉基线回到主叙事。
- **剧情要留下痕迹**：梦里的信息要么被证实、要么被推翻、要么成为人物的状态。什么都不留下的主观段落没有存在的理由。

### 3.3 记忆的主观变形

记忆不是回放。可信的做法是让记忆**有偏差**：细节模糊、时间错乱、环境虚化而面孔清晰，镜头选择性地只聚焦在当事人记得的部分。

判据：这段记忆若与后来揭示的事实不符，观众是否会觉得合理？人本来就会记错——合理就成立，不合理就是穿帮。

### 3.4 不可靠叙述

观众后来发现自己被骗，但仍觉得公平。

- **公平的条件**：信息一直是真实的，只是不完整——与 [层次感](28-layered-depth.md) 的“藏信息但不骗”同源。
- 允许的手法：视点局限（人物没看到关键部分）、主观确信（人物确信一件错事）、省略与延迟。
- **不允许**：画面直接展示与事实相反的内容并让观众当真。那是欺骗，不是引导。
- 兑现：真相揭示时，前文每一处误导都应该能被重新解释通。解释不通的就不该放在那里。

## 五、复核

- [ ] 观众在任何时刻都能说出“这是谁在看”
- [ ] POV 有呼吸、脚步、重心三样在场感来源，抖动写明了来源
- [ ] 人称稳定；第二人称的使用有叙事理由
- [ ] 声音次序里身体声与接触声在最前，配乐最后
- [ ] 瑕疵有来源且幅度小，未读成制作事故
- [ ] 常态建立得够稳，打破有可见依据
- [ ] 主观状态的进入与解除都有标记，且标记在片内稳定
- [ ] 主观段落留下了剧情痕迹
- [ ] 不可靠叙述的信息真实但不完整；揭示后前文能重新解释通
- [ ] POV 段落的主体未入画；入画的身体局部仍受资产一致性约束
- [ ] 画面上有属于这个人的身体局部（手、脚、肩或手中物件），且位置稳定
- [ ] 提示词按可见事实写（视点声明／身体局部／人眼高度／视角随头动），未只依赖术语
- [ ] POV 与客观镜头有交替，段落没有长到让观众疲劳
- [ ] 每一处客观↔主观的切换都能说出观众获得了什么；没有与内容无关的机械交替
- [ ] 需要关系张力时用了互相的主观或过肩内反拍，观众读得到“他们在关注彼此”
- [ ] 先建立了可感的客观场域再切主观；没有出现“观众还不知道自己在哪就被放进某人眼睛”
- [ ] 延长环境镜持续新增空间信息（更窄／更深／更无处可退），不是在凑时长
- [ ] 主观段之后切回客观时，观众能看见张力或关联的来源
- [ ] 需要承载情绪时用了情感物，且它的状态随剧情变化
