# 层次感：四个维度的破平衡

画面扁平不是因为素材差，而是因为**缺少层次**。层次感的本质是**破平衡**——空间破平面、光线破单调、颜色破融合、表演与叙事破直白。

四层各管一件不同的事，逐层做法分别落在既有档，不在此重复；本档只补各档未覆盖的分离、渐变与藏信息手法：

| 维度 | 破什么 | 做法落在哪 |
|---|---|---|
| 空间 | 平面 | 本档 §一 + [camera-vocabulary.md](camera-vocabulary.md) 构图与景深、[21-relationship-composition.md](21-relationship-composition.md) §三 站位分区 |
| 光线 | 单调 | 本档 §二 + [20-lighting-system.md](20-lighting-system.md) §五、§七 |
| 颜色 | 融合 | 本档 §三 + [23-color-and-tone.md](23-color-and-tone.md) §一、[13-camera-and-texture.md](13-camera-and-texture.md) §六 |
| 表演与叙事 | 直白 | 本档 §四 + [visual-storytelling.md](visual-storytelling.md) §三、[27-guidance-three-steps.md](27-guidance-three-steps.md) |

**四层不必同时用满。** 每镜选 1–2 层真正服务的即可；把所有层次一次堆齐，结果是把画面塞满而不是加深。判据始终是**叙事与情感**，不是层次数量。

## 一、空间层次（基础）

平面感的根源是**没有纵深**：主体贴在背景上，前中后景不存在。四种做法：

| 做法 | 具体方式 | 注意 |
|---|---|---|
| **前景介入** | 镜头前加道具、透过门窗拍摄、以树影／栏杆／人群作前景 | 前景不挡关键动作（[camera-vocabulary.md](camera-vocabulary.md) 前景遮挡） |
| **拉开主体与背景** | 让主体远离背景，中间留出人、物或空间过渡 | 需要可用的景深或空间尺度 |
| **光影分离** | 用亮度差把主体从背景里切出来：前亮后暗 / 前暗后亮 | 见 §二，这是最省成本的一种 |
| **偷空间** | 局促环境里用窗、镜、门缝、走廊、反射延伸视觉 | 延伸必须有现实依据，不能凭空扩空间 |

**偷空间的三种常用载体**：

- **窗**：窗外若有可辨层次（街、树、另一栋楼），画面深度立刻翻倍。
- **镜／反光面**：把镜头外的空间折进画面（同 [27-guidance-three-steps.md](27-guidance-three-steps.md) §二 的中景介质）。
- **门缝／通道**：透过狭缝看到远处，纵向空间被拉长。

**判定**：遮住画面的一半再问——如果剩下的部分完全读不出"人物在什么空间里"，说明纵深只靠装饰，不靠结构。

## 二、光线层次（核心）

**平光是扁平的直接原因。** 均匀打亮会把立体结构抹平成色块。三类做法：

### 2.1 明暗对比塑形

用亮暗差建立体积：主体亮、背景暗（最常见的分离方式），或反过来做剪影反差。

| 方向 | 效果 | 适用 |
|---|---|---|
| **前亮后暗** | 主体从暗背景里浮出，最稳的分离方式 | 通用；对话、特写、任何需要主体可读的镜头 |
| **前暗后亮** | 主体成为剪影或半剪影，姿态与轮廓承担信息 | 登场、神秘、逆光揭示、需要牺牲面部时 |
| **侧向分离** | 主光从侧后方来，勾出边缘光把主体从背景切出 | 暗背景 + 深色服装时的必用手段 |

**纪律**：反差是手段不是目的。**需要读表情时不得只给高反差而不说明暗部保留到哪一层**（沿用 [20-lighting-system.md](20-lighting-system.md) §三 的暗部保留层级）。

### 2.2 渐变光替代均匀打亮

均匀打亮＝无信息。渐变光让画面内的亮度**有走向**，本身就携带"光从哪来"的信息。

| 渐变类型 | 做法 | 效果 |
|---|---|---|
| **自然光渐变** | 日落柔光、窗光斜切、黄金时刻的暖调过渡 | 氛围、时间感 |
| **方向渐变** | 画面一侧亮、另一侧暗，亮度沿一个方向递减 | 视线引导、空间纵深 |
| **介质渐变** | 纱窗、百叶、格栅、树影、水波把光切成有纹理的过渡 | 质感与节奏感 |
| **距离渐变** | 近处亮、远处暗（或反向），靠衰减自然形成 | 纵深 |

**关键**：渐变要交代**光源方向**，否则读者只看到"脏"。纱窗渐变打亮之所以有效，是因为它同时说明了光的来源和它经过的介质。

### 2.3 与已有布光表的衔接

[20-lighting-system.md](20-lighting-system.md) §七 的 18 项技术管**光的性质与位置**（硬软、衰减、动机、时序）；本节补的是**主体与背景之间的亮度关系**，以及**亮度在画面内的走向**——两项都不在那 18 项里，但都由同一套布光落地。

## 三、颜色层次（视觉焦点）

颜色的作用是**抠出主体**——在色彩上把主体与背景分开，而不是统一刷一层滤镜。

### 3.1 三种分离手段

| 手段 | 做法 | 注意 |
|---|---|---|
| **冷暖分离** | 暖主体 + 冷背景，或反向 | 必须定主次（[23-color-and-tone.md](23-color-and-tone.md) §一 冷暖对比色） |
| **互补色分离** | 橙青、红绿等互补对撞 | 靠分区不做中间色过渡；避免两色均匀混合成灰 |
| **饱和度分离** | 主体高饱和 + 背景低饱和，或反向 | 反向（主体低饱和、环境高饱和）用于"人被环境吞没" |

**色相数量要克制**：一镜内色相过多，主体就失去唯一性（见 [23-color-and-tone.md](23-color-and-tone.md) §一 高饱和的常见误用）。

### 3.2 亮度与饱和度的渐变

与 §二 的光线渐变同源，但作用在**颜色属性**上：

- **亮度渐变**：背景从一角向另一角逐步变暗或变亮，主体落在最亮（或最暗）的位置。
- **饱和度渐变**：背景饱和度沿画面递减，主体所在区域饱和度最高。
- **纱窗／格栅渐变打亮**：光与色同时渐变，一次建立纵深、方向与焦点。

**与色调一致性的边界**：本节讲的是**同一场次内部**的层次变化，不违反 [23-color-and-tone.md](23-color-and-tone.md) §二 的色调一致性。同一色系与影调档内，颜色仍有明暗与浓度的空间走向——**那是层次，不是漂移**。

**纪律**：颜色层次不能让主体脱离本场已确认的色系与影调档。想要更亮的主体，是在既定影调档内提高主体与背景的差，不是给主体单独换一套色彩。

## 四、表演与叙事层次（内核）

前三维决定画面好不好看，这一维决定作品有没有深度。

### 4.1 表演：复合情绪

**避免"咆哮式"表演**——单一情绪拉满，观众只接收到音量，接收不到内心。

复合情绪是两种以上同时存在的情绪：笑中带泪、愤怒里的无力、平静下的崩溃、亲密中的试探。

| 写法 | 落地方式 |
|---|---|
| **两层并存** | 表层动作（笑、点头、接住杯子）与底层状态（手停半拍、视线落空、呼吸变化）同时给 |
| **转折在镜内** | 情绪在同一镜内从 A 走到 B，镜头时长要够读到转折过程 |
| **压抑优于爆发** | 把情绪压住，让观众自己读出，比直接演出来更有力 |

**纪律**：复合情绪**必须在画面里可见**，不能只在"镜头目的"栏写"内心矛盾"。落到具体的可见载体：手、视线、呼吸、节奏的快慢、动作的完成度。

### 4.2 叙事：藏信息

信息不要一次交完。像剥洋葱，一层一层给——每揭示一层，观众对前一层产生新理解。

**三种藏法**：

| 手法 | 做法 | 涉及档 |
|---|---|---|
| **预埋** | 关系与危险暗示在事件之前给出 | [27-guidance-three-steps.md](27-guidance-three-steps.md) §三 |
| **延迟** | 用新悬念替换旧悬念，而不是拖时间 | 同上 §二 |
| **解读反转** | 同一件事在后文被赋予新含义（同素材不同理解） | [24-visual-motifs.md](24-visual-motifs.md) 复现四手法 |

**纪律**：藏不等于骗。**给出的信息都必须是真实的，只是暂不完整。** 用假信息制造反转，观众复看时会发现被欺骗，而不是发现被引导——两者的差别是作品的深度来源。

### 4.3 节奏：钩子 → 论据 → 共情

场次内部的节奏起伏，与全片结构同源（全片首尾见 [25-opening-and-ending.md](25-opening-and-ending.md)；场次三步自检见 [27-guidance-three-steps.md](27-guidance-three-steps.md)）：

```text
开头钩子：给一个让人想知道的问题（异常、悬念、强关系）
中间论据：用可见的事件推进，每一拍新增信息，不原地复述
结尾共情：落在一个情绪点上，让观众读到的不是"事情结束了"，而是"这意味着什么"
```

**判定**：如果结尾只剩"事情结束了"，说明中间与结尾都在交付信息，没有建立情感。

## 五、四维自检表

| 维度 | 检查 |
|---|---|
| **空间** | 画面有可辨认的前景、主体、背景吗？ |
| | 遮住一半后，人物所处的空间还读得出来吗？ |
| | 主体是否贴在背景上（间距不足、无过渡）？ |
| | 局促环境是否已用窗／镜／门缝延伸空间？ |
| | 前景有没有挡住关键动作？ |
| **光线** | 主体与背景的亮度关系是什么（前亮后暗／前暗后亮／侧向分离）？ |
| | 是否存在均匀打亮（平光）？ |
| | 亮度在画面内有走向（渐变）还是平的？ |
| | 渐变有没有交代光源方向与介质？ |
| | 需要读表情时，是否说明了暗部保留到哪一层？ |
| **颜色** | 主体是靠什么与背景分开的（冷暖／互补／饱和度）？ |
| | 冷暖或互补时，主次是否写明？ |
| | 一镜内色相是否过多，主体失去唯一性？ |
| | 颜色层次是否仍在既有色系与影调档内（未给主体单独换色彩）？ |
| **表演与叙事** | 表演是单一情绪拉满，还是复合情绪？ |
| | 复合情绪是否有可见载体（手、视线、呼吸、节奏）？ |
| | 本场是否把信息一次交完？有没有预埋与延迟？ |
| | 给出的信息是否真实（只是不完整），没有靠假信息制造反转？ |
| | 结尾落点停在情绪上，还是只停在"事情结束"？ |

## 六、常见失败与修复

| 失败 | 症状 | 修复 |
|---|---|---|
| 主体贴背景 | 人物像贴纸 | 拉开距离或加前景；用前亮后暗做分离 |
| 平光 | 脸平、无体积 | 改侧向或前侧 45° 主光，加明暗对比 |
| 全画面一起提亮 | 亮而扁 | 改用渐变光，保留暗部与亮度走向 |
| 局促空间拍死 | 没有纵深，像盒子 | 借窗、镜、门缝偷空间 |
| 颜色平均 | 冷暖各半成灰 | 定主次，两色分区 |
| 色彩数量失控 | 杂、廉价 | 色相收敛，主体守唯一性 |
| 咆哮式表演 | 情绪拉满但读不到内心 | 改复合情绪，给可见载体 |
| 信息一次交完 | 后面靠反转硬拗 | 补预埋与延迟；反转依赖前文真实信息 |
| 层次堆满 | 画面塞满但观众累 | 每镜只留 1–2 层真正服务的 |

## 七、适用范围

- **必用**：画面扁平、平淡、缺立体感、观众反馈"像纪录片式记录"时。
- **优先**：悬疑、情感、文艺类需要"深度"观感的场次。
- **注意**：动作高潮段落以可读性为先，层次不足时优先保动作清晰，不为了层次牺牲因果（见 [action-choreography-rules.md](action-choreography-rules.md)）。

四层是**自检维度，不是输出字段**。除用户明确要求，不把四层写成交付物里的四个标题。
