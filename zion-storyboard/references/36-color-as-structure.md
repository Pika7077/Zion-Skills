# 色彩的结构功能：象征、对比与色彩脚本

[色彩与影调](23-color-and-tone.md) 管的是**色彩是什么**（色系与影调档的分类）与**怎么保持一致**（同场次统一、跨场切换要有触发、弧线与状态表）。本档管的是另一层：**色彩怎么承担含义与结构**——象征、对比，以及用色彩组织叙事本身。

分层：

| 层 | 管什么 | 去哪找 |
|---|---|---|
| 氛围层 | 给这场戏一个情绪基调 | [色彩与影调](23-color-and-tone.md) 的色系与影调档 |
| 结构层 | 色彩承担象征、区分时空与视角、组织全片走向 | 本档 |

## 一、色彩的含义由作品自己建立

同一个颜色在不同作品、不同文化里含义不同：

- 红可以是情欲与亲密（一个人穿着红走过狭窄的走廊），也可以是警示与罪恶（黑白画面里唯一的那一件红衣）
- 绿可以是自然与生机，也可以是系统与虚拟（屏幕般的冷绿）
- 蓝可以是沉静，也可以是病态的冷（日光灯下的冷蓝）

所以：

- **不要套用固定的色义表。** 把“红代表危险”“蓝代表忧郁”当作通用规则，会写出与故事无关的色彩——观众看到的只是流行配色，不是含义。
- **含义靠反复绑定建立。** 先让某个颜色与某个处境在本片里反复同现，它才在这个作品里获得含义；之后每一次出现都会带上这个含义。
- **判据**：能不能说出这个颜色**在本片里**为什么是这个含义？说不出来，它就只是装饰。
- **文化语境要考虑。** 同一个颜色在不同地域与时代的观众那里读法不同。象征性越强的用法，跨文化投放时越要谨慎；不确定时用描述性说法（“这个颜色属于这个人物”），不用断言式象征（“红＝危险”）。

## 二、互补色对：把主体从背景里分出来

色环上对立的一对颜色并置，分离感最强：

| 对子 | 常见用法 |
|---|---|
| 蓝 / 橙 | 暖肤色与冷背景分离主体，类型片常用 |
| 红 / 绿 | 让少量的一方跳出来（背景红、主体绿，或反之） |
| 黄 / 紫 | 强反差、风格化段落 |

纪律：

- **一对就够。** 一镜内同时用两三对互补，会平均成灰，等于没有对比。
- **明确主次**：谁承担主体、谁承担环境。
- 与“冷暖对比”色系的关系：冷暖对比是**阵营级**的大区域对立；互补色对是**具体两个颜色**的对立。两者可以嵌套（大阵营冷，其中主体用一个小面积的暖）。
- 主体与背景分离还有另外两条路（亮度分离、饱和度分离），见 [层次感](28-layered-depth.md)；一镜挑一条做到位即可。
- 互补是**分离手段**；同一对颜色往哪个情绪方向走（危险包围、孤独专注、浪漫或神秘），由面积主次、明暗深浅与光源来源决定，见 §三。

## 三、同一配色的情绪由变量决定

同一对颜色、同一套色系，只要改动下面三个变量，情绪指向就会换向。这是 §一「不套色义表」在操作层的含义：**色相只是材料，方向由变量决定**。

| 变量 | 怎么改 | 换向效果 |
|---|---|---|
| **面积主次与归属** | 谁占大面积；小面积的那一块是**被看的主体**，还是**包围他的环境** | 同一对冷暖：冷占满环境、暖只出现在远处或他人身上 → 被包围的压迫感；冷占环境、暖只落在人物自己身上（皮肤、手边光源） → 孤独中的专注 |
| **明暗与饱和深浅** | 提亮并柔化，还是压暗并加饱和 | 红绿提亮柔光 → 俏皮、浪漫、童话；压暗加饱和 → 秘密、危险。黄紫偏浅偏亮 → 浪漫梦幻；偏深偏暗 → 未知、神秘 |
| **光源来源与分布** | 环境铺光，还是画内有依据的实用光、单点局部光 | 有实用光依据的局部色块会直接成为视线落点，指向具体的人或物；纯环境色的情绪更接近氛围，少指向具体对象 |

| 配色类型 | 冲撞强度 | 常用方向 |
|---|---|---|
| 互补色对（青橙／红绿／黄紫） | 最强，分离与对立都强 | 危险与对立、风格化段落；两色各占一半会互相抵消，必须有主次（见 §二） |
| 邻近色（如黄绿） | 弱，画面内部冲撞少 | 情绪主要由**光质与影调**决定：柔光＋偏亮 → 成长、回忆、暖意；压暗＋低明度 → 沉闷、压抑、停滞 |
| 单色主导（一个颜色覆盖画面） | 无——没有第二个色相可冲撞 | 层次只能靠**明暗**建立：拉开明暗比、留硬阴影 → 冷硬、压迫；低对比、大面积灰面 → 荒凉的陌生感 |

纪律：

- **方向参考不等于色义表。** 上表说的是“改动变量会把读法推向哪边”，不是“青橙＝危险”。这个颜色在本片里究竟什么意思，仍按 §一 靠反复绑定建立。
- **一镜只改一个变量。** 面积、明暗、光源同时大幅改动，方向会互相抵消，也说不清这一镜为什么是这个色。
- **判据**：能不能说出“改掉哪一个变量，这场会读成另一种情绪”？说不出，说明配色是随手挑的，不是设计。
- 与 [层次感](28-layered-depth.md) 的亮度／饱和度分离配合时，先定这一镜要的是**分离主体**还是**换向情绪**，同一镜不必两件事都做。

## 四、色彩承担结构功能

色彩可以标记叙事结构本身，而不只是情绪：

| 功能 | 做法 |
|---|---|
| 区分时空线 | 两条时间线各用一套色，观众一眼知道自己在哪条线上（现在冷、过去暖） |
| 区分叙述版本 | 同一事件的不同说法各用一种主导色 |
| 区分主观状态 | 现实与梦境、回忆的色系不同 |
| 标记段落 | 用色调切换做分幕或分集的分界 |

纪律：

- **一色一义。** 同一套颜色不要承担两种结构功能，观众会读混。
- **色彩只作辅助。** 色调在生成里最容易漂移，时空与视角的判定要靠实体锚点（服装、器物、环境状态）兜底——见 [跨时空转场](31-cross-time-transition.md) 与 [主观性与 POV](33-subjectivity-and-pov.md)。
- 与视觉母题的关系：母题是“重复出现并承载含义的元素”，用颜色做母题是其中一种（见 [视觉母题与呼应](24-visual-motifs.md)）。

## 五、色彩脚本

**在开工之前，把每一场（或每一幕）的色彩走向排出来**，形成一张逐场的色彩设计表。

每场记录：色系、影调档、主光色温、强调色，以及它与前一场的关系（延续、收紧、放开、对撞）。

- 作用：让全片色彩有预设的走向，而不是逐场临时决定。
- 与 [色彩与影调](23-color-and-tone.md) 的衔接：**色彩脚本是全片弧线的展开形式**，色调状态表是它的登记形式。
- 最小可用形态就是一行一场：`场次 | 色系 | 影调档 | 强调色 | 一句话说明这场为什么是这个色`。
- 判据：把色彩脚本按顺序读一遍，**能不能看出走向**（收紧、放开、渐变、对撞）？看不出，说明它只是逐场的独立选择，不是脚本。

## 六、前期与后期的分工

**前期（设计）**

- 色彩脚本。
- 美术与场景：材质、光源色温、显著色块的分布。
- **服装色彩**：人物穿的颜色是他随身携带的色彩标签，会进入每一镜。主角的常服颜色要有意选择，不要默认。

**后期（调色与处理）**

- 统一色调：让全片像出自同一套设定。
- 局部处理：提亮眼神、压暗背景引导焦点、提高关键物件的饱和度。
- 风格化：整段单色化、抽色（只保留某一色相）等。

纪律：**局部处理改的是主次关系，不是给主体换一套色彩**——给主体单独换色违反 [色彩与影调](23-color-and-tone.md) 的场次一致性。具体调色词与预设取 [摄影机与质感词库](13-camera-and-texture.md) §六。

## 七、复核

- [ ] 每个有含义的颜色都能说出它在本片里为什么是这个含义
- [ ] 没有套用通用色义表；不确定处用了描述性说法而非断言式象征
- [ ] 互补色对只用了必要的一对，且主次清楚
- [ ] 情绪方向由变量定：能说出改掉面积主次、明暗深浅或光源来源中的哪一个，这一场会读成另一种情绪
- [ ] 邻近色或单色主导时，情绪方向写明了是靠光质与影调（而非色相本身）实现的
- [ ] 色彩承担的结构功能做到一色一义，没有一色两用
- [ ] 色彩只作辅助锚点，时空与视角的判定有实体依据兜底
- [ ] 色彩脚本按顺序读得出走向
- [ ] 主角的常服颜色是有意选择的
- [ ] 局部处理改的是主次关系，没有给主体单独换色
