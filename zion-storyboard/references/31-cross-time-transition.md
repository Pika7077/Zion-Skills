# 跨时空转场：镜内与镜间两族

本档处理**跨越时间（或同时跨越时间与空间）的那一刀**。手段的图式与两端锚点规则见 [剪辑与转场](22-editing-and-transitions.md)；本档只补它没有的一个分类维度——**这次跨越是在同一个镜头里完成的，还是切到另一个镜头、在后期完成的**——以及跨时空特有的锚点与可生成性问题。

跨时空切换通常同时跨生成组，接缝的末态与机位规则一并遵 [跨生成组的接缝](30-segment-joining.md)。

## 一、先定两件事

**第一，这次跨越是哪一种时间关系。**

| 类型 | 特征 | 对转场的要求 |
|---|---|---|
| 时间跳跃 | 同一条时间线上向前或向后跳过一段（几年后、三天前） | 交代跳过了多久、期间发生了什么；观众不需要同时记住两个时代 |
| 双线并行 | 现在与另一时段（回忆、往事）来回切换，两条线互相解释 | 两条线各自要有稳定的视觉基线，观众随时知道自己在哪条线上 |
| 时间倒错 | 叙述顺序与事件顺序不一致（倒叙、插叙） | 观众必须能建立正确的事件顺序，否则读成混乱 |

**第二，观众是否需要被告知这是一次切换。**

- 需要提示：故事要观众保持"两条线在对照"（回忆与现实互相映照、今昔反差）——用可辨识的手段，让切换被看见。
- 不需要提示：故事只要观众沉浸（一次漫长的时间流逝、一段被省略的过程）——用隐藏手段，让观众事后才意识到跨过去了。

这条决定了后面选哪一族。**不要两头都要**：既想切换被看见、又想毫无痕迹，结果通常是切换不清不楚。

## 二、镜内族：同一镜头内完成跨越

镜头没有断，跨越发生在运动过程中。

| 手段 | 做法 | 必写项 |
|---|---|---|
| 色彩与质感演变 | 同一镜头内，色彩、颗粒、锐度随运动从一种时代感变为另一种 | 变化的触发物（光线变化、镜头推进、回忆进入）；起始与落幅两套色彩与质感设定；变化发生的时刻与速度 |
| 调度隐藏 | 摄影机连续运动中，人物离场与入场、陈设与光源更换完成，镜头不断 | 摄影机路径与速度；每个人物出入画的时刻与方向；更换的要素清单；落幅停在哪个信息上 |
| 主观运动 | 以人物的主观视角运动（旋转、穿行、下坠）作为跨越载体 | 观众与人物视野的关系；运动结束后的时空与人物状态 |

镜内族的力量在于**空间连续性**：同一个位置、同一条动线，观众不会觉得被切断。代价是它必须把跨越"演"出来，所以路径、更换要素和落幅三样缺一不可。

**可生成性警示**：镜内在 AI 生成里是最高风险的一类——一次生成内要换布景、服装、光位与色彩。规划时按下面的分级处理，不要默认它可行。

## 三、镜间族：切到另一镜头

六类基本手段（声音桥、匹配、遮挡、溶解、因果、动作）的取舍、必写项与风险见 [剪辑与转场](22-editing-and-transitions.md)。跨时空用途下另有两条本条族特有的手段：

**嵌套 / 进入画面**：一个画面（旧照片、资料、屏幕、画作、监控）被放大、推进或替换，成为另一个时空的画面。也可以反向使用——现实画面收缩、退回为照片定格。

- 必写：被放大的画面内容；放大路径与落点（从画面的哪一部分进、停在哪）；进入后的时空、人物与场景；两层的比例关系与边缘处理。
- 它既不是匹配（不靠轮廓对应），也不是溶解（不靠亮度叠加），而是**画面成为另一个画面的载体**。因此不要用"高级转场"描述它，要写清进出关系。

**固定机位时态叠化**：机位与构图不动，同一位置的两种时态交叉溶解（夜晚的旧标牌叠化为白天的新布置）。

- 必写：机位与构图在两段中保持一致；同一位置上的对应物（同一个窗、同一张桌）；溶解时长；溶解过程中观众能读到的变化。
- 它比一般叠化更依赖机位一致，机位一变就退化成普通叠化。

## 四、锚点：让观众认出跨越

切换是否被读懂，取决于锚点。

| 锚点类型 | 例 |
|---|---|
| 实体锚点 | 服装、发型、器物形制、文字、车辆、工具 |
| 环境锚点 | 场景的老化与翻新、光源类型、天气与季节 |
| 色彩与质感锚点 | 色温阵营、颗粒、锐度、宽容度表现 |
| 声音锚点 | 环境底噪类型、音乐风格、语言与称呼方式 |
| 构图锚点（隐藏式） | 同构的构图、接续的动作、延续的声音 |

- **双线各自的视觉基线**：两条线如果共用同一套色彩与质感，观众就分不清在哪条线上。两条线要有稳定的差别，且差别在每次切换时都能复现。
- **明确时间点的手段**：需要观众准确知道"这是哪一年"时，用画面内的物证（日历、报纸、标牌、器物）而不是旁白。旁白定时间见 [音频与对白](15-audio-and-lipsync.md)，但画面能给的优先由画面给。
- 只靠色彩区分两条线是靠不住的——色彩在 AI 生成里最容易漂移。**色彩做辅助，实体锚点做判定。**

## 五、可生成性分级

| 风险 | 手段 | 落地方式 |
|---|---|---|
| 低 | 镜间切换（声音桥、匹配、遮挡、动作接续） | 两组分别生成，后期按切点剪接 |
| 中 | 固定机位叠化、嵌套 | 两组按同机位生成，后期溶解或缩放；机位一致是成败关键 |
| 高 | 镜内跨时空（色彩演变、调度隐藏） | 优先降级：镜内只做色彩与质感渐变，时空点移到运动遮挡处硬切；或把跨越点拆成两组分别在两个时代生成 |

生成提示词里只写各自镜头可见的内容，跨时空的说明留在镜头间字段。**不要在一段生成指令里要求两次时代变换**——模型会把两个时代混在同一画面里。

## 六、纪律

- 不把切镜伪装成一个连续镜头指令：真的发生了切换，就分别编号并写两端锚点。
- 不为了"高级"堆转场：手段服务的是"观众该不该被告知"，不是画面花哨。
- 转场不替故事做事：跨越前后如果信息、关系或处境没有变化，这次跨越就该删掉。
- 双线切换要控制频率：切得太密，两条线都立不住；切换点要落在观众已经建立了两条线之后。

## 七、复核

- [ ] 已定时间关系（时间跳跃 / 双线并行 / 时间倒错），并据此要求观众读出的信息
- [ ] 已定"是否要让观众察觉切换"，且没有两头都要
- [ ] 镜内族写明路径、更换要素与落幅；镜间族写明两端锚点
- [ ] 嵌套与固定机位叠化写清了进出关系 / 机位一致性
- [ ] 两条线各有稳定视觉基线，差别每次切换可复现
- [ ] 判定主要靠实体锚点，色彩只作辅助
- [ ] 已按可生成性分级选路，高风险手段有降级方案
- [ ] 生成指令里没有要求一段之内完成两次时代变换
- [ ] 跨越前后信息、关系或处境确有变化
