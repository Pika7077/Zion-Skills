# 13 · 摄影机与质感词库

按 [导演决策标准](directing-policy.md) 选择与当前任务有关的成像、运动、调色及材质写法，不将参考选型表当作数量配额或模型硬限制。
> 本档只给质感与运动词：景别、观看位置/角度、观察关系与构图的当前口径见 [camera-vocabulary.md](camera-vocabulary.md)；运镜轴、常用运动的表意与纪律、具名运动见本档 §三。
> 观察方式不使用代号，直接写名称（过肩、正侧面、前景遮挡……）。旧稿中的 V1–V12 为已废弃编号，仅历史样例保留。

## 一、表演与摄影机的配合

情绪不直接对应固定机位或运动。先确定当前可见事件和镜头任务，再判断摄影机是应该参与、对比，还是保持稳定让表演在画内发生。

| 表演/事件需求 | 可选摄影方法 | 判断条件 |
|---|---|---|
| 压力与不稳定 | 轻微手持、受限观察、固定机位下的画内失控 | 选择观众应与角色一起不稳，还是应该冷静观察 |
| 平静、掌控或对峙 | 稳定构图、固定机位、缓慢单轴运动 | 保持稳定是否更能读清人物选择与关系 |
| 震惊或信息揭示 | 停住、缓推至新信息、或拉出显示新处境 | 落幅必须出现新信息，不为“戏剧性”空推 |
| 孤立、离开或失去 | 从近景/中景拉到全景或大全景 | 仅在环境与人物比例能表达处境时使用 |
| 动作冲击 | 低位仰拍、跟随、快速重构或保持全景读清动作 | 根据动作路线、接触点和结果选择；帧率/快门只在已确认制作参数时写 |

单镜内表演变化不要求摄影机必须同步变化。若使用运动，说明哪个行为或信息触发运动、运动如何变化、最后停在什么结果上。核心是摄影机服务事件与演员，不走自己的节拍。

**角度不是权力标签**：仰拍可放大尺度或冲击，俯拍可表现弱势、监视、全局或空间掌控。先按当前主体、构图、上下镜和观众位置判断，再决定是否与表演节奏叠加；不建立“掌控者必仰拍、被动者必俯拍”的固定映射。

## 二、质感层：机身 / 镜头 / 焦段 / 光圈

### 2.0 焦段、视角与透视（选焦段前先读）

**核心口径**：透视关系由**拍摄距离**决定，焦段只决定**视角宽窄**；机位决定透视，景深与画幅影响虚实和空间。

```
焦段  → 视角宽窄（同一机位，越短越宽、越长越窄）
距离  → 透视强弱（越近越强、越远越弱）
景深  → 光圈 × 焦距 × 距离 × 画幅 共同决定
压缩  → 更远距离 + 更窄视角 → 背景层次被压缩，画面更简洁
```

两个常见误读必须纠正：

- 广角拍人变形，不是广角本身的问题，而是**为了取景靠近了主体**；广角也提供不靠近的环境视角。
- 长焦压缩空间，不是长焦本身的效果，而是**为了取景退到了更远处**；在很近的物距下长焦透视同样强。

因此选择顺序是：**先定观众站得多远（含主体尺度与透视强度）→ 再定焦段 → 最后定光圈与虚实**。不得由焦段反推机位距离，也不得用焦段区间表直接判定景别或判错（见 [导演标准](directing-policy.md) §不再使用的绝对规则）。

### 2.1 焦段档位：视角、透视与代价

| 焦段 | 画面关系 | 强项 | 代价 / 风险 | 常用场景 |
|---|---|---|---|---|
| 超广角 14–24mm | 容纳大量环境，近大远小明显 | 空间纵深、现场氛围、冲击力 | 边缘拉伸，面部/手脚/身体比例易变形；元素多则杂乱 | 建筑、风光、室内、空间人像 |
| 广角 24–35mm | 人靠近、环境信息多 | 临场感与代入感强，环境叙事 | 必须靠近主体，距离感控制难；贴近时肢体比例被夸张 | 街拍、人文、纪实、环境人像、生活方式 |
| 标准 35–70mm | 人与环境平衡 | 视角自然、变形小，不夸张也不疏离 | 没有广角的空间冲击，也没有长焦的强压缩，不制造戏剧性 | 日常人像、胶片风格、静物、职业形象、商业小品 |
| 中焦 70–135mm | 主体突出、背景柔化 | 面部比例自然、焦外柔和、背景干净 | 物距更远，室内受限；环境信息减少，叙事感弱于广角 | 人像写真、肖像、半身、特写、情绪写真 |
| 长焦 135–200mm | 背景压缩、情绪距离强 | 杂乱背景被压干净，主体突出，可远距离不打扰地抓拍 | 器材更重，对快门、防抖与追焦要求高；小空间不灵活 | 户外人像、仪式特写、舞台、活动纪实 |
| 超长焦 200mm+ | 强烈主体分离 | 捕捉远处主体，背景极简，情绪集中 | 对机身追焦、防抖、快门速度要求很高 | 体育、生态、舞台、远距离纪实 |

**在 AI 短剧语境下的取舍**：竖屏 9:16 与小屏可读性优先，主力落在 **24–85mm**；超过 135mm 的强压缩只在需要把杂乱背景压干净或制造情绪距离时使用，且要检查小屏下主体是否仍可读。超广角用于空间建立，不用于人物近景对白（边缘拉伸会破坏身份一致性）。

### 2.4 焦段与光圈（按镜头目的选）

先按 §2.0 定观众距离与透视强度，再查本表选玻璃与光圈：

| 目的 | 常用焦段起点 | 景深任务 |
|---|---|---|
| 极紧情绪特写（额到下巴充满画面） | 85mm / 100mm | 先判断背景关系是否仍需可读，再定浅或深 |
| 中景对白、双人 | 35mm / 50mm | 两人同时清楚，或明确一次焦点交接 |
| 广角 / 建立 | 21mm / 35mm | 入口、位置、路线或群体关系可读 |
| 插入 / 物件细节 | 50mm / 85mm | 关键接触点清楚，背景按归属需求保留 |
| 微距（毛孔、水珠、织物） | 45mm macro | 控制极薄焦平面，确保目标细节落在清晰区 |
| 反应 / 人物孤立 | 75mm | 隔离主体时可浅；需同时读环境压力时保留层次 |

光圈数值只作为曝光与景深的技术起点，不承载固定情绪含义。`f/1.4`、`f/4` 或 `f/11` 的实际景深还受焦距、距离、画幅与对焦位置共同影响；先按 [镜头语言](camera-vocabulary.md) 确定哪些层必须清楚，再定数值。
> 本表是“目的 → 玻璃与景深任务”的起选链，不是数值 → 景别的判读链；景别由**焦段、机距与主体尺度共同**决定（本档 §2.0）。

### 2.6 条件式控制从句

- **需要持续锁定主体时**：`焦点平面从第一帧到最后一帧锁定在 {对象} 上——无焦点漂移，无自动对焦搜寻。` 若镜头任务是焦点交接，不得再附这句。
- **需要几何准确时**：`建筑直线保持笔直，无随机桶形或枕形畸变，无鱼眼。` 若镜头有意利用近距离广角透视强化尺度与速度，应改写为“受控透视夸张，人物身份与四肢结构保持稳定”，不能同时禁止一切广角效果。
- **写机身/镜头品牌时**：不把机型名当作指令直接投喂。相机身与镜头拆成可见结果再写进提示词——浅景深程度与焦外质感、肤色与高光滚降、颗粒与动态范围、畸变与变形宽银幕光晕。台词与打光才是观感的主要来源，机型名称不替代其中任何一项。

## 三、镜头运动：轴 → 具名 → 组合规则

### 3.1 运镜轴（11 种：先选轴，再选具名）

五维中的“运镜轴”指摄影机的运动自由度。先定轴，再从 3.2 的具名运动里选词——直接挑具名运动容易选出互相矛盾或超出上镜可实现范围的动作。

| 轴 | 运动 | 物理含义 | 主要具名 |
|---|---|---|---|
| 1 | 固定 Static | 机位与朝向都不变 | 锁定机位、固定 |
| 2 | 推近 Dolly In | 沿光轴向前位移 | Dolly In、Super Dolly In |
| 3 | 拉远 Dolly Out | 沿光轴向后位移 | Dolly Out、Super Dolly Out |
| 4 | 横移 Truck / Track | 左右平移 | Dolly Left·Right、Action Run、Car Chasing |
| 5 | 升降 Boom / Pedestal | 垂直位移 | Crane Up / Down、Levitation、FPV 穿梭 |
| 6 | 摇摄 Pan | 机位不动，水平转动 | Whip Pan、static pan |
| 7 | 俯仰 Tilt | 机位不动，垂直转动 | Tilt 类 |
| 8 | 滚转 Roll | 机身绕光轴旋转 | Dutch Angle |
| 9 | 弧线 Orbit / Arc | 绕主体公转 | 360 Orbit、Arc、Lazy Susan、Robo Arm |
| 10 | 变焦 Zoom | 焦距变化，无位移 | Crash Zoom In / Out |
| 11 | 焦点转移 Rack Focus | 焦点平面变化 | 拉焦、焦点交接 |

**稳定度是修饰，不是轴**：锁定 / 平滑（稳定器）/ 手持（有机抖动）/ 机械臂（Robo Arm）/ 身体绑定（Snorricam）。手持可附加在任意轴上，写清楚幅度与用途即可。

**不属于 11 轴的特殊工艺**：时间类（Bullet Time、Hyperlapse、Timelapse、Low Shutter）与穿物类（Through Object In / Out、Mouth In）改变的是时间或空间连续性，不是摄影机自由度。使用前单独评估上镜可行性与生成稳定性。

### 3.2 八种常用运动的表意与纪律

> 摄影机运动 + 人物调度是图生视频的核心。运动解决三件事：**注意力引导**（观众看哪里）、**情绪推进**（紧张、疏离、安宁）、**空间感建立**（广度、层次、结构）。先判断运动的表意作用，再写提示词——重点不是用多用少、华丽或朴素，而是**每一个运动都有叙事目的**。

| 运动 | 轴 | 表意 | 纪律 |
|---|---|---|---|
| 推进 | 2 | 进入人物（中近景、特写、动作）；压缩距离，观众本能感到压迫累积；大景别推向小景别以强化细节 | 落点必须有信息——情绪、动作或关键物件；不空推 |
| 拉远 | 3 | 展示环境（从面部带出所在空间）；制造疏离；空间信息逐步释放 | 新出现的环境要有内容，不然只是缩小 |
| 横移 | 4 | 展示空间及前中后景与人物位置关系；与主体同向运动产生跟随感；逐步展开空间广度 | 路径上要有可读的层次变化，不做匀速过场 |
| 跟拍 | 4 / 5 + 跟随意图 | 代入感（不是旁观而是同行）；陪伴视角（肩后镜头让人站在人物身后）；完整呈现"从哪来、到哪去、经过了什么" | 写清跟谁、从何方向、结束位置 |
| 环绕 | 9 | 突出主体（被环绕即重要）；背景变化而主体锁定，形成仪式感与张力；轴线不断变化 = 试探、压迫、较量 | **必须有环绕的理由**（对峙、审视）；易过度使用，造成疲劳与拖沓 |
| 摇摄 | 6 | 信息切换（从一个重点带到另一个重点）；提示画外还有东西；建立两个主体的关联 | **摇过去必须出现新信息**，否则是无意义的扫场 |
| 手持 | 稳定度修饰（可叠加任意轴） | 临场感（摄影机像观众的眼睛）；呼吸感；真实追逐或突发事件氛围 | **不能写得太轻**——要明确写出随画面明显晃动；最怕只有晃没有情境，需搭配具体动作；克制使用 |
| 固定 | 1 | 观察与凝视（观众会去看人物、空间与关系的变化）；情绪在同一构图内堆积；建立气氛的稳定性 | 写清保持什么构图、画内怎样变化 |
| 下降（垂直） | 5 | 展示空间维度；开场先给世界或场景的尺度，再落到具体主体 | 与 Crane Up 的"揭示尺度"方向相反：下降用于引入 |

> 这份表是"为什么用"，§3.1 是"有哪些"，§3.3 是"怎么命名"。选型顺序：叙事目的 → 轴 → 具名运动 → 写时序。

### 3.3 命名运动表（37 项，按轴归组）

**Dolly**：Dolly In（亲密、揭示、张力积累）/ Dolly Out（孤立、离去、扩展语境）/ Dolly Left·Right（跟随、揭示）/ **Dolly Zoom In**（前推 + 后拉焦；眩晕、震惊、顿悟）/ **Dolly Zoom Out**（后拉 + 前推焦；被淹没、世界压来）/ Super Dolly In（突发惊吓）/ Super Dolly Out（尺度戏剧性揭示）

**Crane / 垂直**：Crane Up（揭示尺度，亲密→宏大）/ Crane Down（从上方引入地点，个性化）/ Crane Over The Head（脆弱、监视、编排感）/ Levitation（神秘、超脱、出体）

**Orbit / Arc**：360 Orbit（情绪孤立、戏剧强调）/ Arc（半圆；揭示、情绪转折）/ Lazy Susan（慢转盘、主体居中；产品、人物登场、服装展示）/ Robo Arm（精密机械弧线；编排场景、产品揭示）

**Zoom**：Crash Zoom In（震惊、顿悟、强调细节）/ Crash Zoom Out（抽离、突然扩展语境）

**Follow / 动作**：FPV Drone（快速敏捷穿梭；追逐、空中动作）/ Action Run（低位跟随奔跑）/ Handheld（有机抖动；纪录真实、亲密、混乱）/ Head Tracking（锁定头部；第一人称强度、眩晕）/ **Snorricam**（绑在演员身上，背景摇摆；压力、醉酒、情绪高涨）

**特殊**：Bullet Time（主体冻结、摄影机扫过；动作高潮）/ Dutch Angle（心理张力、不稳定、恐惧）/ Fisheye（超现实、滑板）/ **Whip Pan**（快速横向模糊摇摄；动态转场）/ Overhead（正上方鸟瞰；编排、空间关系）

**时间**：Hyperlapse / Timelapse Human / Timelapse Landscape / **Low Shutter**（慢快门运动模糊；速度、急迫、醉意）

**穿物**：Through Object In · Through Object Out · Mouth In（超现实转场、进入记忆/梦境）

**载具**：Car Chasing（贴地跟随）/ Car Grip（挂载车身同乘）/ Buckle Up（颠簸剧烈摇晃；糟糕路况、失控）

> 注：Cinema Studio 内部 **Crane Up → Jib Up，Crane Down → Jib Down**，映射时注意。

### 3.4 组合规则与边界

- **一条主导轨迹**：默认只保留一条观众能追踪的摄影机路径。弧线 + 升降 + 推进可以耦合为连续三维轨迹，但必须写清起点、方向、速度、主导变化和落点；不是按术语数量机械判错。
- **完整 360° 不是默认值**：用完成揭示所需的最短弧线；60°–180° 常已足够。完整环绕要有足够时长、场地净空、四周可用美术与可连续的光源关系。
- **同一时刻不下相反指令**：推进与后拉、上升与下降不能被写成同时发生；若剧情需要先后反转，必须标出转折时点、停顿或触发事件，并确认镜头时长足够。
- **顺序组合必须写时序**：`摄影机 0-3 秒向左摇摄跟随角色，停住，4-8 秒推向面部`，否则模型会把两段压成一个含糊动作
- **耦合与顺序分开写**：同时发生的运动写成一条空间轨迹；先后发生的运动写时间段与切换点。没有足够时长或路径无法解释时，删减运动或拆镜。
- **匀速与强度词不得冲突**：若要求全程匀速、无突然加速，不再写“极速后拉、猛然推进、突然升起”。冲击可以来自遮挡解除、主体入画、焦点交接或构图关系变化；焦点变化速度也要单独说明。
- **Static pan vs glide**：pan = 原地旋转；glide = 空间平移。多数覆盖镜头优选 **static-pan**（读作"选定的视点"），glide 读作"无锚漂浮"。**必须写明是哪一种。**
- **反向自检**：`声明的运动必须能产生声明的落幅`——"缓慢推进"不可能从全景落到极特写；10cm 后拉不可能完成全身揭示。矛盾时模型会二选一并自行脑补另一侧。

### 3.5 微运动的幅度与速度

先说明可见的起止构图与运动幅度。自然语言足以消歧时无需数字；“缓慢后拉”仍容易被理解成大幅运动时，可用距离与时长作制作估计，例如：

> `在完整的 7 秒里摄影机只后拉 10–15 厘米——慢到几乎察觉不到。无变焦，无突然推进。`

**绝不用 `zoom` 描述物理位移**——必须写 dolly / track / push-in / pull-out。

### 3.6 生僻术语的翻译公式

```
摄影术语 + 目标主体 + 可见变化 + 前后景关系 + 方向或速度
```
> 拉焦：焦点从前景的叶子平滑转移到后景的人。叶子逐渐模糊，而人脸由柔变锐。

精确转场时刻再加：触发时间、遮挡物、方向、之后继续做什么。**可见结果比裸数值更清楚**，但光圈/焦距/快门数值允许写。

### 3.7 可靠措辞白名单

| 意图 | 可靠写法 |
|---|---|
| 无摄影机运动 | `锁定机位完全静止，无运动` |
| 缓慢接近 | `8 秒内从中景缓慢推轨至紧凑特写` |
| 跟随主体 | `手持跟随主体，细微晃动，不混乱` |
| 揭示尺度 | `摇臂从地面高度升到正上方` |
| 环绕主体 | `视平线高度平滑 180 度环绕，距离恒定` |
| 戏剧性变焦 | `冲击瞬间从全景疾推至极特写` |
| POV 运动 | `FPV 摄影机以步行速度穿梭于环境之中` |

## 六、色彩分级

> 本节给**色值与调色词**。影调体系（明度 × 饱和度七色调）、共同色偏、影调弧线与色彩叙事推进见 [23-color-and-tone.md](23-color-and-tone.md)。本节不重复该档的分类与推进规则。

### 6.1 情绪 → 调色词库

| 情绪 | 调色描述 |
|---|---|
| 冷峻惊悚 | 青橙、去饱和、高反差 |
| 温暖怀旧 | 黄金时刻琥珀、柔和阴影、低反差 |
| 赛博 | 霓虹洋红与青、深阴影、HDR |
| 恐怖 | 病态黄绿、压黑的暗部、去饱和 |
| 爱情 | 柔和暖粉金、抬起的阴影、梦幻 |
| 纪录 | 中性、自然光、无调色 |
| 史诗奇幻 | 浓郁宝石色、深阴影、体积光 |
| 黑色电影 | 高反差黑白，或近单色 |
| 科幻冷调 | 冰蓝与银、刺眼白光 |
| 后末世 | 去饱和橙棕、尘霾 |

### 6.2 八种调色预设

Naturalistic Clean（写实中性）· Bleached Warm（日晒暖调）· Hyper Neon（高饱和霓虹）· Teal Orange Epic（大片标准）· Sodium Decay（钠灯橙 + 衰败）· Cold Steel（去饱和冷调）· Bleach Bypass（高反差低饱和）· Classic B&W（黑白档案感）

### 6.3 配比与预留

- **60 : 30 : 10（可选）**——用主导色 / 次要色 / 点缀色帮助建立主次，按实际光源、表面和叙事需要调整，不作为每幅画面的固定配额。
- **为故事预留饱和强调色（可选）**：关键道具可以独占低调色盘中的强调色，也可把特殊色温留给剧情转折；只有采用该策略时才写入项目色彩规则。

### 6.4 一个风格锚点（One Style Anchor Rule）

> 优先明确主风格锚点；补充词只保留能增加可见信息、且与主风格一致的内容。不按 style token 个数推断模型必然失效。

✅ `风格：变形镜头、轻微颗粒、muted 配色`　　❌ `风格：电影感、变形、情绪化、氛围、戏剧光、胶片颗粒、去饱和、黑色电影、高反差、复古`

### 6.5 Anti-Slop 替换表

抽象词没有画面信息，替换成能被画出来的东西，不加更多形容词：

| 抽象词 | 换成 |
|---|---|
| 电影感 / cinematic | 具体镜头、光位与影调（变形镜头、轻微颗粒、muted 配色） |
| 高级感 | 材质、工艺、留白与光比 |
| 氛围感 | 光与空气介质（雾、尘、湿地面反光） |
| 震撼 / 史诗 | 尺度对比、负空间、低机位 |
| 唯美 / 梦幻 | 柔光、薄雾、低反差高光、粉彩配色 |
| 大片感 | 反差、色彩分离、清晰的明暗结构 |
| 复古 | 具体年代材质与成像响应（搪瓷、水磨石、某型胶片） |
| 有故事感 | 可见的物件状态与使用痕迹 |
| 孤独 / 压抑 | 位置、距离、遮挡与暗部占比 |

不做反向操作：不用更多形容词替换一个形容词，也不堆 `8K`、`masterpiece` 一类无画面信息的词。

### 6.6 Register Poles（影调档位与切换）

Register 是画面影调与色彩体系的档位。同一部片可以用多个 register，但每次切换必须有叙事触发并登记在连续状态里。

> 影调档（明度 × 饱和）、共同色偏与全片影调弧线见 [23-color-and-tone.md](23-color-and-tone.md)；本表给**切换的写法与纪律**。

| Register | 影调特征 | 触发 |
|---|---|---|
| 现在时 | 中性自然、标准反差、中饱和 | 主线叙事 |
| 回忆 | 抬起阴影、低反差、略降饱和、轻微褪色 | 进入记忆、闪回 |
| 传说 / 档案 | 高反差、近单色、颗粒加重 | 传说、史料、不可靠叙述 |
| 幻境 / 异质时空 | 色温偏移、强化强调色、非常规光质 | 梦境、幻觉、超现实段落 |

写法与纪律：

- 给每个 register 写清色温、反差、饱和、颗粒和强调色的取值，而不是只写“褪色”。
- 一个场次通常保持清楚的主导 register；若剧情需要同时呈现不同时间、空间或主观体验，可分区或交替使用，并写清各自范围与叙事动机。切换用光变、曝光、介质、材质或剪辑等可读线索承接，不只靠抽象标签。
- 切换后写入连续状态（本组末态即下一组起始态），跨组继承。
- 60 : 30 : 10 可辅助分配主色、辅色与强调色，不要求每个 register 固定满足比例。多个色盘同框时写清各自范围和视觉主次，避免无意混色。

### 6.7 从参考图反推项目级风格层

用户给出参考图（剧照、截图、美术设定）时，先**反推**再落风格层，五维逐项写清，不直接抄风格词：

| 维度 | 反推什么 |
|---|---|
| 色彩 | 主色与辅色、饱和度、色温阵营、强调色的用量 |
| 光影 | 主光方向与硬度、光比、暗部保留层级、高光滚降 |
| 材质 | 表面反射属性、织物／金属／木石／皮肤的质地倾向 |
| 对比度 | 整体反差、黑位是否干净、高光是否允许溢出 |
| 镜头质感 | 景深呼吸与焦外特征、畸变、颗粒、锐度、光晕 |

纪律：

- 反推结果落成**项目级风格层**——一次设定、整组复用，不在每镜复述（见 [12-prompt-hygiene.md](12-prompt-hygiene.md)）。
- **不默认套用旧项目（旧片、旧系列）已用的 LUT 或风格层**；确要跨项目复用须说明依据，否则按本片参考图重新反推。
- 五维与 `zion-assets` 的题材美术档冲突时，以用户明确要求为先，其次题材档。
- 未提供参考图、且项目没有已确认风格层时，不补虚构默认值；光影与影调的分档分别见 [20-lighting-system.md](20-lighting-system.md) 与 [23-color-and-tone.md](23-color-and-tone.md)。

## 七、材质写实六轴（道具 / 服装描写）

从下列属性中选择真正影响识别、光线或动作反馈的项，不为每个表面凑固定数量，避免用泛化的“塑料光泽”替代材质：

| 轴 | 取值 |
|---|---|
| Base | metal / glass / fabric / ceramic / wood / leather |
| Roughness | matte / satin / glossy / mirror |
| Imperfection | scratches / dust / wear / fingerprints / patina |
| Edge | beveled / sharp / rounded / chamfered |

例：`哑光陶瓷花瓶，有发丝裂纹与轻微包浆，柔和的圆边，置于粗砍橡木之上。`

**服装复杂度（piano test）**：若某服装元素对模型的渲染开销"像画一架钢琴"，模型会把预算花在它身上而不是动作上。只保留**剪影 + 一个识别特征**。

## 十一、分辨率决策矩阵

| 内容特征 | 选 |
|---|---|
| 快速 / 混乱运动（爆炸、水流、人群、急摇） | **720p**（像素少 = 流动更顺、少闪烁） |
| 精细物理（发丝、沙、小颗粒、玻璃碎片、织纹） | **1080p** |
| 重量感（重载车辆、悬挂行程、质量冲击） | **1080p** |
| 草稿验证 | **480p** |

**升频管道**：母版取**模型最大分辨率 + std 模式**，绝不低于交付分辨率的一半。
**细部判定必须在最终分辨率重测**——480p 恰好藏掉的就是你要判定的那些细节。
