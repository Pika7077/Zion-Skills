# MiniMax H3：可选视频模型适配

本档只处理**输出壳**：上游的剧本事实、资产引用、空间关系、时长配平、语气与声音分层一律继承 [导演决策标准](directing-policy.md) 与 [音频、对白与物理声响](15-audio-and-lipsync.md)，不改判据，只把生成块改写成 H3 的原生字段结构。

核验说明：本档的字段名、段序、时长区间与素材上限转述自外部资料（manju-laoli 6.9.8 版本，其自述为逐条核对 MiniMax 官方仓库与规格表；核验日期 2026-09-19）。本工作区**未独立核验实际入口**。投喂前按当前入口复核字段名与上限；入口未开放或字段不符时，按 [模型适配](10-engine-constraints.md) 的口径回到已核验模型，不凭本档推定。

## 一、两个入口与字段集

H3 只有两个 checkpoint，选择依据是**投喂素材的形态**：

| 入口 | 输入 | 对应情形 | 字段集 |
|---|---|---|---|
| FL2VA 族 | 零图 | 纯文本段 | 三字段 |
| FL2VA 族 | 一图（首帧） | 有分镜首帧图 | 首帧指令行 + 三字段 |
| FL2VA 族 | 一图（尾帧） | 只有收势定格图 | 尾帧指令行 + 三字段 |
| FL2VA 族 | 两图（首尾帧） | 需要锁定动作起止 | 首尾帧指令行 + 三字段 |
| Ref2VA | 多模态参考 | 有角色、场景、道具参考图组 | **六段式** |

- 三字段：`integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`
- 六段式（顺序固定）：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`

采用参考图组锁定形象时走 Ref2VA；只有一两个具体帧需要锁定时走 FL2VA 族。两者不混用。

## 二、指令行

仅 FL2VA 族需要，作为正文第一行，其后空一行：

```text
I2VA:  For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

FL2VA: How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.

L2VA:  How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

`N` 为实际末镜编号，`S.SS` 为有效时长（两位小数）。Ref2VA 没有指令行。中文项目可把整行译写，但字段名、标签与时间码格式保持原样。

## 三、映射关系

| 本档产物 | H3 落点 | 要求 |
|---|---|---|
| 画幅与风格行 | 请求参数 `ratio` + 开场 1–2 句 | 画幅不进正文；“电影感”一类空词换成可见要素（镜头质感、色温、光位、景深） |
| 场景资产（`loc_` 资产） | `<Subject N>`（环境类） | 场景图作为环境参考；只有图本身要当具体帧时才另立 `<Picture N>` |
| 核心人物（`char_` 资产） | `<Subject N>`（人物类） | 外观特征写进定义行；资产锚点符号全部去掉；有音色素材时把音色写成主体描述里的短语 |
| 站位声明 | **无对应栏** | 转写成画面语言句并入对应 `[Shot N]`（“三步外停住”“身子半侧向庭院”“两人之间”）；禁坐标表、禁示意图 |
| 时间轴分镜 | `[Shot 1]`（不带时间戳）+ 后续 `[Shot N]` 与切点 | 后续切点以 `在 00:04.000 处` 形式**严格递增**且不超过本段时长；切镜写“镜头切至” |
| 镜行声音 | 拆三层 | 环境音与物理音进 `overall_soundscape`；配乐进 `non_diegetic_music`；对白留在正文 |
| 台词与语气位 | 说话人短语 + `<d>[语言] 原文</d>` | 语气（情绪色、力度、音质、节奏）与角色身份合成一句说话人描述，写在 `<d>` **外面**；`<d>` 内只放语言标签与原句，逐字不改 |
| 画外声 | 声音段 + 闭口证据 | 画外声必须紧跟“嘴唇始终完全闭合”一类的可见证据，与 [音频、对白与物理声响](15-audio-and-lipsync.md) 的闭口纪律同款 |
| 画内文字 | 引号内保原文 | 用英文直角双引号，不用中文引号或书名号 |
| 表演描述 | 可见肌肉语言 | 表情强度档、动作编码一类的内部标注不进正文，只写肌肉与幅度 |
| 抽象形态词 | 具象可见形态 | 按 [提示词清晰度](12-prompt-hygiene.md) 的具象判据改写 |
| 接续状态 | **无对应栏** | 末帧画面信息写进本段末镜句尾（谁+在哪+姿态+道具状态，可画出一帧），供下一段作首帧或接缝参考 |
| 负面清单与音效栏 | 不进正文 | H3 正文只写“有什么”，负面项由执行者侧管理 |

### 必须继承的三条上游纪律

H3 没有对应的栏位，但纪律照旧成立，只能由写稿人守住：

- **摆位的人要入画**：站位里摆了位的每个人，转换后必须在至少一个 `[Shot N]` 出现（正拍、焦外身影、全景群像、反应镜头均算）；给不了镜头就写明已出画或已退场及去向。
- **首镜要有主体锚**：`[Shot 1]` 必须带一个具名主体（人名，或注明归属的身体局部，如“她的一只手”）；空镜开场须在镜行首写明“空镜”，且每段至多一镜。
- **首镜只许一个主体统摄**：不写“X 与 Y 同框”一类并列主体句式，部位以从属形式出现（“她的/他的 + 部位”），不用没有先行词的指示代词。

## 四、边界

- **时长 4–15 秒**，与请求时长严格对齐；超过 15 秒的单段按因果落点再拆一刀。
- **参考素材上限**（Ref2VA）：图像不超过 9 张；视频不超过 3 段（每段 2–15 秒、总长不超过 15 秒）；音频不超过 3 段且**不能作为唯一输入**，必须与图像或视频同时投喂。
- **画幅**：可用 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16；参考类模式用自适应。比 [画幅导演](aspect-ratio-directing.md) 常用三档多出 4:3 与 3:4。
- **输出规格**：24 FPS、32 kHz 立体声、默认短边 768。
- **语言**：跟随内容主语言，中文项目写中文；台词、歌词与画内文字永远保原语言。固定英文的只有格式词——字段名、保留度标记、标签、发言人编号、语言标签与时间码。
- **发言人编号**：按本段实际发声顺序从 `(S1)` 起编；未发声的角色不给编号。分段生成时每段独立重编。
- **保留度标记**取固定英文值（画面 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`；音频 `fully_copy` / `partially_copy` / `reference` / `weak_reference`），且不写在保留度分析段之外。
- **任务类型前缀**写在摘要段首：`keyframe completion` / `reference generation` / `video editing` / `video continuation` / `audio reuse` / `audio reference`，多类型用 ` + ` 连接。
- **参考素材取材顺序**：先保具体帧锚图，再保主要角色的资产板（一张资产板算一张图），再保核心场景，最后才轮到次要角色与道具；超限时把后面的降级为定义行里的文字描述，丢的是图锁定强度，不是信息。
- 已在站位或主体定义里出现、正文却一次都没引用的素材，等于白占一个名额。

## 五、正文写法纪律

H3 正文只写“有什么”：

- 不写否定式指导（“不要出现 X”“没有 Y”）。
- 不用资产锚点符号、不用本档段落栏名、不用工作流词（末态继承、拼接节点、换机位）。
- 不写坐标或示意图。
- 抽象的形态与程度副词按 [提示词清晰度](12-prompt-hygiene.md) 换成可命名的具象形态。
- 追求信息密度而非字数：把可见要素写细，但不靠注水凑长度。

## 六、复核

- [ ] 字段集与入口匹配，六段式顺序正确
- [ ] 首镜无时间戳，后续切点严格递增且不超本段时长
- [ ] 时长落在 4–15 秒，与载荷中的时长一致
- [ ] 素材上限未超（图 ≤9、视频 ≤3、音频 ≤3），且每项都写明了用途
- [ ] 定义过的标签都在正文被引用
- [ ] 语气写在台词 `<d>` 外，`<d>` 内只有语言标签与原句
- [ ] 画外声紧跟闭口证据
- [ ] 摆位者全部入画或有出画说明；首镜有单一具名主体
- [ ] 正文无否定式、无锚点符号、无栏名与工作流词
- [ ] 投喂前已按当前入口复核字段名与上限

## 七、与 Seedance 2.5 的分工

两者不是二选一的前置锁。默认按 [模型适配](10-engine-constraints.md) 的 Seedance 2.5 执行；用户点名 H3 或实际入口只有 H3 时，改用本档的输出结构，上游判据不变。两组字段结构不可混写；同一部戏跨模型时，按段落整体切换，不在一段内混用两套字段。
