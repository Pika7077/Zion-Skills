# 剪辑逻辑、时长与切点：可执行判据

本档处理**镜头为什么这样接、每个镜头该多长、在哪个瞬间切**。目的是把判断从"凭感觉"换成可复核的量与关系。

**本档只管进度与关系，不管图式。** 镜内揭示、匹配剪辑、遮挡、声音桥、场次过渡的具体手段与必写项见 [剪辑与转场](22-editing-and-transitions.md)；本档只补它没有的两个判据：**视觉变化量够不够**与**切点落在动作的哪一阶段**。

## 〇、判断权的次序

几个判据互相冲突时，按这个次序取舍：**情感与反应的真实 → 剧情推进 → 节奏 → 视线落点 → 构图 → 空间关系**。

它说明为什么“构图不完美但情绪接住了”的切点可以成立，而“构图漂亮但情绪断了”不成立。这是排序，不是权重分数，也不用来推翻空间与轴线的基本纪律——对象是否在同一位置、持物是否连续这类问题按连续性规则处理，不参与这个排序。

次序靠前的项有更大解释权：为保住关键反应，可以让构图让一步；但反过来不成立——不能为了构图对称而把一次真实反应切掉。

## 一、组接逻辑：先问变化量

### 1. 基础规则

| 规则 | 判据 | 落地写法 |
|---|---|---|
| 30° 原则 | 同一主体、同一距离的连续两镜，机位角度差**≥30°** | 写清两镜的机位方位与角度差，不写"换个角度" |
| 180° 原则 | 同一动作段内摄影机保持在**轴线一侧**；越轴必须有可理解的重建过程 | 轴线在空间草图阶段标定；反打两侧共享同一轴线与色调设定 |

轴线怎么定、越轴怎么重建，按 [镜头语言](camera-vocabulary.md) 的切镜复核与 [动作编排规则](action-choreography-rules.md) 的连续性校验执行。**不把 30° 当作硬性门槛去加镜头**：景别变化、主体位移或运动方向变化已经足够时，机位角度可以小于 30°，但必须写出那是哪一项变化在起作用。

### 2. 视觉变化量

把"画面变化程度"当量来估，够不够用三项相加判断：

| 变化项 | 取值依据 |
|---|---|
| 景别变化 | 相邻两档以内变化小，跨两档及以上变化大（大远景↔全景↔中景↔特写大致为四档） |
| 主体占比变化 | 主体在画面中的高/宽占比是否明显改变 |
| 机位角度变化 | 30° 以下、30°–60°、60° 以上分三档 |

三项**同时都很小** → 观众会读作跳变（同主体同景别同机位），改为拉开角度、改景别或干脆合并成一个镜头。三项**至少一项明显变化 + 叙事上接得住** → 可以直切，不必凑第三项。

景别跳档（全景直接接特写、特写直接回大全景）是合法的：判据是**足够变化 + 逻辑合理**，不是相邻景别才准接。逻辑是否合理看两点——观众此刻需要更大的信息（细节）还是重建位置（环境）。

极端两级跳档（大特写／特写直接接大远景／大全景，或反向）变化量足，但**重新定位成本也最高**。至少保留一个承接锚点（同一人物/物件、运动方向、画面位置或连续声音），或让后镜停留到观众重建空间后再交付下一条关键信息。若目的就是制造震动或短暂失向，也要在下一关键信息到来前恢复方位；“看不懂”不能冒充冲击力。

### 3. 动势匹配

先给每个镜头标一次**动势**，再决定怎么接：

| 标签 | 判定 |
|---|---|
| 静 | 画面内无显著位移，主体基本停在原位，机位不动或极缓 |
| 动 | 主体或机位有明显位移、速度或方向 |

| 组合 | 处理 |
|---|---|
| 动 → 动 | **速度匹配**：后镜起速与前镜落速相当，或有意做加速/降速（慢镜）；**方向匹配**：主体在画面内的运动方向一致，跨过画面中线前先建立新方向 |
| 动 → 静 | 用动作收尾或主体出画承接，让运动自然停住 |
| 静 → 动 | 后镜从静止起动，或由前镜的**画内刺激**（视线、声源、动作指向）触发 |
| 静 → 静 | 需要景别/角度/构图有明显变化；否则合并 |

"加速慢镜头"是速度匹配的一种取值，属于风格化强调，不是让画面变慢就叫匹配；它必须落在**已有运动**上，静止画面降速只会变成拖沓。

### 4. 视线落点与反应镜头

**视线落点承接**：观众上一镜的注意力落在画面哪个位置，下一镜的关键信息点就出现在相近位置，或沿同一方向顺势滑入。同向位移的镜头尤其需要这条——上一镜主体从画面右侧出画，下一镜就从右侧入画。这条不要求精确到像素，只要求观众不用满屏搜索焦点。

**反应镜头**：在关键接触、关键信息或判决性台词的一瞬间，把镜头交给在场者的可见反应（瞳孔收缩、倒吸一口气、身体僵住、手中动作停住），借他人的反应放大事件强度。反应镜头是**独立编号的镜头**，不是前一镜的延续；同一瞬间不要既拍接触又拍反应，也不要用反应镜头替换接触本身。

### 5. 已有素材不匹配：先诊断再修

先区分两种情况：若断裂让观众误判人物、动作、方向、时间或因果，它是连续性故障；若观众仍能读懂，且断裂明确服务冲击、失序、梦境或节奏，它可以是有意的不连续。高速动作、密集快剪和情绪爆发只能提高观众对**细小外观误差**的容忍，不能豁免身份、接触、方向与结果。

修复按破坏最小的顺序尝试：

1. **调和原镜头**：调整切点；在分辨率和构图允许时轻量缩放、裁切、重构位置；同一空间内匹配曝光、白平衡、对比与色彩。调和不能改变动作事实、视线对象、左右手、道具状态或空间地理。
2. **插入带任务的桥接镜头**：用全景/俯视重建空间，用纵深运动重建方向，用物件、环境反馈或动作局部跨过接缝。不存在“万能中性镜头”；每个插入镜都要新增定位、因果、情绪或时间信息，并计入时长。
3. **转移注意后回接**：使用在场者的真实反应、角色视点、手脚动作、道具结果或第三方观察，让观众先完成一次有因果的注意力转移，再回到原行动。不得为了遮错捏造不存在的反应、旁观者、回忆或道具，也不得跳过关键接触和结果。
4. **替换或重做**：关键人物身份、道具归属、接触动作、表演峰值或空间因果严重冲突时，采用局部合成、替换镜头、重生成或重拍；过渡镜不能把事实错误变成正确。

| 不匹配类型 | 优先修法 | 不能牺牲 |
|---|---|---|
| 景别/角度太近似，形成跳变 | 合并、拉开变化量，或插入确有信息价值的镜头 | 关键反应与动作进度 |
| 主体位置/视线错位 | 安全重构画面；用视线—视点、反应或全景重建位置 | 谁看谁、人物世界位置 |
| 运动方向相悖 | 展现转向过程；以纵深运动、动作局部或短暂空场重建方向 | 出入画方向、动作因果 |
| 越轴导致关系颠倒 | 展现人物/摄影机跨轴；用齐轴镜头、可读全景或俯视重建地理 | 左右关系、视线对象、行动路线 |
| 光影/色彩不连续 | 同场基线内做曝光、白平衡、对比与色彩匹配 | 有叙事意义的时空或状态差异 |
| 多人对话跳位 | 回到主观察镜头/全景，或用真实反应重新定位后再进单人镜 | 说话者、听者与视线轴 |

水平翻转只作为最后的局部技术选项：画面不得含可读文字、标识、非对称服装/伤情/发型、方向性道具、驾驶位置、惯用手动作或可核对地标；翻转后的光向、出入画方向、轴线和相邻镜也要全部成立。任何一项不满足，就改用重构、桥接、替换或重做。

## 二、镜头时长：先信息，再情绪，后节奏

按信息获取、情绪表达、节奏控制三层判断，先满足第一层再加第二层，最后一层只做收放。

### 1. 客观参考

| 读取阶段 | 参考量级 | 分镜含义 |
|---|---|---|
| 感知光影、色调、氛围 | 0.1–0.3 秒 | 环境级画面可短，但只能承担氛围，不能承载信息 |
| 理解画面内容与关系 | 0.5–3 秒 | 常规镜头下限参考；信息越多越靠上 |
| 注意力衰减 | >6 秒无新信息开始掉 | 长镜必须持续给新信息（新动作、新表情、新位移） |

这是参考量级，不是配额。超过 6 秒的镜头要能指出**它持续新增什么**；短于 0.5 秒的镜头只能作辅助画面（闪回、意象、卡点），不能承载关键反馈。

### 2. 主观控制

| 加长 | 缩短 |
|---|---|
| 信息密集（多层同框、需辨认细节） | 辅助画面（闪回、转场、意象）0.3–0.5 秒 |
| 抒情、留白、等待 | 卡点快切 |
| 关键反应与决定（记忆锚） | 已交代过的重复动作、铺垫动作 |

**缩短只压铺垫，不压记忆锚**：进门、关门、走到桌边坐下可以合并或快速带过，重点反应要给足起承转合。分配规则见 [三步引导法](27-guidance-three-steps.md)。

**强调靠表演时长，不靠慢动作**：需要长读数的反应延长真实表演时间；慢动作是风格选择，不是重点分配手段。

对白与声音占用的时长按 [剧本保真与时长](script-fidelity-gates.md) 配平，本档不重复语速取值。

### 3. 心理时间

银幕时长不等于观众感到的时间。先写清希望观众觉得时间在**压缩、延长还是近似实时流动**，再选手段：

| 时间感 | 常用组织 | 成立条件 |
|---|---|---|
| 压缩 | 省略重复过程，只留状态变化的标志节点；跳剪或蒙太奇 | 被省略的过程可由前后状态补全，每个节点有新变化 |
| 延长 | 同一瞬间的不同视角、反应、声音延续、延迟揭示结果；必要时慢动作 | 每次延长新增信息或情绪，慢动作落在值得读取的运动上 |
| 近似实时 | 连续动作与连续声音，常由短长镜头或克制切镜维持 | 变化过程本身有戏，镜内持续产生新信息 |

“雕刻时间”不是任意拖慢或快切。复核时问：观众应感到时间怎样流动；在被压缩或延长的期间，信息、动作或情绪究竟发生了什么变化。

### 4. 特殊场景

| 场景 | 时长主导 |
|---|---|
| 口播、访谈、独白 | 语言逻辑：一句说完就切，不按秒数裁 |
| 卡点视频、音乐段落 | 音乐节奏；只在已确认使用配乐时启用 |
| 动作段 | 动作因果：接触—受力—恢复必须可读 |
| 环境建立 | 观众能认出地点与方位即可，不拖 |

## 三、切点选择：两条相反思路

### 1. 弱化痕迹（求顺滑）

| 情形 | 切点 |
|---|---|
| 动作镜头 | "出动作—接动作"：A 镜切在动作**起步之后、完成之前**，B 镜从该动作的后续进度接续；常用约 **3:7** 分配（前镜收 3、后镜接 7）作为起始估计，按动作可读性调整 |
| 非动作镜头（人物、对话） | 结束点或消失点：动作收尾静止、主体出画、动作触点 |
| 生理引导 | 眨眼点：贴合观众眨眼习惯，适合情绪转折或视角切换 |

3:7 是**起始比例而非硬性数值**。判据是：切点两侧不能重复同一段动作，也不能跳过接触点或关键反馈。连续性校验见 [动作编排规则](action-choreography-rules.md)。

### 2. 强化表达（求风格）

| 手段 | 做法 | 边界 |
|---|---|---|
| 跳剪 | 同主体、同机位连续切，刻意打破连续；可跟音乐节奏跳切 | 跳剪读出的是**时间省略或风格节奏**，观众须能自行补全省略了什么 |
| 意外剪辑点 | 在预期之外的位置切断（提前于动作完成、错位于节奏） | 全片少用；是否成立看它服务什么风格，不服务内容的意外点只是失误 |

弱化与强化不是二选一，同一部片可以两种并存：常规推进用弱化，高能段落或风格段落用强化。**风格化剪辑不豁免因果**：切掉了什么，观众必须能读出来。

第三种打断节奏的手段是**闪切**——用极短插入镜打断并重建节奏。它与跳剪、卡点的区别、可读性上限，以及 AI 流程下的三条实现路径（裁切／截取／后期插入）见 [蒙太奇段落](32-montage-sequences.md)。

## 四、与生成流程的对接

剪辑点写在镜头之间，不写进单镜生成提示词。AI 生成的现实约束：

- **逐镜生成没有自动完成的后期接头**：选择逐镜方案时，先按 [剪辑与转场](22-editing-and-transitions.md) 的镜头 A/B 结构分别生成，再在后期完成切点；选择一段多镜时则写清组内镜头顺序与切点，但不把模型内切换当作可逐帧控制的后期接头。两种方案的生成提示词都只写各镜可见、可听的内容。
- **"出动作—接动作"需要跨两个生成的末帧/首帧对齐**：导演稿写清 A 的末帧锚点（动作阶段、位置、朝向、运动方向）与 B 的首帧锚点。实际帧对齐留到后期校准，不写进提示词当作保证。
- **组内切点不等于可逐帧控制的后期接头**：同一连续世界内可以按 [模型适配](10-engine-constraints.md) 写成一段多镜，并在组内标明镜头顺序与切点；但模型生成的切换不能冒充已经完成了精确帧级剪辑。跨越时间、空间或概念，或要求精确跳剪、闪切、卡点时，改为逐镜生成并在后期完成接头。
- **时长预算**：本组各镜时长之和须落在 `meta.generation_limit_seconds` 内；默认模型与预算从 [模型适配](10-engine-constraints.md) 读取。以闪回、卡点为由压到 0.3–0.5 秒的镜头仍计入总时长；时长不足时先压铺垫，不删原文。

## 五、复核

- [ ] 连续两镜变化量已核对：景别、主体占比、机位角度不同时都很小则已合并或改造
- [ ] 同主体连续镜头机位角度差 ≥30°，或已写明是景别/位移/方向在承担变化
- [ ] 轴线未无因越过；越轴有可理解的重建过程
- [ ] 每镜已标静/动，接法符合速度匹配与方向匹配；画面内运动方向未无因反向
- [ ] 时长落在信息读取区间内；超过 6 秒的镜头能指出持续新增的信息
- [ ] 记忆锚未被压缩、铺垫已合并；强调未改用慢动作代替
- [ ] 切点写明落在动作起始/进行中/收尾/出画/眨眼点中的哪一个
- [ ] 动作接剪未重复同一段动作，也未跳过接触点或关键反馈
- [ ] 使用跳剪或意外剪辑点时，省略内容对观众可读，且服务内容而非只为风格
- [ ] 同向位移镜头的入画位置承接上一镜的出画位置，观众无须满屏搜索焦点
- [ ] 反应镜头独立编号，且同一瞬间未同时承载接触与反应
- [ ] 已有素材不匹配先区分有意断裂与连续性故障，并按调和／桥接／注意力转移／替换重做的顺序处理
- [ ] 插入镜有定位、因果、情绪或时间任务；未捏造反应、旁观者、回忆或道具来遮错
- [ ] 若使用水平翻转，文字、非对称身份特征、方向性道具、光向、轴线与地标均已逐项验证
- [ ] 卡点、慢镜、跳剪只在项目已确认使用配乐或明确要求风格化时采用
- [ ] 剪辑说明留在镜头间字段，未写进单镜生成提示词；各镜时长之和未超本组预算
