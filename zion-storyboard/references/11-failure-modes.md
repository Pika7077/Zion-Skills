# Seedance 2.5 分镜失败诊断

把已观察到的症状与推测原因分开；不把猜测写成模型定律。通用制作基线见 [导演标准](directing-policy.md)。

| 症状 | 优先检查 | 可选修正 |
|---|---|---|
| 画面空、人物轮流说话 | 台词之外是否有目标、关系与行动过程 | 用已有物件/位置承载策略，增加真实反馈或有意义的等待 |
| 物体乱动或接触穿帮 | 起始状态、持物手、受力方向、接触阶段 | 简化同步动作，保留关键接触，必要时给状态图或白模 |
| 切镜后动作重复 | 上一镜结束和下一镜起始是否明确 | 继承动作进度，删除重复触碰/撞击 |
| 角色/空间漂移 | 附件用途是否混杂、世界位置是否固定 | 明确参考映射，减少相互冲突的参考；空间关系写进镜行的位置与朝向描述，不用额外板块承载 |
| 场景元素越画越漂 | 元素数量超出可维持范围 | 按取舍顺序删装饰性陈设，保住窗户位置、光线方向、地面质感；补俯视空间位置图，见 `zion-assets` 的场景一致性与状态阶梯档 |
| 运镜很多但难看清 | 主行动是否与多重运动争抢注意力 | 留一个观察任务，用固定或单一运动看清反馈 |
| 台词串人、漏词 | 声源、覆盖时间与可见口型是否对应 | 清楚写出声音时间线，必要时拆音轨或分组 |
| 反射/多人互动混乱 | 主体区分、遮挡、观察位置是否清楚 | 调整构图、分开关键接触，保留更简单的备选拍法 |
| 文字错误 | 文本是否需要精确读取 | 保留文字信息的剧情作用，安排可控后期叠加 |

不要一次同时改动作、镜头、光线和参考身份，优先改导致失败的一个关键变量。重复失败时比较保留镜头、局部编辑、拆组或改写方案；涉及剧情、对白与重要风格的变化交用户选择。
