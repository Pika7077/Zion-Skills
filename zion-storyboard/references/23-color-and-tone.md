# 色彩与影调：色系、影调、记忆与叙事推进

本档回答"**用什么色彩讲这段故事，以及色彩如何随剧情走**"。
选色值、调色词与预设见 [13-camera-and-texture.md](13-camera-and-texture.md) §六；布光与光比见 [20-lighting-system.md](20-lighting-system.md)；跨场色彩呼应见 [24-visual-motifs.md](24-visual-motifs.md)。

本档管**色彩是什么**与**怎么保持一致**；色彩如何承担**象征、区分时空与视角、组织全片走向**（含义由作品自己建立、互补色对、同一配色靠面积主次与明暗深浅换向情绪、色彩脚本、前后期分工）见 [色彩的结构功能](36-color-as-structure.md)。

本档给两套并行的分类，各管一件事，**不互相替代**：

| 分类 | 管什么 | 怎么用 | 在哪节 |
|---|---|---|---|
| **色系**（九种） | 色相阵营与色彩关系：冷 / 暖 / 冷暖对比 / 高饱和 / 低饱和 / 暗黑 / 霓虹 / 糖果 / 小清新 | 定"这段画面颜色往哪边靠"，贴合题材与情绪 | §一 |
| **影调档**（七色调） | 明度 × 饱和度：白 / 粉 / 明 / 鲜 / 灰 / 深 / 黑 | 定"这段画面有多亮、多浓"，决定成片的统一读感 | §四 |

**先选色系定方向，再用影调档定强度。** 两者组合成一个场次的完整色彩设定（组合方式见 §三）。

## 一、色系：九种色彩阵营

色系管的是**色彩倾向与色彩关系**，回答"观众一眼看到的颜色是什么阵营"。

| 色系 | 主色 | 氛围 | 适配题材 | 画面做法 | 常见误用 |
|---|---|---|---|---|---|
| **冷色调** | 蓝、青、紫 | 理性、疏离、压抑、神秘 | 科幻、悬疑、刑侦、职场 | 冷色主导 + 冷光源依据（月、荧光、屏幕、阴天）；暖色只作对比点缀 | 无冷光源却调冷，暗部发蓝显数码味 |
| **暖色调** | 红、橙、黄 | 温暖、治愈、怀旧、热烈 | 家庭、年代、爱情、美食、西部 | 暖色主导 + 钨丝/烛火/黄金时刻依据；阴影保留暖褐而非冷青 | 全画面刷黄，肤色失真、暗部发脏 |
| **冷暖对比色** | 冷与暖强对冲 | 紧张、冲突、戏剧张力、视觉奇观 | 动作、超级英雄、赛博、犯罪 | 冷主暖辅或暖主冷辅，**必须定主次**；两色分区而非均匀混合 | 无主次地冷暖各半，平均成平淡灰 |
| **高饱和色调** | 纯度高的浓烈色 | 鲜艳、梦幻、热烈、张扬 | 奇幻、动画、仙侠、儿童 | 色相少而纯、对比强、暗部干净；一镜内色相数量要克制 | 色相过多 → 俗气、廉价感 |
| **低饱和色调** | 柔和的灰调色 | 克制、沉静、高级、压抑 | 战争、文艺、现实、女性题材 | 整体降饱和 + 保留一层强调色避免死气；明暗层次承担信息 | 全画面一起雾化，失去可读性与质感 |
| **暗黑色调** | 低亮度的深色 | 神秘、压抑、危险、冷峻 | 恐怖、犯罪、暗黑、复仇 | 暗部压住 + 少量高光或单点色形成光池；**明度分强弱**（见下） | 全画面压黑却无光池，观众看不见主体 |
| **霓虹灯色调** | 高饱和荧光撞色 | 迷幻未来、都市颓废、迷离孤独 | 赛博朋克、复古霓虹、都市夜 | 洋红 / 青 / 紫 / 电光蓝撞色，来自招牌、屏幕、反射面；湿地面反光强化 | 无光源依据的霓虹，像贴上去的滤镜 |
| **糖果色调** | 浅粉、薄荷绿等浅亮色 | 甜美、童趣、愉悦、超现实 | 儿童、浪漫、甜宠、广告 | 浅亮高明度 + 中高饱和 + 低反差；马卡龙色板少量色相 | 色彩数量失控 → 变成廉价塑料玩具感 |
| **小清新色调** | 通透明亮 + 可见光影 | 干净、温柔、松弛、淡雅 | 青春、治愈、校园、日常 | 高调 + 通透光（逆光、耀斑、树影）+ 略高饱和的浅色；保留光的方向感 | 过度提亮拉平光比，失去体积与层次 |

**四个要点**：

1. **暗黑色调的"明度分强弱"**——先明确属于哪一档，不要笼统写"暗"：
   - 弱暗黑：暗部占 60–70%，仍有可读的中灰层次（犯罪、暗黑都市）
   - 中暗黑：暗部占 70–85%，只保留关键区域的亮部（恐怖、地下空间）
   - 强暗黑：暗部压到近黑，仅剩光池与轮廓（黑色电影、极端惊悚）
   强档必须说明"保留可读的是哪一部分"，否则观众看不懂画面。
2. **冷暖对比色的主次不可省**——两色同时在场时，必须写清哪一个是主光色、哪一个是点缀。术语与写法沿用 [20-lighting-system.md](20-lighting-system.md) §六 混合色温：室内暖 + 窗外冷，必须写明主光。
3. **高饱和与糖果色的区别在明度**：高饱和偏中低明度、浓烈；糖果色偏高明度、浅亮。两者都怕色相过多。
4. **霓虹与冷色调的区别在饱和度与来源**：冷色调低饱和、理性；霓虹高饱和、迷幻。霓虹必须有画内光源依据。

## 二、场景与剧情的色调一致性

**基本原则：同一场景、同一剧情段落内，色系与影调档保持统一。** 这是短剧的可读性底线——观众在小屏上不会去分析色彩意图，只会感知"这段是干净还是压抑"；色彩漂移会被读作制作事故。

### 2.1 一致性的三层

| 层 | 统一什么 | 不统一会怎样 |
|---|---|---|
| **镜头层** | 同一场次内所有镜头的色系、影调档、主光色温 | 相邻镜头一冷一暖，像两场戏拼在一起 |
| **场次层** | 同一场景的每次出现保持同一色调设定，除非有叙事触发 | 同一个房间早上一版、晚上另一版，观众会以为换了地方 |
| **剧情层** | 同一剧情段落（一个事件、一段关系、一个时空）保持统一色调 | 情绪断裂，前半段刚建立的氛围被后半段推翻 |

### 2.2 变更的唯一合法理由：叙事触发

色调**可以有变化**，但必须有可见原因。允许的变化与不允许的变化：

| 允许（有触发） | 不允许（无触发） |
|---|---|
| 时间推进：白天 → 黄昏 → 夜晚（光源随之改变） | 同一场次内色温无来由地漂移 |
| 光源更替：开灯、熄灯、换灯、拉窗帘 | 为了"好看"把某一镜单独调色 |
| 空间切换：从客厅（暖）到地下车库（冷） | 同一空间换机位后色调变了 |
| 段落分界：进入回忆、进入幻想、时空跳转 | 反打切换时两侧色调不一致 |
| 人物主观：进入某人视角，色调代表其心理 | 同一镜内冷暖忽然反转 |
| 实用光介入：霓虹招牌开启、屏幕亮起、火光出现 | 无光源依据的霓虹或冷蓝出现 |

**反打特别注意**：正反打的两侧必须共享同一套色调设定。光源在世界坐标中不变，只有画面左右镜像（沿用 [20-lighting-system.md](20-lighting-system.md) §九 反向机位规则）。两侧色温不同是最常见的隐性穿帮。

### 2.3 跨场景的统一与分化

同一部剧有多个场景时，按下面两选一，**先拍板再执行**：

| 策略 | 做法 | 适用 |
|---|---|---|
| **统一基调**（推荐做默认） | 全片一条共同色偏 + 一条影调弧线；各场景在此框架内变化 | 短剧主线、集数多、需要成片整体感 |
| **场景分区** | 不同场景有各自稳定的色调设定（家=暖、办公室=冷、地下=暗黑），每个场景内部严格统一 | 场景对立明显、关系用空间说话、多时空 |

**两种都要守的规则**：

- 无论哪种策略，**同一场景内部必须完全统一**。
- 分区策略下，各区的设定**一经确定即冻结**，不得因单场情绪临时改变一个场景的基线色调。
- 跨区切换必须有空间或时间依据（换场、跳时空），靠剪辑承接，不靠调色渐变掩盖。

### 2.4 登记：色调状态表

跨场统一必须登记，否则多集之间会失去控制。在项目连续状态中记录：

```text
色调状态：[项目名]
策略：统一基调 / 场景分区
共同色偏：{全片统一色温偏移与饱和水平}

场景色调表：
  {场景 ID / 名称}｜色系：{冷/暖/对比/霓虹…}｜影调档：{明度+饱和}｜主光色温：{__K}
                    ｜允许变化：{时间推进/光源更替…}｜禁止：{…}

剧情段落色调：
  {段落 ID}｜起止场次：{SC001–SC005}｜色系与影调：{…}｜触发切换点：{事件}
```

单场景项目可只登记共同色偏与场景色调表；多集项目建议全填。

## 三、两套分类的组合用法

色系与影调档**组合**，得出一个场次完整的色彩设定。组合原则：**色系给方向，影调档给强度**。

| 色系 × 影调档 | 典型组合 | 效果 |
|---|---|---|
| 冷色调 × 低调深色 | 青蓝暗部 + 高反差 | 冷峻悬疑（刑侦夜景） |
| 冷色调 × 高调白色 | 通透明亮偏冷白 | 现代医疗、科技、冷淡都市 |
| 暖色调 × 高调粉 / 明 | 粉暖浅色 + 低反差 | 甜宠、初恋、治愈日常 |
| 暖色调 × 低调深色 | 琥珀暗部 + 暖光池 | 年代、酒馆、怀旧夜戏 |
| 冷暖对比 × 中调灰 | 冷底 + 暖点缀 | 都市情感、职场（主次要明确） |
| 霓虹 × 低调深色 | 荧光色 + 深压黑 | 赛博、都市夜、颓废 |
| 糖果 × 高调鲜 | 浅亮高明度 + 中高饱和 | 儿童、浪漫、轻松喜剧 |
| 小清新 × 高调白 / 粉 | 通透 + 可见光斑 | 青春、校园、日常治愈 |
| 低饱和 × 中调灰 | 整体去饱和 + 保留强调色 | 战争、文艺、现实题材 |
| 暗黑 × 低调深 / 黑 | 光池 + 轮廓 | 恐怖、犯罪、惊悚 |

**组合时守两条**：

1. **一个场次只一个主色系**。可叠加点缀（如暖调中一点冷色），但主色系只有一个，否则观众读到的是"杂"。
2. **影调档优先于色系**。当色系与影调档冲突时（如要求"高饱和"又要求"低饱和灰色调"），以影调档的明暗结构为准，调整色系的纯度——因为明暗是观众最先读取的信息。

## 四、影调两个维度：明度与饱和

影调 = **明度**（画面整体亮暗）× **饱和度**（色彩浓淡）。两者独立取值，组合出七种基本色调。这个分类管的是**全画面倾向**，不是单件物体的颜色。

| 明度档 | 色调 | 饱和度 | 感受 | 画面做法 | 典型用例 |
|---|---|---|---|---|---|
| **高调** | 白色调 | 低饱和 | 清新、素雅、留白 | 大面积浅色，暗部抬到很亮，几乎无重阴影；主体靠材质与线条区分 | 极简、医疗、无印风产品、纯洁关系 |
| 高调 | 粉色调 | 稍高饱和 | 天真、清纯、柔软 | 浅色底 + 粉／杏／奶油点缀，高光泛光，反差低 | 日系人像、初恋、少女向、母婴 |
| 高调 | 明色调 | 高饱和 | 活力、阳光、明快 | 亮底 + 鲜亮色块，阴影浅，色彩分离清楚 | 风景、街拍、旅行、美食、夏日 |
| 高调 | 鲜色调 | 最高饱和 | 强烈、刺激、活泼 | 多色高饱和同框，对比强；**用错即俗气** | 潮流、综艺、广告焦点、少儿 |
| **中调** | 灰色调 | 低饱和 | 内敛、高级、克制 | 中间明度 + 低饱和，色相范围窄，层次靠明暗过渡 | 莫兰迪、静物、时尚、高级感商业 |
| **低调** | 深色调 | 较高饱和 | 沉稳、浓郁、有重量 | 中间偏暗 + 保留色彩浓度，暗部有层次不死黑 | 暗调人像、风光、啤酒/威士忌、复古 |
| 低调 | 黑色调 | 低饱和 | 神秘、厚重、压抑 | 暗部压住 + 去饱和，少量高光或单点色 | 暗黑系、夜景、黑色电影、恐怖 |

**选择顺序**：先定情绪强度与明度档（高调／中调／低调），再定饱和度，最后才选具体色值。不要先挑颜色再倒推感觉——那是配色，不是影调。

**与题材的关系**：题材档给的"调色"字段只是倾向（如"低饱和暖棕"），按本档定位到色系与具体色调档后再落地。

## 五、统一色彩倾向：让画面"像一个整体"

单张画面好看不等于成片好看。成片的色彩统一感来自**共同色偏**——让不同场次的颜色共享一个倾向（统一偏暖／偏冷／统一低饱和／统一抬阴影）。

| 做法 | 效果 | 代价 |
|---|---|---|
| 统一色温偏移（全片偏暖 / 偏冷） | 最快建立整体感，跨场不散 | 用过头会显得单调、像滤镜 |
| 统一饱和度水平（整体降饱和） | 克制、写实、高级 | 高饱和段落失去爆发力 |
| 统一暗部处理（阴影同色相） | 暗部有"品牌感"，冷青或暖褐 | 需与光位一致，否则穿帮 |
| 统一高光色（高光偏暖／偏青） | 决定"高级"还是"数码" | 与白平衡设置绑定，跨镜要一致 |

**纪律**：

- 共同色偏由调色层统一施加，**不能靠每镜单独写不同色值**去凑。
- 共同色偏不得推翻已锁定的光源色温逻辑：冷青阴影必须有冷光源依据（见 [20-lighting-system.md](20-lighting-system.md) §六）。
- **各材质保有自己的中性落点。** 色偏可以统一，但混凝土与灰墙仍是中性灰，金属呈冷灰，肤色保留血色。把三者统一推向同一色相，画面会读成“上滤镜”而不是“在那束光里”；肤色被整体带走时，人物的可辨认度也跟着掉（同本档 §一 各色系“必须有光源依据”的口径）。
- 强调色（故事关键道具、关键情绪）可以**脱离共同色偏**，是唯一允许"跳出"的元素（见 §八）。
- 延续 [13-camera-and-texture.md](13-camera-and-texture.md) §6.3：主／辅／点缀的配比按需，不做每幅固定配额。

## 六、影调记忆：影调即情绪语言

三类色调对应三种情绪主张，是分配影调时的判断依据：

| 主张 | 影调 | 常用手法 |
|---|---|---|
| **清新治愈** | 白 / 粉 / 明色调 | 高调 + 低反差 + 抬起的阴影 + 自然光 |
| **内敛敏锐** | 灰色调 | 中间调 + 窄色相 + 精确明暗层次 + 少强调色 |
| **个性与厚重** | 鲜 / 深色调 | 高浓度色块或深压暗部 + 强对比 + 单点强调 |

判断句式：**"这一段要让观众感到什么" → "因此用哪个明度档、哪个饱和档"**。反过来先堆颜色再看效果，等于没有影调设计。

## 七、色调与叙事：随剧情推进

色调不是一次性设定，是**可以演进的变量**。三种推进方式：

| 方式 | 做法 | 适用 |
|---|---|---|
| **按段落递进** | 开场高调明亮 → 中段转中调灰 → 结局低调深。整体亮度与饱和度随剧情走 | 成长、堕落、真相揭开、时代变迁 |
| **按时间线分区** | 过去用低饱和暖褪色，现在用中性标准，未来用冷青高反差 | 多时空、回忆、闪回 |
| **按人物视角切换** | 不同人物主导的场次有各自色偏（她偏暖、他偏冷），交汇场混合 | 双主角、关系对位、分裂人格 |

**纪律**：

- 每一次影调漂移都要有触发：进入回忆、真相揭露、人物变化、季节更替。
- 切档写法与登记沿用 [13-camera-and-texture.md](13-camera-and-texture.md) §6.6 Register Poles：**写清色温、反差、饱和、颗粒、强调色的取值**，不只写"褪色"。
- 切换后用可读线索承接（光变、曝光、介质、材质、剪辑），不靠抽象标签。
- 切换后写入连续状态，跨组继承（本组末态即下一组起始态）。
- 渐变优于突变：在同一场次内做影调漂移时，靠光源更替（实用灯点亮／日落推进）自然过渡，不硬切。
- **推进不等于放弃一致性**：§二的一致性规则管"同一场景与同一段落内必须统一"；本节管"跨场景与跨段落如何有依据地演进"。两者不冲突——推进发生在**段落边界**上，不在段落内部。

### 7.1 全片影调弧线

在分镜开始前，为全片（或多集）写一条简短影调弧线，避免每场各自为政：

```text
影调弧线：[项目名]
起点：{明度档} + {饱和档} + {共同色偏}（第 __ 场至第 __ 场）
中段转向：{触发事件} → {新档位}
终点：{明度档} + {饱和档}（第 __ 场）
强调色：{跳出共同色偏的颜色}，仅用于 {物件/情绪}
```

只在项目确实需要跨场色彩设计时写；单场或短片可以省略，直接沿用题材档调色倾向。

## 八、作为视觉母题的色彩

某个颜色被**反复使用**并承载含义时，它就从配色升级为叙事元素——色彩母题。设计、登记与复现方式见 [24-visual-motifs.md](24-visual-motifs.md) §三。

本档只负责：母题色的**取值**（精确色相与明度）与**影调兼容性**（母题色必须在该场影调档下仍然可辨，不能被共同色偏吃掉）。

## 九、提示词写法

沿用 [13-camera-and-texture.md](13-camera-and-texture.md) §6.4 一个风格锚点规则与 §6.5 Anti-Slop 替换表。本档补充：

- **抽象情绪词不进提示词**：`治愈`、`高级`、`神秘`、`迷幻` → 写成明暗结构、饱和度、色相与光源依据。
- **色调描述要可执行**：不写"日系色调"或"赛博感"，写"高调、抬起的阴影、低反差、微粉高光、窗光为主"。
- **共同色偏写一次即可**：项目级共同色偏进入风格骨架冻结段逐字复用，不逐镜重写。
- **饱和度的程度词要具体**：`去饱和` 与 `轻微降饱和` 画面差别很大；关键段落写明"保留多少色彩"。
- **色系要带光源依据**：写"冷蓝环境光"必须能说出光源（月光、屏幕、荧光、阴天）；霓虹要写出来源的招牌或反射面。色系不是滤镜层。
- **一个场次只写一个主色系**，点缀色单独标出。
- **暗黑档要写"保留可读的是哪一部分"**，否则模型会把主体一起压黑。

示例：`全片统一轻微降饱和、阴影偏冷的共同色偏；本场为冷色调 × 灰色调，中间明度、窄色相范围、主光为窗外阴天冷光，暗部干净有层次，高光不溢出。`

## 十、检查清单

- [ ] 本场**色系**已明确（冷/暖/对比/高饱和/低饱和/暗黑/霓虹/糖果/小清新之一为主）
- [ ] 本场**影调档**已定位到明度档与饱和档，不是只写几个颜色名
- [ ] 色系与影调档的组合不冲突；冲突时以影调档的明暗结构为准
- [ ] 色系有光源依据，不是无动机的滤镜式偏色
- [ ] 冷暖对比、霓虹等双色系场景已写明主次
- [ ] 暗黑档已说明明度分档与"保留可读的是哪一部分"
- [ ] 影调选择由情绪主张推出，与剧情功能一致（见 §六）
- [ ] **同一场次内所有镜头色系与影调档统一**，反打两侧共享同一设定
- [ ] **同一场景每次出现保持同一色调设定**，变化有叙事触发（见 §二）
- [ ] 全片共同色偏已确定，各场不各自为政；已按策略选择统一基调或场景分区
- [ ] 色调状态表已登记（场景色调表 / 剧情段落色调）
- [ ] 强调色确实跳出共同色偏，且只用于关键物件或情绪
- [ ] 跨场影调切换有触发事件，且按 Register 写法登记取值
- [ ] 共同色偏没有推翻光源色温逻辑（冷阴影有冷光源依据）
- [ ] 共同色偏之下各材质保有自己的中性落点（混凝土中性灰、金属冷灰、肤色血色），未被统一推向同一色相
- [ ] 需要跨场呼应时，色彩母题已在 [24-visual-motifs.md](24-visual-motifs.md) 登记
- [ ] 提示词里没有残留 `治愈`、`高级`、`神秘`、`赛博感` 一类无画面信息的色调词
