# 梦境与幻觉：潜意识的画面翻译

[主观性与 POV](33-subjectivity-and-pov.md) 给出主观性状态的原则（要能分辨、标记要稳定、解除要呼应、段落要留痕）。本档把其中**梦境与幻觉**这一类展开成可落地的写法：怎么让观众认出、内容该是什么、怎么出来、节奏怎么排。

## 一、病根：模糊不等于梦

最常见的错误写法是：人物闭眼 → 再睁眼 → 画面变模糊。

观众看不出这是梦还是现实，会把它当成一次没做好的转场。问题在于**模糊不是梦的语言**——梦是角色的潜意识投射，观众要看见的是"这个人心里藏着什么"，不是一个看不清的画面。

模糊、虚化、晃动只是**手段之一**（边缘处理），单独用它承担不了"这是梦"的说明责任。

## 二、建立：让观众认出"这不是现实"

**判据：梦境出现后的前几秒内，观众能不能独立判断出"这不是现实"。** 判不出来就要重做——观众一旦把梦当现实看、或把现实当梦看，后面的叙事节奏就全乱了。

四条视觉标签，至少选一条做到极致：

| 标签 | 做法 | 说明 |
|---|---|---|
| 色调变化 | 现实彩色 → 梦境高饱和 / 黑白 / 褪色 / 单色 | 最通用、辨识度最高；必须与现实形成明显反差（黑白对彩色、冷灰对暖金），模糊的差异不算 |
| 边缘处理 | 四角虚化 / 边缘发光 / 画幅收窄 | 制造"非现实"的距离感；让画面像"被记忆包围" |
| 光影异常 | 头顶一束光、背后光晕、无来源的光 | 像舞台布景，不自然本身就是信号 |
| 物理异常 | 水珠悬停、花瓣不落、人飘着走、手穿过物件 | **最能节省辨识时间**——看到水珠停在空中的瞬间，判定立刻完成 |

要点：

- 四类可以叠加，但**至少一类要做到极致**。每样都沾一点、每样都不彻底，是最差的组合。
- 优先顺序：物理异常最省辨识时间，色调变化最通用。时间紧就用前者，需要氛围就用后者。
- 标签要**递进铺开**，不要一次交完。有效的顺序是：熟悉的场景（观众先认出这是哪）→ 色调变了（不对劲）→ 世界出现不可能的事（这不可能是现实）→ 触感/物理规律失效（确认是梦）。四步下来不用任何字幕，观众自己完成判定。
- 标记的**具体取值要在片内稳定**（这部片子的梦长什么样应当固定），见 [主观性与 POV](33-subjectivity-and-pov.md)。

## 三、内容：恐惧、愿望或秘密

梦的内容必须指向角色的潜意识，不能是无意义的抽象画面。按三选一确定指向：

| 类型 | 画面指向 | 揭示什么 |
|---|---|---|
| 恐惧型 | 重复同一场悲剧、被追赶、坠落、失去重要的人 | 角色最怕的事 |
| 愿望型 | 失而复得、遗憾被弥补、美好到不像真的场景 | 角色最渴望的事 |
| 秘密型 | 扭曲的记忆、看不清脸的人、被篡改的关键片段 | 角色潜意识里藏着的事 |

- **恐惧型与愿望型最容易上手**：把角色最怕的、或最想要的直接拍出来。
- **秘密型最难，也最有效**：它要同时处理"记忆被扭曲"和"真相被隐藏"两层，但在解谜向的故事里效果最强。写它要保证观众之后能分辨哪些是被扭曲的部分。
- 判据：**这一段梦能不能用一句话说出它揭示了角色的什么**？说不出就是无意义的抽象。
- 梦境不必解释自己。观众看完不需要旁白或对白来说明"他怕的是这个"——画面本身要能回答。

## 四、抽离：标记"醒了"

直接切回现实，观众会延迟一两秒才反应过来"哦已经醒了"。这一两秒里情绪是断的。所以要在切回现实之前或同时，给一个能让人**视觉上感到"出来了"**的过渡动作。

四种方式：

| 方式 | 画面 | 情绪效果 |
|---|---|---|
| 从水中浮起 | 画面模糊 → 光线渐亮 → 破水而出 → 睁眼 | 窒息后的释放 |
| 从暗到明 | 黑屏 → 光点扩大 → 睁眼 → 喘气 | 压迫后的反弹 |
| 坠落中断 | 坠到一半 → 画面闪白 → 惊醒 → 抓床单 | 惊吓的余震 |
| 触感中断 | 梦里抓住了什么 → 切回现实 → 手里是空的 | 失落的实感 |

时长参考：**不宜短于约 1.5 秒，也不宜超过约 3 秒**。太短观众反应不过来，太长拖节奏。这两个界限有理由支撑（反应时间与节奏），所以可以作为规划依据；具体取值按整体节奏调整。

**回归反应**：醒来之后不要立刻进入下一场。留一个短镜承载余波——喘气、流泪、攥紧床单、看四周确认安全。这是梦的情绪落地的位置（对应 [主观性与 POV](33-subjectivity-and-pov.md) 的"段落要留下剧情痕迹"）。

## 五、节奏参考

| 步骤 | 做什么 | 参考时长 |
|---|---|---|
| 进入 | 用视觉标签明确告知"不是现实" | 约 2 秒 |
| 内容 | 恐惧 / 愿望 / 秘密三选一 | 约 6–10 秒 |
| 抽离 | 水中浮起 / 从暗到明 / 坠落中断 / 触感中断 | 约 2–3 秒 |
| 回归 | 喘气 / 流泪 / 攥床单 / 确认安全 | 约 2 秒 |

这是规划参考，不是配额。段落长短按它在整场里的位置决定，与 [剪辑逻辑、时长与切点](29-cut-logic-and-timing.md) 的读取区间一致——关键是四步都在，而不是每步卡在某个秒数。

AI 生成下：**一次生成内不要同时包含现实与梦境两套美术**。进入与抽离都是切换点，按 [跨生成组的接缝](30-segment-joining.md) 分组生成再在后期连接；抽离动作若要在一次生成内完成，只保留一个主导变化（例如只有"破水而出"），不要同时变色又变形。

## 六、反面

| 反面 | 问题 |
|---|---|
| 靠模糊表示做梦 | 观众读成没做好的转场 |
| 与现实的色调差异不明显 | 黑白与彩色、冷灰与暖金要一眼分开，含蓄的差异不成立 |
| 每类标签都沾一点 | 每样都不彻底，等于没有标记 |
| 内容抽象无指向 | 说不出它揭示了角色的什么 |
| 直接切回现实 | 观众延迟一两秒才反应过来，情绪断掉 |
| 醒来立刻进下一场 | 梦的情绪没有落地位置 |
| 用旁白解释梦 | 画面该自己回答"他怕的是什么" |

## 七、复核

- [ ] 梦境出现后几秒内，观众能独立判断"这不是现实"
- [ ] 至少一类视觉标签做到了极致；色调与现实的反差一眼可辨
- [ ] 标签递进铺开，不是一次交完
- [ ] 梦境内容能用一句话说出揭示了角色的什么
- [ ] 用了抽离动作，时长落在可反应的区间内
- [ ] 醒来后有回归反应承载余波
- [ ] 四步都在（进入／内容／抽离／回归）
- [ ] 标记与梦的"长相"在片内稳定
- [ ] 一次生成内没有混装现实与梦境两套美术
