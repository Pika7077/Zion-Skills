# 声音设计、对白与音画关系

本档处理声音制作路径、对白与口型、听觉焦点、空间声场、主观声音、物理声响及音乐关系。包含生成音频时，目标模型的适用能力与入口边界见 [模型适配](10-engine-constraints.md)；采用自然语言与时间段描述，不将旧 `[AUDIO]`、花括号或尖括号模板声称为官方专用语法。

## 制作路径：按轨选择

录音路径不是全片只能三选一。对白、歌唱、音乐、动作声、环境声可分别选择，再组成混合流程：

| 路径 | 适合解决什么 | 主要代价与检查 |
|---|---|---|
| 预录/先录 | 歌舞、口型、节拍或动作必须跟随既定声音；先锁定音乐、台词或节奏参考再设计画面 | 表演与剪辑要服从已定时间线；确认现场或生成入口怎样播放/引用预录素材 |
| 同期/生成内声 | 希望表演、空间和声音在同一次记录中自然对应 | 环境噪声、口型、串音和多说话人可控性较低；不能把“自然”当作自动清晰 |
| ADR/后期配音 | 修复对白、精确控制字词、表演与混音，或制作语言版本 | 重新匹配口型、呼吸、空间混响、距离和表演力度；后期自由不等于无需现场或画面依据 |
| 后期拟音/音效设计 | 补足接触、材质、环境、转场或心理声音 | 声源与时点仍需可追踪；风格化替换要说明叙事目的 |

不默认 ADR 是所有项目的主路径，也不把同期声限定为纪实类型。按项目场景、表演、入口能力、预算和后期条件逐轨决定；选择后记录哪些声音已锁定、哪些随画面、哪些待后期完成。

## 声音构成与声景

声音常见三大板块是人声、音乐与音效；制作时把音效继续拆成动作/拟音、环境底噪和特殊设计声，才能检查来源与连续性。

每个场景先建立声景基线：

- **地域与空间**：远处交通、风、虫鸣、设备、邻室人声等能说明地点的声音。
- **空间性质**：室内外、开阔/狭窄、硬/软表面、遮挡与开口怎样改变混响和高频。
- **时间与状态**：昼夜、天气、人员密度、设备启停及剧情造成的环境变化。
- **听取位置**：观众跟随谁、处在空间哪里；同一声源随距离、方向、遮挡和镜头/视点改变怎样变化。

环境声可以在画面切入前先建立地域与压力，但必须有可追踪来源或有意的主观归属。只添加“城市氛围声”“电影感环境音”而无空间特征，不能形成声景。

## 台词与口型

原句、说话人、语言及顺序保持一致。角色音色给稳定特征，临时语气写在本句。可见发声者嘴部对应台词；画外声、OS、电话和录音明确来源，画中听者不承担口型。

对白可跨正反打或物件镜头持续播放，完整句子只在声音时间线上记录一次，标出覆盖区间。不要为了音频填满而新增台词。静默明确时长与正在等待的事件。

目标生成方式难以稳定保持跨镜语音时，在制作说明中安排连续配音或后期音轨，不将一句台词重复生成多遍。

多人对话明确谁先谁后，重叠只在原剧情需要时使用。复杂重叠导致不清楚时，提出错开或后期分轨方案，不冒称“一镜只能一张嘴”。

## 对白要写清“怎么说”

对白有三项：谁在说、说了什么、**怎么说**。前两项由说话人和台词文本承载，第三项最常被漏掉。缺了它不只是声音变平，人物的表情也会跟着变平——写明说话方式，是在同时给声音和脸下达指令。

写法：把语气紧贴角色名，放在台词前、同一字段内，不新增字段：

```text
台词：【角色名（语气）："台词原文。"】
```

语气按四项写，只写本句有戏剧功能的部分：

| 维度 | 写什么 | 例 |
|---|---|---|
| 情绪色 | 这句此刻的底色 | 冷笑 / 强撑镇定 / 压着怒 / 试探 |
| 力度 | 音量与用力 | 低语 / 气音 / 一字一顿 / 拔高 |
| 音质 | 嗓音质地 | 沙哑 / 发颤 / 干涩 / 破碎 |
| 节奏 | 速度与断句 | 急促 / 拖长 / 断续 / 平直 |

- 默认状态不必写：“平静”只在它是**反常的平静**（强压怒火）时才值得写。
- 允许写演进，用箭头表示一句话内部的变化：`（强撑→崩）`。
- 每句不超过三个词。堆到五个以上会互相抵消，模型抓不住重点。
- 禁结果词：开心、难过、生气、邪魅。它们既不是音质也不是力度，是结论；写不出来就先问“这个人此刻在撑什么”。
- 无台词的镜头写“台词：无。”，不补语气位。

### 语气词与画面词的分流

判据一句话：**麦克风能录到的写进语气位，摄像机拍得到的写进画面段。**

| 上游写法 | 归属 |
|---|---|
| 嗓音质地（沙哑／气音／发颤／撕裂） | 语气位 |
| 音量力度（低语／嘶吼／一字一顿） | 语气位 |
| 发声方式（冷笑／嗤笑／讥诮／拖长音） | 语气位 |
| 肢体可见变化（俯身／攥拳／后退半步） | 画面段 |
| 面部可见变化（咬肌隆起／眼眶红／嘴角抖） | 画面段 |
| 混合写法（俯身，冷笑地说） | 拆开：肢体进画面段，发声方式进语气位 |

把“嘶哑”“冷笑”留在画面段，模型会把它当**画出来的样子**处理（画一张冷笑的脸），而不是发声方式。这类错位比漏写更糟，因为它还会污染画面。

声音层不受画面段“不堆形容词”的纪律约束——声音没有肌肉动作可写，质地词（嘶哑、低沉、气声）正是它需要的。声音层同样禁结果词：写“嘶哑”可以，写“难过”不行。

## 语速与对白时长

按语速粗估：慢速约 2.5–3.2、克制约 3.0–3.8、普通约 3.3–4.2、急促约 4.3–5.2 汉字/秒，另计标点和表演停顿。这是规划估计，不是保证；不能为塞台词擅自加速。

判断顺序：拆句 → 只数可发音字符（标点不计）→ 加标点停顿（句内逗号约 0.1–0.3 秒，句末约 0.3–0.6 秒）→ 按本句语气选档 → 得对白时长 → 对照本镜预算。

- **语气直接决定语速档**。语气位写“气音／低语／一字一顿”时按慢档估算，不能仍按普通语速倒推镜长——这是“台词塞不进镜头、只好把镜头拉长”的常见原因。
- 连续急促（约 5 字/秒以上）不宜持续超过约 3 秒，否则口型与气息都会失真。
- 单句过长（约 24 字以上）时，按因果落点或反应落点拆成 2–3 镜，每镜约 18 字以内。拆的是镜头，不是台词：原句不删词、不加速、不改写。
- 关键金句之后留一个短的同场反应镜头（约 0.3–0.8 秒）承载余韵，不给台词。这不是配额，而是“说完一句重话之后总有人要反应一下”；缺了它，重话会显得没有落地。
- 声音连续播放与简单动作可以并行；关键文字读取和复杂动作需要独立注意力。记录并行与串行关系后算本组占用时长，不把整组时长重复给每句对白使用。

## 画外声：内心独白（OS）与旁白（VO）

画外声不承担口型，也不是台词的补充。它有三条纪律。

### 一、画面里的角色必须闭口

内心独白发声时，画面中的人物嘴不能动——嘴一动，观众就以为他在说话，声画分离当场破裂。

这条要在**画面段留下闭口证据**（嘴唇紧闭、嘴角无起伏、下颌不动、呼吸平稳），而不是靠一句“不要张嘴”的否定指令。画面用可见的克制承载声音的张力：瞳孔收缩、手指收紧、视线停在某处、雨水落在睫毛上。

### 二、篇幅要有节制

画外声一多，成片读起来像有声书。以单集为单位给声音容量分一下：画面与动作留白约占一半，声音容量约占一半；声音容量里角色开口台词占大部分，内心独白与旁白合计不超过约三成。折算到 15 秒一组的尺度，画外声约 20 字上下是舒适区。

### 三、旁白不翻译画面

判据：**把旁白删掉，画面信息量没有减少**——这句旁白就是复述，删。

旁白该给的是画面给不出的东西：与画面形成反差的另一层信息、冷静的时间刻度（“第三千天”）、观众知道而角色不知道的事。

反面写法：画面里她走在雨里，旁白说“她感到极其绝望”——既复述画面，又替观众下结论。

- 正当用途：段落收官的一句定调、人物登场时钉住身份与处境的一句自述、情绪顶点后把具体的账摊开、时间刻度、信息差投放。
- 不写的：交代世界观与前情（设定该由画内的物证与冲突自己长出来）、复述正在发生的事、用独白解释情绪以省掉一场戏。
- 不与相邻镜的画外声连排，也不在段落收尾处紧贴断句——画外声结束后留一镜画面或对白作缓冲。

### 四、字段归属

台词字段只装画内开口的对白；内心独白与旁白写进声音层，标明来源与音色，台词字段写“无”。给画外声加“贴着嘴唇说”一类写法，会诱导模型补出张嘴动作。

画外声随画面生成还是后期贴声，按项目已确认的交付方式决定；无论走哪条路，闭口证据都要写在画面段。画外声台词不计入口型与语速预算（无口型可锁），但计入成片时长。

## 三层功能：齐缺与取舍

按**功能**看，一场戏的声音回答三个不同的问题。这与下一节的听觉焦点是两个维度：本节看**层是否齐、该留哪层**，下一节看**某一条声音此刻在前景还是后景**。

| 层 | 回答什么 | 典型内容 | 检验方式 |
|---|---|---|---|
| 基础层 | 这是哪里、多大、什么状态 | 环境底噪、空间混响、持续设备声 | **抽掉它，空间是否显得虚假**——它靠“存在”起作用，不靠被听见 |
| 叙事层 | 此刻发生什么、谁在说什么 | 对白、同期声、动作与拟音 | 承担关键信息时保证可懂度；**优先级与音量不是固定值**（见下一节） |
| 情感层 | 观众该怎么感受 | 配乐、关键音效、心理声场 | 只能被观众听到；要能说出它为什么在此刻进入、何时退出 |

**常用取舍**（是判断方向，不是配方）：

- **空镜与环境段**：基础层为主，其余可让位——观众要的是感受这个空间。
- **沉默镜头**：情感层单独进来；沉默本身就是设计，见下方「客观声场与心理声场」的设计静默。
- **对白场**：叙事层优先，其他层让路。“让路”指的是**可懂度与注意力**，不是音量排序——把对白一律推到最大，正是本档已废止的旧口径。

**诊断：听觉扁平先查缺层，不加音轨。** 一场戏读起来单调时，先问“三层里缺了哪一层”，而不是继续叠声音——层不齐时加得越多越糊。反过来，音轨数量本身不是问题：叙事声常需按来源与空间位置分组，见下方「空间声场与先声入画」。

## 混音层级与听觉焦点

前景声是当前需要观众主动听取的对象，后景声负责空间、连续性和情绪铺垫。它们是**叙事位置**，不是固定音轨类别：一句耳语、脚步、倒计时、风声或音乐都可以在某一时刻进入前景，随后退回背景。

- 对白承担关键信息时优先保证可懂度；若故事要表现失语、隔绝、耳鸣或主观无助，可以有意压低、遮蔽或抽掉对白，但要让观众明白这是表达选择而非混音事故。
- 物理音效承担动作结果时，可以暂时压过音乐；关键小声可借对白停顿进入前景，不必夸大成重击。
- 环境底噪通常保持空间连续，镜头切换后可随听取位置变化，但不能无理由重启或换成另一空间。
- 配乐、人声、音效和环境声尽量保留分轨或可独立调整的交接；最终响度与动态范围按项目交付规范处理，不在分镜中设通用数值。

每次焦点转移要能回答：观众此刻该听什么、为什么现在听见、其他声音怎样让位、下一镜是否继承。

## 客观声场与心理声场

**客观声场**维持空间可信度：声源位置、距离、朝向、遮挡、材质、混响和衰减与画面关系一致。声画同步可按观众理解和剪辑节奏适度简化；只有距离本身承担剧情时，才需要突出可感知的延迟。

**心理声场**服务人物感受与叙事情绪，可以选择性放大、压低、过滤、重复、拉长、替换或暂时抽走声音：

- 放大呼吸、摩擦、心跳或倒计时，集中注意力；
- 压窄频段、弱化外界或加入耳鸣，表达主观隔绝；
- 用不写实的声音替代真实撞击、动作或环境声，建立隐喻或冲击；
- 设计静默：明确哪些声音被抽走、保留什么细节、持续到哪个事件结束，而不是把“没有声音”当空字段。

偏离物理真实时写清**听觉归属、进入触发、持续范围、退出方式和叙事目的**。若观众需要把它当成现实声源，就保留空间证据；若是主观或象征声，就用视点、反应、频谱变化或重复方式建立规则，避免被误读为连续性错误。

## 空间声场与先声入画

- 声源的左右、前后、高低只在项目播放规格与实际声道支持时精确交付；普通交付仍需写清方向、距离和遮挡关系。
- 沉浸式或多声道设计要从叙事运动出发：声源怎样进入、经过、离开，观众为何需要追踪；不因支持全景声就把所有环境声铺满空间。
- **先声入画（J-cut）**：下一场声音先于画面进入，用于预告地点、人物或压力；写明新声何时进入、当前场哪些声音仍保留。
- **声音延续（L-cut）**：上一场声音跨过画面切换继续，用于承接因果、情绪或一句话的余波；写明结束点与新画面的声源关系。
- 同一声音桥可以同时保持连贯并标记新空间；不能因为声音连续就忽略画面已经换场。

## 物理声响

接触、摩擦、振动、脚步和液体声音对应具体声源及触发时点。强弱符合材质、力度与距离，余响随环境衰减；避免所有动作都添加重击声。

反应发生在刺激被感知之后。底噪保持连续，剪辑不无故重启环境音。关键纸响、杯底触桌等小声可在对白停顿显露，不靠把声音夸大到不真实。

## 配乐与字幕

默认聚焦对白、动作声与环境底噪；用户要求配乐或字幕时保留并安排。不得同时输出“有字幕”和“无字幕”。重要精确文字可提出后期叠加方案；不自行删除原文信息。

## 复核

- [ ] 对白、音乐、动作/拟音、环境与特殊设计声分别选择了预录、同期/生成内或后期路径，未套全片单一路径
- [ ] 三层功能齐缺已检查：基础层抽掉是否显虚假、情感层能说出进入理由、叙事层承担的关键信息可懂；听觉扁平时先查缺层，未靠加音轨解决
- [ ] 场景声景写清地域、空间性质、时间状态和听取位置，不是泛化“氛围声”
- [ ] 有台词的镜头都写了语气位，且语气词没写进画面段
- [ ] 语气位无结果词，每句不超过三个词
- [ ] 对白时长落在本镜预算内；慢档语气已按慢档估算
- [ ] 过长台词已按落点拆镜，原句未删词未加速
- [ ] 金句后有反应镜头承载余韵
- [ ] 画外声镜头的画面段含闭口证据；画外声写在声音层，台词字段写“无”
- [ ] 旁白删掉后画面信息量不减；无连排、不贴段落断句
- [ ] 听觉前景与后景随叙事焦点变化；承担关键信息的对白可懂，有意遮蔽时目的与范围明确
- [ ] 客观声场的距离、方向、遮挡、混响与衰减有依据；心理声场写清归属、触发、范围和退出
