# 人物关系构图：关系 → 取景语法

补五维镜头语言之外的**关系层**。同样两个人、同样景别，站位、朝向、视线和占比不同，读出的关系完全不同。本档服务导演标准第一原则里的**人物对位**与**人物与场景构成**两个维度。

本档不新增机位参数：景别、机位高度、观察方式、构图仍按 [camera-vocabulary.md](camera-vocabulary.md)；运镜按 [13-camera-and-texture.md](13-camera-and-texture.md) §三。

本档管**关系如何被构图表达**（静态的取景结果）；涉及**人物移动、摄影机跟随与信息交接**的调度方法见 [场面调度](34-staging-and-blocking.md)。

## 一、七个可控要素

| 要素 | 控制什么 |
|---|---|
| 距离 | 亲疏、可接触程度 |
| 朝向 | 对视 / 平行 / 背向、是否开放 |
| 高度差 | 权力与心理位置 |
| 画面占比 | 主次、谁主导这一镜 |
| 遮挡 | 谁可见、谁被隐去 |
| 视线 | 关系是否成立、谁在看谁 |
| 留白方向 | 前方留白=前路与余地；身后留白=被推走、无退路 |

## 二、关系 → 取景语法

| 关系 | 取景语法 | 观众读出 |
|---|---|---|
| 对等同盟 | 等高平视、画面均分、朝向一致 | 并肩、同心 |
| 对峙 | 左右分置、等高、中间留空、正侧或过肩 | 势均力敌、僵持 |
| 压制 | 一人前景大、一人后景小；或明显高低位差 | 权力不对等 |
| 求助 / 依赖 | 一人在画框边缘、身体前倾、视线向上 | 弱势、请求 |
| 疏离 | 大空间把两人分开、各居一侧、视线不交 | 关系断裂 |
| 亲密 | 同框近距、肩线重叠、浅景深、视线交错 | 情感靠近 |
| 隐瞒 | 前景遮挡挡住半张脸、背身、视线回避 | 有秘密 |
| 监视 / 被看 | 过肩或遮挡框、前景背影压住后景主体 | 被观察 |
| 受审 / 孤立 | 一人背对镜头的剪影在前景，被看者在后景正面 | 被审视、无援 |
| 群体中的异类 | 众人同向，一人反向或独占空白 | 不合群、被排斥 |
| 保护 | 前景人物身体朝外、把另一人挡在身后 | 庇护 |
| 告别 | 一人在画内，一人已出画或只留局部 | 离开、未完成 |

## 三、站位与画面分区

- **左右分置**：对等或对峙；观众默认先读左侧。
- **上下分置**：权力差。上位者在上，除非刻意反用。
- **前后分置**：主次与纵深。前景大、后景小 = 压制或引导；前景虚、后景实 = 注意力在后。
- **三角形**：三人稳定结构；一人脱离三角即打破同盟。
- **错位 / 不对齐**：不稳定，用于关系正在变化。

**轴线**：同一场戏内不要为了让构图好看而随意把两人换边——世界位置不因机位改变。跨轴要有可理解的重建过程（见 [camera-vocabulary.md](camera-vocabulary.md) §切镜复核）。

## 四、视线

- 视线相接 = 关系成立；视线错开 = 隔阂或回避。
- 视线高度 = 心理位置：谁俯视、谁仰视。
- 视线方向决定轴线；主观镜头必须与视线对象匹配。
- 听者的视线变化，比听者的表情更有信息量。

## 五、人物与场景构成

| 构成 | 读出 |
|---|---|
| 人小景大 | 渺小、被环境吞没、无力 |
| 人大景小 | 压迫、聚焦、无处可退 |
| 人物被门 / 窗 / 框切割 | 被限定、被困、被观察（框中框） |
| 人入光区 / 留在暗处 | 被揭示 / 被隐藏（配合 [20-lighting-system.md](20-lighting-system.md)） |
| 人物与关键道具同框 | 道具成为关系的中介（递、挡、扣、推回） |
| 人物前方留白 | 前路、余地、未说完的话 |
| 人物背后留白 | 被推走、无退路、孤立 |

## 六、使用规则

- 关系的变化优先用**调度**表现：走位、距离、朝向、遮挡的可见变化，而不是靠台词说明或堆特写。
- 一次只改变一到两个要素，观众才能读出是哪一项在变。
- 关系反转时，机位高度与画面占比应与之一致（不要低位却显得弱势），见 [13-camera-and-texture.md](13-camera-and-texture.md) §一 权力差规则。
- 无配额：各类关系取景不限次数，按剧情需要选择。
- 同框人数不是限制；三人以上按可读性组织，不因人数自动拆镜（见 [aspect-ratio-directing.md](aspect-ratio-directing.md)）。

## 七、检查

- [ ] 同框时两人的关系能用一句话说清吗
- [ ] 权力关系与机位高度、画面占比是否一致
- [ ] 视线与轴线是否匹配，越轴是否有重建
- [ ] 关系变化在画面里看得见吗（而非只在台词或旁白里）
- [ ] 人物与场景的构成服务剧情，还是只是好看的摆拍
- [ ] 留白方向与场景意图是否一致
