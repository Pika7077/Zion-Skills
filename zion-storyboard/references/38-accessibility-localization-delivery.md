# 38 · 无障碍、本地化与最终交付设计

本档在项目要求字幕、多语言、无声观看、色觉可读、闪烁风险控制或多平台交付时读取。具体阈值由用户、平台、发行方或已核验规范提供；没有来源时记录待确认，不把经验值写成通用硬门槛。

## 一、先建版本矩阵

按项目需要记录：

| 维度 | 可能变化 |
|---|---|
| 平台与画幅 | 横版、竖版、方形、不同 UI 遮挡 |
| 语言 | 字幕、画内文字、配音、标题与片尾 |
| 声音 | 有声、静音可读、立体声/其他声道版本 |
| 内容版本 | 品牌、地区、年龄分级或客户差异 |
| 技术交付 | 分辨率、帧率、编码、码率、封装、文件命名 |

只制作实际需要的版本。共同内容继承同一镜头身份，差异项独立登记，避免复制后各自漂移。

## 二、字幕与画内文字

- 关键文字避开已知平台 UI、裁切和交互控件区域；安全区以目标平台模板或项目规格为准。
- 字号、行数、停留和换行以最终显示尺寸、语言长度和阅读任务验证，不在导演稿中套通用数值。
- 字幕与画内重要细节同时出现时，安排注意力次序；不要让观众在同一时刻读两处关键文字。
- 背景复杂或亮度变化时，使用项目允许的描边、底板、阴影或位置调整保持可读。
- 精确文字保留可编辑源，不把生成结果中的近似字当正式字幕或品牌文字。

## 三、无声观看与声音可达

- 项目要求无声可理解时，检查关键关系、动作结果和转折是否只存在于对白、画外声或音效中。
- 可用字幕、画面行为、图形提示或前后镜头补足，但不机械把所有声音逐字贴到画面。
- 需要区分说话者、画外声或重要音效时，按项目字幕规范记录身份与声音提示。
- 对白、旁白、音乐和音效的最终响度、峰值与声道要求由交付规范提供；缺少规格时列为待确认，不宣称已通过混音验收。

## 四、不只靠颜色传递信息

- 阵营、状态、按钮、路线或警告若只靠颜色区分，增加形状、位置、文字、纹理或动作等第二通道。
- 调整颜色时不能破坏已经建立的叙事色彩逻辑；优先增加辅助编码，而不是随意换色。
- 在最终尺寸和实际背景上检查主体、字幕与图形的明暗分离；“使用互补色”不自动等于可读。

## 五、闪烁与强刺激

- 有频繁明暗变化、快速图案、高对比闪烁或强烈镜头震动时，标记具体时间段、来源和叙事必要性。
- 能用持续光、降低变化幅度、延长变化过程或改用声音/剪辑表达时，提供保真代价最小的替代方案。
- 是否满足发行要求必须按目标规范和实际成片检测；分镜阶段只能标记风险，不能用文字自检冒充结果通过。

## 六、本地化

- 翻译后文字长度、断行、阅读方向和字号可能改变，给画面和载体保留可调整空间。
- 双关、押韵、文化符号、手势、日期、单位和画面内文字列为本地化关注项，不自行假设所有地区理解一致。
- 配音版本重新核对台词时长、口型依赖、反应镜头和音乐空位；不只替换音轨文件名。
- 不同语言素材使用独立版本与文件映射，保持镜头、场次和资产 ID 可追溯。

## 七、最终交付前的分工

分镜负责预留空间、注意力顺序、替换路径和版本差异；实际成片由 `zion-qa` 按真实文件、目标规范和最终播放条件验收。缺少平台模板、音频规格或成片时，写“待验证”，不写“已适配”。

## 八、自检

- [ ] 实际需要的平台、语言、声音与内容版本已列明
- [ ] 字幕和画内文字在最终显示条件下有可读路径
- [ ] 要求无声观看时，关键叙事不只依赖声音
- [ ] 颜色不是状态、阵营或操作信息的唯一编码
- [ ] 闪烁与强刺激风险已定位，是否合规留待真实成片与目标规范验证
- [ ] 本地化可能改变文字长度、口型和文化理解的部分已标记
- [ ] 技术交付参数有来源；未知项未被写成已通过
