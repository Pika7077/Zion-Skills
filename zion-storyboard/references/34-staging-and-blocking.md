# 场面调度：人物移动与摄影机的配合

调度是在一个连续空间里安排人物与摄影机的移动，让观众在正确的时刻看到正确的关系。本档给**调度本身的方法**；分散在其他档的相关素材按下面的索引查，不重复。

本档只补这些档都没有的那部分：**一次调度怎么组织、什么时候该用调度而不是切镜、摄影机与人怎么配合。**

## 一、一次调度的结构

三段：**起始状态 → 移动 → 落点**。

- **起始状态**：人物在哪、朝哪，摄影机在什么位置，观众此刻知道什么。
- **移动**：谁在动（人物、摄影机、或两者同时）、往哪动、过程中什么被遮住、什么被揭示。
- **落点**：移动结束后新的关系或信息是什么。

判据：**把落点拿掉，这次调度还剩什么？** 什么都不剩，说明它只是在动，不是在调度。

## 二、调度还是切镜

同一个信息交接，两条路都能走：

| | 调度（镜内完成） | 切镜 |
|---|---|---|
| 换来什么 | 空间的连续感、关系的渐变 | 省时间与生成成本、控制更精确 |
| 代价 | 时间长、生成难度高、落点不易控 | 空间的连续感被打断 |
| 什么时候用 | 变化本身需要被“看着发生”（距离改变、权力转移、态度转变） | 只需要观众“看到新信息” |

判据：**这次变化的过程本身有没有戏**？有——走近的每一步都在施压、后退的每一步都在失去——就用调度；没有，只是想知道谁来了，就用切镜。

不要为了“显得高级”而调度。一次没有戏的移动只会拖慢节奏。

## 三、摄影机与主体的四种关系

移动不只是“跟着走”。四种基本关系：

| 关系 | 做法 | 效果 |
|---|---|---|
| 跟 | 与主体同速同向 | 陪伴、共行；观众与主体同步 |
| 等 | 提前到落点，等主体进入 | 预期、压迫；观众先看到结果 |
| 迎 | 朝主体移动（相对运动） | 加剧、逼近；距离快速压缩 |
| 让 | 摄影机让开，把位置交给主体或另一人物 | 交接、让位；视线接管 |

- 一场戏里可以交替使用，但每次更换都要有原因。
- **等**最容易被忽略也最有用：观众先看到主体要去的方向有什么，紧张感来自“他知道吗”。
- **让**用于焦点或主导权的交接：摄影机让位给新人物，等于把叙事主导权交出去（与 [镜头语言](camera-vocabulary.md) 的权力群像接力一致）。

## 四、人物走位的四个变量

人物移动改变的是这四样，每次移动至少改变一样：

| 变量 | 改变什么 | 例 |
|---|---|---|
| 距离 | 与对手或物件的远近 | 从隔桌到贴近 |
| 朝向 | 面对谁、背对谁 | 从并肩到转身相对 |
| 高低 | 站、坐、蹲、俯身 | 从站到坐，视线关系倒转 |
| 遮挡 | 谁在谁与镜头之间 | 从并排到一人挡在另一人前面 |

四样可以在一次移动里同时变，但要指明哪一个主导。只写“走向对方”，等于没说清变了什么。

## 五、调度的因果

每一次移动都要有原因，且原因要在画内：

- **有动机的移动**：被叫住、让开、递东西、逃避、接近、遮挡。
- **无动机的移动**：为了走位而走位——观众会觉得“这人怎么突然站起来了”。
- 环境也可以逼出移动：桌子的位置、房间的窄、门的方向（见 `zion-assets` 的场景一致性与状态阶梯档）。
- 移动的**结束**同样要有原因：停在某处是因为遇到了什么，而不是因为走位图到这里。

## 六、轴线与空间限制

- 人物移动时轴线容易漂。移动前先确认：移动后两人的相对位置关系是否还成立。
- 需要越轴时按 [镜头语言](camera-vocabulary.md) 的规则重建（镜内过轴、中立镜过渡、方向动作重置），不在移动中悄悄换边。
- 窄空间与竖屏：可用空间有限时，**纵向的高低变化比横向走位更有效**（见 `zion-assets` 的场景一致性与状态阶梯档、[画幅导演](aspect-ratio-directing.md)）。

## 七、AI 生成下的调度

- **一次生成内的移动幅度有限**：多次位移、多人交叉容易丢失位置关系。多数情况下把一次调度收敛成**一条连续路径、一个主导变量**。
- 需要多次交接的复杂调度，拆成几段分别生成，接缝按 [跨生成组的接缝](30-segment-joining.md) 处理（末态具体化、换机位、空镜过渡）。
- **落点要写进生成提示词**（停在哪、谁与谁处于什么关系），否则模型会自行收在任意位置。
- 多人调度写明每个人的路径与因由，避免模型自行分配位置。
- 与 [动作编排规则](action-choreography-rules.md) 的分工：本档管空间位置与关系变化；接触动作的施力与受力因果归动作档。

## 八、复核

- [ ] 每次调度都有落点；拿下落点后这次移动不剩什么
- [ ] 已判断用调度还是切镜：变化过程本身有戏才用调度
- [ ] 摄影机与主体的关系明确（跟／等／迎／让），更换有原因
- [ ] 人物走位至少改变距离、朝向、高低、遮挡之一，且写明主导项
- [ ] 移动有画内动机，不是只为走位
- [ ] 移动后轴线关系仍成立，或已按规则重建
- [ ] 一次生成内的路径与变量已收敛；复杂调度已拆段并处理接缝
- [ ] 落点已写进生成提示词
