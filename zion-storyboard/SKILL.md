# Zion Storyboard：导演分镜与视频制作

负责“故事如何被拍出来”。先设计事件、场面调度、信息揭示和连续状态，再选择景别、机位、运动、灯光、转场、声音和生成分组。资产身份与图像提示词由 `zion-assets` 管理。

## Zion 家族统一规则

**第一原则：分镜服务剧本。** 判断标准是是否最好地展示剧本中的时间过程、故事走向、人物情绪、冲突、场景、人物对位、人物与场景构成、旁白和画外声。镜头数、运镜种类、长镜头段数、固定镜头占比、特写次数和观察方式没有默认配额。详见 [导演决策标准](references/directing-policy.md)。

冲突优先级：

1. 用户本轮明确要求，以及已确认的平台、画幅、时长、视频模型和交付范围。
2. 原剧本中的事实、对白、人物关系、关键道具、行动结果和揭示顺序。
3. 已登记资产及其身份、版本和可用状态。
4. 空间、时间、物理、身份和声音连续性，以及内容可读性。
5. 已核验的视频模型限制。
6. 导演选择、风格参考、模板和历史经验。

默认允许补充不改变剧情的表演、环境互动、普通陈设和物理反馈，并标明补充范围。用户要求严格原文时只调整拍法。改变剧情、增删对白、改变人物动机或突破明确时长前，需要用户选择。

分镜不得在镜头提示词中重新设计资产。已有资产使用稳定 ID 和真实引用；缺失资产写入需求清单，交给 `zion-assets`，不能假装已经上传或绑定。

## 任务范围与需求缺口

继承对话中已确认的材料、参数和授权；只询问确实影响当前交付、又无法从上下文合理判断的缺口。可将相互关联的问题一并提出，不把下列项目变成逐项问卷：

1. 输入材料及完成度：大纲、剧本、已有分镜或生成失败样本。
2. 交付范围：粗分镜、正式导演分镜、画幅适配、视频提示词或局部优化。
3. 原文保真程度：严格原文、允许表演与环境补充，或允许返回剧本阶段补写。
4. 发布平台、画幅、总时长、单集时长与集数。
5. 需要视频提示词时的目标模型、版本/入口和单次生成时长。
6. 视觉风格、节奏和明确禁改项。
7. 已有资产登记、实际参考文件和待制作缺口。
8. 声音、口型、字幕、旁白和配乐要求。

在已授权范围内直接作常规导演选择，并记录影响交付的假设；不要求用户说出特定代选口令。剧情、对白、人物动机或明确时长的实质变更仍需用户选择，难以判断时给出具体选项。纯导演稿不询问视频模型；视频提示词未指定模型时默认 **Seedance 2.5**，记录在 `meta.target_model`，用户可覆盖。其普通单次上限为 30 秒；未给更短预算时按此上限规划，实际组长由内容决定，不凑满。项目总时长仅在确实限制叙事或交付时澄清。默认采用不等于用户逐项确认或已通过生成验证。

## 承接与让渡

- 纯剧本创作、改编、对白或正文细化：`zion-script`。
- 人物、场景、道具、服装变体、其他资产及图像提示词：`zion-assets`。
- 已有剧本/大纲的粗分镜、正式分镜、镜头优化、画幅适配和视频提示词：本档。
- 独立审计、投喂前检查和生成结果验收：`zion-qa`。

普通交付前检查属于本档职责，不因存在 `zion-qa` 而省略。

其他技能未安装时，继续完成本技能可处理的分镜与普通自检；使用用户提供的资产登记或真实文件，缺失项列为待制作并给出可交接需求。不假装调用成功，不因缺少整个 Zion 套件阻塞可完成的部分。

## 按交付范围制作

- 粗分镜：聚焦事实、空间、事件覆盖和资产缺口，不先补全正式 JSON 或模型参数。
- 正式导演稿：完成逐镜拍法、时间与连续状态，不要求模型提示词或上传绑定。
- 视频生成稿：在导演稿基础上核对目标模型、单次预算与真实引用，输出自足生成块。
- 局部优化：只读取与指定镜头/字段有关的参考，检查受影响的前后状态；已有事实和参数直接继承，不重新走完整建档流程。直接交付修改结果；仅当需要完整结构化导出时才使用下方脚本。

以下步骤按上述范围选用：

### 1. 建立事实与空间

提取对白、行动及结果、场景时间、在场人物、进出场、道具归属、伤情、声源和信息揭示顺序。区分原文事实与导演补充。

建立文字空间草图：出入口、人物位置与朝向、行动路径、视线对象、关键物件、光源和摄影机轴线。画面左右可随机位变化，世界位置不能漂移。

新建场次或需要重排内容时读取 [画面内容设计](references/visual-storytelling.md) 和 [导演决策标准](references/directing-policy.md)；对白调度见画面内容设计的对白章节。需要用**空间与视角承载人物情绪**时见 [画面内容设计](references/visual-storytelling.md) §三——顺序是**先写核心情绪、再选能物理承载它的空间、最后用视角外化**：空间的净空与体量、密度与朝向、遮挡与开口要能说出哪条在给人物施压或掩护（说不出就是美术不是情绪；换到中性空间若照样成立，说明空间没在承担情绪）；视角可以随心态走一条线（陌生／藏身／融入），但角度与情绪不是固定映射；压力靠环境、细节、比例三层叠加，且三层压的是同一件事。分镜的第一标尺读 [三步引导法](references/27-guidance-three-steps.md) §一——**观众关心的有意义变化**：每镜要能说出带来了什么变化、观众为什么在意；整场只有全景交代与正反打时，逻辑通顺但一处变化也没发生（用替换性检验：换成任意两人任意房间是否照样成立）。先写一句"这场要让观众产生什么感受、由哪个可见变化带来"，再挑画面；核心加篇幅收景别，次要合并缩短。悬疑、揭秘、反转类场次或任何有"答案"的场次（找物、找人、等结果、对峙前），再做**找重点 → 找节奏 → 找关系**的逐场自检：等待要分清"不知会不会发生"（等结果，靠隐藏与插入新悬念）与"知道一定会发生"（等时间，靠细节持续新增"它更近了"，画面只给这一件事）；危险可用**环境预示**承担——铺预期（聚焦环境的危险属性而非人物动作）→ 揭示 → 释放，把人物动作换成同类动作后预示仍成立才说明压力在环境上。打斗、追逐或复杂接触动作再读 [动作编排](references/action-choreography-rules.md)。

### 2. 粗分镜与资产需求

先按事件、关系和空间设计必要覆盖，形成不依赖虚构资产的粗分镜。列出真正需要的人物角度、场景方向、道具状态、服装变体、动作/白模或声音身份。

读取 `zion-assets` 交付的资产登记与交接结果。先核对 `project_id`、`source_script_version` 和 `source_scene_ids`，再无损保留每项资产的 `asset_id`、`ref`、`version`、`status`、`files` 与 `target_reference`。具有真实文件的 `approved` 资产可进入正式导演稿；包含视频生成提示词时，实际使用的资产必须为 `uploaded` 且具有目标入口引用。缺失项标为待制作并交回 `zion-assets`，不得伪造引用。

### 3. 设计事件与反馈

梳理目标、阻力、尝试、反馈、选择和局势变化。先写观众能看见和听见的过程，再决定切镜。

物理互动写清施力主体、接触部位、方向/阻力、材质或身体反馈、声音时点和可继承末态。没有互动时不硬加敲桌、攥拳、飞尘或装饰性微表情。

### 4. 配平时长与生成组

读取 [剧本保真与时长](references/script-fidelity-gates.md)。先安排对白、声音、必要视觉读取和动作过程，再确定组长。允许能同时发生的声音与轻动作重叠，不机械累加。

生成组按所选模型的已核验上限与本项目预算拆分，并落在可继承状态；默认模型按上述 30 秒上限规划。生成组不等于叙事段落；镜头数、特写数、运镜种类和视角数量没有默认配额。**一段多镜还是逐镜独立生成**按 [模型适配](references/10-engine-constraints.md) 的生成粒度判据选：同一连续世界里的切换可组内写切点，跨越时间／空间／概念则逐镜生成、在后期完成段落结构。

同一连续场次被拆成多组时读取 [跨生成组的接缝](references/30-segment-joining.md)：末态要写成可开拍的画面、接缝两侧换机位或换景别、必要时用带任务的空镜过渡。组内切镜按 [剪辑与转场](references/22-editing-and-transitions.md) 与 [剪辑逻辑、时长与切点](references/29-cut-logic-and-timing.md)。

### 5. 选择拍法

选型需要时读取 [镜头语言](references/camera-vocabulary.md)（含用局部替代脸的判据）；定焦段、机身或需要质感层写法时读 [摄影机与质感词库](references/13-camera-and-texture.md) §二；新定画幅或改编画幅时读 [画幅导演](references/aspect-ratio-directing.md)。先按镜头任务选景别与观看位置，再定观察关系、构图和运动；`pov_family`、`camera_height`、`camera_angle` 分开记录。

**透视由拍摄距离决定，焦段只决定视角宽窄**。先定观众站得多远、主体尺度与透视强度，再选焦段与光圈；不得由焦段反推机位距离，也不得用焦段区间表判定景别或判错。

画面出现扁平、平淡或"像记录而非创作"时，读 [层次感](references/28-layered-depth.md) 做四维自检——空间破平面、光线破单调、颜色破融合、表演与叙事破直白。四层不必用满，每镜留 1–2 层真正服务的即可。

涉及镜内揭示、匹配剪辑、隐藏剪辑、声音桥、场次衔接或序列/大段落边界时读取 [剪辑与转场](references/22-editing-and-transitions.md)：先判断同场切镜、场次转场还是段落分隔，再确定本次更重连贯、分隔或两者兼顾。要**用同比例构图硬切跨时空**（旅拍、开箱、过程类内容常用）时见同档的 [剪辑与转场](references/22-editing-and-transitions.md) §一·3——两端保持相同比例构图并共享一个元素（同一动作相位、同一物件、同位置同类物、同一节拍），判据是把 A 末帧与 B 首帧并排后轮廓、位置、占比或运动方向至少一项能对齐；**两端锚点必须在计划阶段就写成分镜锚点，后期只对齐不发明**。判断**相邻两镜为什么这样接、每镜该多长、切点落在动作哪一刻**时读取 [剪辑逻辑、时长与切点](references/29-cut-logic-and-timing.md)——该档用视觉变化量、动势匹配与动作阶段给出可复核判据，是 [剪辑与转场](references/22-editing-and-transitions.md) 的比例与阶段补充。

**一组镜头**要表达一段时间、一种情绪或一个概念（蒙太奇段落、闪切、交叉剪辑、分屏同时信息、用镜头语言代替表演）时读取 [蒙太奇段落](references/32-montage-sequences.md)：先分清这组镜头是只在“连接画面”，还是也在“操控情绪”；**意义来自组合与顺序**——写完换个顺序读一遍，意思不变就说明它只是流水记录。段落按功能（时间／情绪／概念／节奏）与关系（连续／平行／对比／隐喻）两个维度选用；分屏只在同时呈现能产生关系时采用，各面板默认分别生成后合成；闪切在 AI 流程里要靠裁切、截取或后期插入实现，不能写成独立生成任务。要把**不宜直拍的内容**（伤害细节、私密、病态过程）换成可拍画面时，见 [蒙太奇段落](references/32-montage-sequences.md) §九——三类替代任务与**两道闸门**：意象既要与本场此人处境有具体关联，又要让观众凭已有联想读得出；替代换掉的是画面，不是信息。题材与平台允许出现什么画面属项目规则，不由技能裁定。要**靠重复累积情绪**时见 [蒙太奇段落](references/32-montage-sequences.md) §十：重复必须有情绪任务并能说出累积的是什么——节奏型（快承担波动、慢承担落地）、景别型（长焦小景别反复压缩空间、特写反复标记重点）、隐性（多轮几乎相同的处境，画面差值极小而累积发生在观众侧，到观众能预判即停）。

**跨时空**（时间跳跃、双线并行、倒叙插叙的切换）读取 [跨时空转场](references/31-cross-time-transition.md)：先定时间关系与“是否要让观众察觉这次切换”，再按镜内／镜间两族选手段，并按可生成性分级选路；镜内族是 AI 生成的高风险项，规划时要给降级路径。

**主观视点**（POV 段落、梦境与幻觉、记忆变形、不可靠叙述）读取 [主观性与 POV](references/33-subjectivity-and-pov.md)：POV 要给出视线来源、保持主体不入画、用呼吸与脚步做在场感（防悬浮），并调整声音次序；主观状态的进入与解除都要有稳定标记，且要留下剧情痕迹。其中**梦境与幻觉**的画面翻译（四类视觉标签与优先级、内容指向、抽离方式与四步节奏）读 [梦境与幻觉](references/35-dream-and-hallucination.md)。判断**该用客观还是主观、两者怎么组合**时见 [主观性与 POV](references/33-subjectivity-and-pov.md) §三——客观给世界与事实、主观给感知与情绪，每处切换都要能说出观众获得了什么（说不出就是轮换拍法）；三种组合任务是建立关系张力（互相的主观或过肩内反拍）、强调被环境压住（先客观环境再切主观）、揭晓关联（主观后切回客观）；顺序上**先建立可感的客观场域，再用视角进入**。

灯光按 [光影系统](references/20-lighting-system.md) 落到有动机光源、光位、硬软、阴影、反差和色温；一个场景内需要光随时间演变时读该档 §十二。多人同框按 [人物关系构图](references/21-relationship-composition.md) 确定站位、朝向、视线与占比。需要安排人物移动、摄影机跟随与信息交接（一次调度怎么组织、什么时候该用调度而不是切镜、摄影机与主体是跟／等／迎／让）时读 [场面调度](references/34-staging-and-blocking.md)。

定色调时读 [色彩与影调](references/23-color-and-tone.md)：该档给**两套并行分类**——**色系**（冷/暖/冷暖对比/高饱和/低饱和/暗黑/霓虹/糖果/小清新，管色相阵营）与**影调档**（明度×饱和七色调，管明暗强度）；先选色系定方向，再用影调档定强度。色值与调色词仍取 [摄影机与质感词库](references/13-camera-and-texture.md) §六。

需要色彩承担**象征、区分时空与视角、组织全片走向**时读 [色彩的结构功能](references/36-color-as-structure.md)：色彩的含义由作品自己建立（不套通用色义表）、互补色对只留必要的一对、结构功能一色一义、开工前排出色彩脚本。判断**同一套配色该往哪个情绪方向走**时见 [色彩的结构功能](references/36-color-as-structure.md) §三——方向由**面积主次与归属、明暗与饱和深浅、光源来源**三个变量决定，不是由色相对应某一个情绪：冷占满环境而暖只在远处是包围感，暖只落在人物自身则是孤独中的专注；压暗加饱和走向秘密与危险，提亮柔化走向浪漫与童话；邻近色与单色主导的情绪靠光质与影调实现（单色只剩明暗可分层）。

**同一场景与同一剧情段落内，色系与影调保持统一**；跨场景切换色调必须有叙事触发，并按策略预先拍板走「统一基调」还是「场景分区」。反打两侧必须共享同一套色调设定。一致性规则见 [色彩与影调](references/23-color-and-tone.md) 的「场景与剧情的色调一致性」一节，推进规则见该档的「色调与叙事」一节。

需要跨镜复现道具、颜色或构图意象时读 [视觉母题与呼应](references/24-visual-motifs.md) 并登记母题表；设计一部戏或一集的第一镜与最后一镜时读 [开场与结尾设计](references/25-opening-and-ending.md)。母题数量无配额，没有值得复现的意象时不强设。设计**人物第一次出现**时见 [开场与结尾设计](references/25-opening-and-ending.md) §1.5——最省的做法是拍别人看他：旁观者的凝视（每次要有新增信息）、环境的反应（常态被打乱）、光影随他经过而变；判据是**删掉主角的镜头、只留旁观者反应，观众还能说出他的分量**。隐藏型人物先明确"隐藏"的目的，保留一个可继续识别的稳定特征，数量靠删镜检验收敛而不是按配额凑。

关键镜头生成风险高、已有素材组接不匹配、需要复杂合成、精确文字、替换版本或明确后期修复时读 [后期可救性与合成交接](references/37-post-and-recovery.md)：先按 [剪辑逻辑、时长与切点](references/29-cut-logic-and-timing.md) 区分连续性故障与有意断裂，再按实际风险规划调和、桥接、注意力转移、有效覆盖、头尾余量、分层素材、可替换区域与降级路径，不给每镜强加备用镜头，也不用插入镜掩盖事实错误。项目要求字幕、多语言、无声观看、色觉可读、闪烁风险控制或多平台交付时读 [无障碍、本地化与最终交付](references/38-accessibility-localization-delivery.md)，具体阈值只继承有来源的项目或平台规格。

每次真实剪辑独立编号；长镜头内部使用时间阶段，不拆成虚假镜头。焦段、光圈和摄影参数只在影响画面或制作时写入；机身与镜头只作为风格描述，不进入生成提示词的硬参数位。

### 6. 视频提示词

目标模型为 Seedance 2.5 时读取 [Seedance 渲染器](references/seedance-prompt-renderer.md)、[提示词卫生](references/12-prompt-hygiene.md) 和 [音频与对白](references/15-audio-and-lipsync.md)；目标为 MiniMax H3 时改读 [MiniMax H3 适配](references/16-minimax-h3-adapter.md)，上游判据不变、只换输出壳；其他模型只使用已核验规格。输出结构见 [输出契约](references/output-schema.md)。

提示词卫生档给出可复核判据：主体数量写准（单主体句、指代带归属、首镜有主体锚）、能画出来才写（不可命名的过程形态与程度副词删掉）、**写多少由风险决定**（删掉这句模型可能画错什么，答不出来就删；参数与质感词下沉到项目级风格层，不在每镜复述）、正向优先于否定（排除概念时改写描述而非加“不”）、**画面内文字分三种需求**（须读清／只需存在但不读清／完全不要）、示例句只从已验证产物回收。涉及声音制作、表演与对白时读 [声音设计、对白与音画关系](references/15-audio-and-lipsync.md)：按轨选择预录、同期/生成内声或后期路径，建立声景、检查**三层功能（基础／叙事／情感）的齐缺与取舍**，再处理动态听觉焦点、语气位、语速、画外声、心理声场与声音桥。

保留详细导演稿；生成提示词只写目标模型需要的可见、可听指令。资产用真实入口引用映射，身份已锁定时不重复设计外观。反射、多人、文字、连续接触和复杂时空变化按具体风险处理，必要时给替代拍法或后期方案。

### 7. 检查与交付

按交付范围选用 [交付前检查](references/17-stage5-checklist.md)，检查原文保真、时长、连续状态、对白、资产引用和生成组自足性；有后期、本地化或多版本要求时一并检查可救路径、版本矩阵与待验证规格。修正后同步更新受影响的后续状态。已有生成失败样本时再读取 [失败模式](references/11-failure-modes.md)。完整 JSON 可使用以下导出与检查工具：

```text
python scripts/export_output.py input.json --validate
python scripts/export_output.py input.json --audit
python scripts/export_output.py input.json --format markdown --output output.md
```

脚本通过只代表结构检查通过，不等于艺术质量或生成结果已经验证。输入文档或视频需要预处理时可运行 `python scripts/parse_input.py <file>`。

## 交付形式

| 请求 | 默认交付 |
|---|---|
| 粗分镜 | 参数摘要 + 空间草图 + 事件覆盖 + 资产需求清单 |
| 正式导演分镜 | 参数与补充范围 + 资产引用表 + 逐镜导演分镜 + 连续状态 |
| 分镜加视频提示词 | 正式导演分镜 + 按模型时长拆分的自足生成块 |
| 局部优化 | 只交指定镜头/字段的修改结果与受影响连续链 |

每镜写 `source_scene_id`、时间、拍法、完整画面过程、实际资产引用、必要物理反馈、对白/声音、切点和承接状态。禁止用“同上”省略独立生成块所需信息；导演稿可以引用项目级公共参数，避免机械重复。

可复跑的行为判据见 [人工案例](tests/manual-regression.md)；自动结构与导出行为的覆盖见 [脚本回归](tests/test_storyboard_audit.py)。
