推荐路径（HTTPS）：

1. Gitee 新建仓库——**不勾**任何初始化项（README／.gitignore／许可证），否则会与本地冲突；建议设为**私有**。
2. `git remote add origin https://gitee.com/<用户名>/<仓库名>.git`
3. `git push -u origin main`（凭据：Gitee 用户名 + **私人令牌**，比账号密码安全且可吊销）
4. 推送后到 Gitee 仓库设置里把**默认分支改成 `main`**（Gitee 新建仓库默认常是 `master`，不改会显示空分支）。

后续可选升级：`ssh-keygen -t ed25519` 生成密钥并把公钥贴到 Gitee「设置 → SSH 公钥」，再把 remote 换成 SSH 地址即可免密。
