# 10 · 生理性叙事与表演词库

> 剧本阶段的核心动作：把抽象情绪词翻译成可拍摄的身体事实。
> 分镜阶段由 `zion-storyboard` 按镜头景别、动作可读性与当前情绪变化取用；不把本档的表情单元当成必填配额。

---

## 零、核心公理

> **用肌肉下达指令，不用情绪标签。** Direct a face by muscle, not by mood.

**FACS 是"描述物理而非描述情绪"这条规则的肌肉级实现。** 它最能出效果的场合，恰恰是"两个相似表情之间的差异承载意义"的地方：

- **假笑**（forced smiles）
- **压抑**（suppressed expressions）
- **混合情绪**（mixed emotions）
- **诡异感**（the uncanny）

**反 AI 自检问句**：*这段是像从提示词模板出来的，还是像导演看完演员排练后写的笔记？*
微节拍应当**被观察到**，而非**被生成出来**。

### 混合规则（Mixing for nuance）

> **有意思的表情都是混合体。** 把两种情绪的 AU 都列出来，让冲突自己被读出来。

| 想要的效果 | 配方 |
|---|---|
| 强行装温暖 | 真诚笑肌（AU6+AU12）与恐惧肌（AU1+AU7）**同帧对抗** |
| 苦涩的愉悦 | AU12（无 AU6）+ 微弱 AU4 |
| 安静的崩溃 | AU1 + AU15 + AU17 + AU24（眼含光、下颌紧、在硬撑） |

## 三、生理注册配方表（最贴合 Zion 的"生理性叙事"）

> **这些是菜单不是清单。** 只挑 **2–4 个 tell**，八项的愤怒配方是供你选词的词库，**绝不是一次全渲染的堆叠**。

| 注册（Register） | 生理配方 |
|---|---|
| **愤怒 / 决绝** | 咬肌在颌部可见搏动 · 颈动脉搏动可见 · 太阳穴青筋起 · 重音词上鼻翼扇动 · 瞳孔收缩 · **外眼角变硬**（真实强度，不是廉价眯眼）· **高潮处不眨眼** · 眉与鼻翼渗出细汗 |
| **焦虑 / 紧张** | 一次可见吞咽（喉结）· 开口前一次短浅鼻吸 · 舌舔干下唇 · 下唇微向内抿 · 颊部毛细血管泛红 · 关键词上瞳孔放大 |
| **悲伤（无泪）** | 外眼角下坠 · 眼含光但**绝不落下** · 皱眉肌在眉间打结 · 唇微颤 · 头下沉几度 |
| **掌控 / 冷静 / 优越** | 平稳均匀的呼吸（与紧张的对手形成对照）· 手指松弛 · 缓慢从容的眨眼 · 下巴微抬 · **渐进建立**的杜氏笑，**绝不以成品笑开场** |
| **沉重 / 被压垮** | 肩下沉 · 头略低 · 深而慢的呼吸 · 回答时 **5–15°** 小歪头 |
| **震惊 / 僵直** | 触发点僵住 **0.3–0.5 秒**，完全不动 · 僵住中瞳孔放大 · 唇无声张开 · 僵住解除后一次延迟的锐利鼻吸 · 目光锁在触发物上，不眨眼、不游移 |
| **压抑（最难）** | 写成**生理性抵抗**：面部每块肌肉都在对抗涌上来的情绪 · 咬肌缓慢收紧 · 一次延迟而费力的吞咽 · 眼渐蓄光至发亮，**泪不落** · 一次缓慢深吸气，胸腔可见起伏 · 下颌一次颤动，随即重新咬紧 |

### 默认值

- **除非剧本明确要求，否则不写眼泪**——"眼含光但不落下"是悲伤的默认读法
- **不写卡通式鬼脸**；思考时不写"眼睛望天花板"，改用具体注视方向
- **没人只是站着说话**——永远有微动作
- **绝不完美同步**：群体反应按每人 **0.3–0.5 秒错峰**（"陈屿先转头；0.4 秒后苏汐；再 0.4 秒后陈黎"）。三个人绝不同步
- **虚焦里的听者不是雕像**：即使完全散焦，也要写头/视线方向、肩部微动、错峰反应——模糊的静止读作人偶

## 四、八大情绪通道（行为层，与 AU 解剖层互补）

> 通道说身体**做什么**；AU 说**哪块肌肉**动。二者是行为层与解剖层的兄弟关系。

| 通道 | 观察什么 |
|---|---|
| **Breath** | 速率、深度、屏息、呼气的性质 |
| **Eye behavior** | 注视、眨眼率、视线方向 |
| **Jaw tension** | 咬紧 / 松弛 / 在动 / 定住 |
| **Loss of focus** | 视线漂移、注意滑脱、反应延迟 |
| **Scanning pattern** | 扫视路径与被追踪的目标 |
| **Delayed recovery** | 刺激到回到基线的滞后 |
| **Control attempt** | 可见的压制努力 |
| **Emotional residue** | 高潮过后身体上残留的东西 |

## 五、身体四参数（先于任何心理）

| 参数 | 取值与含义 |
|---|---|
| **Center of gravity** | 高（胸/下巴）= 自信、攻击性；低（肩/塌陷）= 疲惫、恐惧、顺从 |
| **Tempo** | 快而乱 = 紧张；**慢而省 = 掌控——最危险的人动得最少** |
| **Openness** | 开放 / 封闭的躯干与肢体 |
| **Breath** | 高而快 = 恐慌；低而慢 = 掌控。**呼吸是最诚实的状态指标**，且声音必须符合物理：刚跑过的人不可能气息平稳地说台词 |

### Proxemics 距离表

| 区间 | 距离 | 含义 |
|---|---|---|
| Intimate | **<0.5 m** | 爱或暴力，擅入即侵略 |
| Personal | **0.5–1.2 m** | 信任 |
| Social | **1.2–3.5 m** | 事务 / 戒备 |
| Public | **3.5 m+** | 疏离 / 等级 |

> **距离改变 = 节拍改变，且必须以米为单位写进剧本。**

### Status（地位）

- **High**：头不动、动作慢、长注视、回答前停顿、占据空间、碰别人的东西
- **Low**：忙乱、频繁自体触摸（脸/发）、断句、填充式笑、用眼神请求许可
- **最精彩的是 status break**（地位反转）

### States, not transitions

> 模型搞不定过程、拿得准状态。
> ❌"把手伸进包里，掏出刀，扬起来" → ✅"投掷中途，手臂已展开"

### 眨相速记（静态镜头里买到活脸最便宜的方法）

`一次慵懒的眨眼 → 一次快速的双眨 → 一次用力的重置眨眼`

### Degradation accumulates

角色跨故事被消耗，身体要累积携带——更灰、更沉、反应更慢，**绝不场景间重置**。

## 六、台词三段式节拍（每句台词必写三段）

| 段 | 内容 |
|---|---|
| **Pre-line beat** | 第一个字之前：一次吞咽 / 一次吸气 / 舔唇 / 姿态转换 |
| **During the line** | 重音落在哪个词，通过什么承载：鼻翼扇动、语调、瞳孔位移 |
| **Post-line beat** | 约 **0.5 秒**的屏息或锁定注视，然后才是释放 |

**示例**：
```
开口前：一次短促鼻吸，一次可见的吞咽。
台词："别再问我了。" ——重音落在"再"上，鼻翼在该词上扇动。
台词后：目光锁定在对手身上 0.5 秒——然后才移开。
```

## 八、Eye Life（强制字段，永不省略）

- **micro-saccades**（微跳视）
- **与状态绑定的眨眼率**：压力下 rapid blink-bursts / 掌控中 slow calm lids / 解离时 blink-and-glaze
- **live catchlights**——但**眼神光是渲染属性不是解药**："带着漂亮眼神光的呆滞凝视仍然是呆滞凝视"。死眼靠**给眼睛一个任务**来修，不靠打光
- **Eyes lead the thought**（视线先于转头抵达目标）
- **Controlled stillness is chosen, never dead**（受控的静止是主动选择，不是死掉）

## 十、Acting Master Profile 模板

```
{角色名} 的表演。[体型、体格、姿态——身体即其传记]。[心理引擎，一句话]。
声音档案：[音高/音色，口音/籍贯，语速与表达方式，情绪下声音如何破或变]。
关键肢体习惯与抽动：[标志性 tic + 触发条件；压力 tic + 触发条件；掩饰行为；
                    那张面具，以及它在什么确切条件下裂开]。
眼的生命：[眨眼质地与频率，扫视模式，视线先于转头，眼神光]。
步态：[带引号的专名 + 重量、节奏、落脚方式]。
然而，当 {情绪触发}，{转变}。[可选：唯一一个软化对象]。
```

**八条块规则**：
1. 只写可观察行为（不写"他紧张"，写"下唇颤抖 / 沉重吞咽 / 用嘴长吸一口气、从抿紧的唇间锐利呼出"）
2. **每个 tic 都要有 trigger**（`[tic] + [何时/为何]`；无触发器的 tic 是装饰，有触发器的是戏剧结构）
3. 给步态起**引号里的专名**（"权力步"、"攻城锤式步伐"、"老拳手的走法"）再展开重量/步幅/躯干手臂/头
4. **每个档案至少一个 "However, when X…" 子句**（面具 + 裂缝）
5. 只给**一个**软化对象
6. 不写服装
7. 不写机位与颜色
8. **体型承载传记**

篇幅参考：**150–220 词一段**；每场 **2–4 个 beat changes**（少于则表演扁平）。

## 十一、Zion 剧本阶段的落地纪律

### 11.1 落地纪律

- 对白长度按实际语速和表演停顿验证，不用固定字数替代时长判断。
- 情绪落地用 §二 AU 配方 + §三 生理注册配方给出**具体替换词**。
- 动作行只写**状态**不写过程（"投掷中途，手臂已展开"），不重复台词已说的事。
- 生理节拍写进动作行，不额外增加集均台词句数。

### 11.2 情绪翻译三步（写每一场都走）

1. **命名情绪节拍**并定 AU 集（例："她把恐惧伪装成安抚" → 恐惧 AU1+AU2+AU4+AU5 在 AU12 单独构成的假笑下闪动）
2. **挑 2–4 个生理 tell**（从 §三 的菜单里选，不是全抄）
3. **落成可见行为**写进动作行（肌肉 / 呼吸 / 皮肤 / 手，不写情绪标签）

### 11.3 硬限制

- 每次生成（每个镜头）**最多 3–4 个表情单元**
- **每个节拍 1–2 个 AU**
- **只做本场景真正需要的 3–6 个表情的小表**——禁止生成完整 49-AU 表再从中挑（把模型摊薄、标签不可读、白付 45 个用不上的面板）
- 角色参考图**可选**——AU 码在无图的文生视频下照样生效
- **必须仍写完整场景**（构图/光/情绪槽都在），纯 AU 码列表太薄

### 11.4 自检清单

- [ ] 全文无"他很愤怒""她很悲伤"式情绪标签，全部为肌肉/呼吸/皮肤的可观察描述
- [ ] 每个重要情绪节拍都挑了 2–4 个（不是 8 个）生理 tell
- [ ] 群体反应已错峰，无三人同步
- [ ] 每句重要台词有三段式节拍
- [ ] 每个主要角色有 Acting Master Profile，且至少一个 "However, when…" 子句
- [ ] 每个角色的每个 tic 都有触发条件
- [ ] 情绪有惯性：强事件后的余波带进了下一拍
- [ ] 距离变化以米为单位写出
- [ ] 角色跨集消耗有累积，未场景间重置
