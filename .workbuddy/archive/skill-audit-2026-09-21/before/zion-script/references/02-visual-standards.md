# 视觉标准

视觉标准来自用户、平台、题材和项目已经确认的风格。无明确要求时采用自然、写实、剧情驱动的基线。

保持跨镜连续的项目级参数包括画幅、时代、主要色彩关系、人物与场景资产、主要光源逻辑和材质方向。画幅未确认时逐项询问；用户授权代选后才从平台推定或推荐 9:16。

摄影机品牌、镜头体系、帧率、快门、颗粒、景深和运动方式只在会影响画面或制作时指定，不设统一硬值。真实感项目可强调自然皮肤、材质使用痕迹、合理曝光与光源；风格化项目按其视觉契约执行。

负面约束按目标模型支持方式与当镜风险选择，不能与用户要求的字幕、文字、音乐、风格或动作冲突。未经核验的禁词和固定负面串不得当成平台规则。
