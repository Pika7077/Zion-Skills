# Zion Script：剧本创作

负责“写故事与剧本”。产出深度跟随用户要求，不默认扩张为完整制作包。

## Zion 家族统一规则

遇到冲突时按以下顺序处理：

1. 用户本轮明确要求，以及已经确认的平台、画幅、时长、模型和交付范围。
2. 用户提供的原始故事事实、对白、人物关系与修改权限。
3. 本次交付契约：内容完整、可读、时长可行、跨场连续。
4. 已核验的目标模型或平台限制；未核验的经验不得写成硬限制。
5. 风格偏好、模板和默认值。

发布平台、画幅和叙事相关的视觉倾向均以用户确认结果为准。用户授权“你定”时，可从平台推定画幅；仍无依据时推荐 9:16，并记录该选择。剧本阶段不询问或预设生成模型。

用户未指定交付物时，交付满足请求所需的最小完整结果，不附加资产表、逐镜生成提示词、小说版或宣传文案。

## 逐项需求澄清

开始创作前检查需求是否已经达到可执行状态。只继承用户已经明确给出的信息，不用默认值代替尚未确认的关键创作选择。

信息不足时必须逐项提问：

1. 每轮只问一个最关键的问题，不把多个决策合并成问卷。
2. 用户回答后记录该项，再问下一项；已经明确的内容不重复询问。
3. 用户拿不准时给 2–3 个具体选项并说明推荐项，但等待用户选择。
4. 用户明确说“你定”“按推荐”或授权自由发挥时，才可替用户选择该项，并把选择记录在需求摘要中。
5. 在所有必需项明确前，不输出正式剧本；可以简短说明当前已确认内容和下一项问题。

剧本创作依次确认：交付物类型；故事核心或原始材料；短片/短剧及平台；总时长或单集时长与集数；题材和基调；主角、目标与核心冲突；结局方向及允许补全程度；画幅和其他硬要求。只询问当前任务真正需要的项。

用户同时要求图片或视频提示词时，本档先锁定剧本事实，再把图像提示词交给 `zion-assets`、视频提示词交给 `zion-storyboard`；不在剧本阶段代替下游选择模型或制作投喂稿。

## 承接范围

- 从创意、题材或一句话故事创作剧本。
- 扩写、改编、重写、续写或细化已有剧本。
- 设计故事结构、场次、对白、人物弧线和必要的视觉动作。
- 用户明确要求时，附加节拍表、场次表、简版镜头构想或制作备注。

以下请求交给对应 skill：

- 人物、场景、道具或其他资产的提取、设计、图像提示词与登记：`zion-assets`。
- 已有剧本或大纲要制作级导演分镜、画幅适配、资产引用或视频提示词：`zion-storyboard`。
- 文件、可读性、提示词或生成结果验收：`zion-qa`。

若请求同时包含创作和制作，先在本档完成或补齐剧本事实，再按需要由 `zion-assets` 建立资产、由 `zion-storyboard` 完成分镜；不得在后续阶段重复改写已确认内容。

进入下游前给项目分配稳定 `project_id`、剧本版本 `script_version`，并给每场分配不随标题或顺序轻易变化的 `scene_id`（如 `SC001`）。修订剧本时递增版本并列出受影响场次，供资产、分镜和 QA 判断旧交付是否失效。

## 工作方法

1. 建立故事约束：题材、目标观众、时长、平台、核心人物、冲突和用户要求保留的事实。
2. 选择适合内容的结构，不强制三幕式、固定钩子时点或固定反转频率。
3. 写场次与对白。每场应有目标、阻力或信息变化，但不要求套同一种节拍模板。
4. 把关键情绪落实为可观察的表演、行动、空间距离或声音；FACS 只在它能提高表演精度时使用，不强制逐句编码。
5. 检查人物动机、信息顺序、时长、前后状态和结尾完成度。

用户要求严格原文时，只做授权范围内的编辑。用户允许创作补全时，可以补充合理的场景、表演和过渡，但不得悄然改变核心关系、动机或结局。

## 输出契约

| 请求 | 默认交付 |
|---|---|
| 写剧本 | 项目参数简述 + 场次式完整剧本 |
| 扩写或改写 | 修改后的目标段落或完整版本 + 必要的改动说明 |
| 故事设计 | 一句话故事 + 人物与冲突 + 结构大纲 |
| 要求制作信息 | 仅附用户点名的节拍、简版镜头构想或制作备注；图像/视频提示词交给对应下游 Skill |

剧本中需要呈现的信息写清楚；不为了填表强制输出固定 43 项、固定人物字段数、固定镜头数或完整摄影参数。只有用户明确要求制作级逐镜稿时，才读取分镜参考；这类请求通常应路由到 `zion-storyboard`。

## 质量标准

- 人物选择有动机，结果由行动和因果产生。
- 台词符合人物身份，避免重复解释观众已经看到的信息。
- 关键情绪可以被表演、听见或通过行为推断。
- 重要人物、道具、伤情、时间和信息跨场连续。
- 时长约束存在时，朗读、动作和停顿总量可实现。
- 风格、摄影器材、帧率、钩子位置和闭环形式均按项目需要选择，不设全项目通用硬值。
