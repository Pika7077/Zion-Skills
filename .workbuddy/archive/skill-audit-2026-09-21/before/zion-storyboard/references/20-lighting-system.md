# 光影系统：光位、光比、配光、继承

**单一来源档。** 布光技术表与灯光律以本档为准，其它档只引用、不复制。题材资产对应的光源倾向见 `zion-assets` 的题材风格预设档；调色与色彩配比见 [13-camera-and-texture.md](13-camera-and-texture.md) §六。

核验日期：2026-09-20。

## 一、四层结构

先确定观众此刻应怎样理解主体，再按四层落地。不是所有镜头都要逐项长写；项目灯光律已经锁定的内容可以继承，但本镜发生变化的项必须显式说明：

1. **光位**——光从哪个方向来。
2. **光比**——亮部与暗部差多少。
3. **配光层级**——有几层光，各管什么。
4. **光质与色温**——什么性质的光、什么颜色。

最后检查可见结果：阴影落在哪里、边界是否清楚、暗部保留多少细节、主体是否仍可读。抽象情绪词只留在导演稿；生成提示词应写成这些可见条件。

## 二、光位

| 光位 | 位置 | 可见结果 | 常见任务与边界 |
|---|---|---|---|
| 正面平光 | 摄影机轴附近 | 脸平、阴影少、无立体感 | 商业、古风轻喜剧、甜宠、参考图 |
| 前侧 45° | 主光从前侧上方照入 | 面部立体，背光侧保留层次 | 通用人像与对话；鼻影与面颊亮区构成三角时才称伦勃朗光 |
| 侧 90°（Split） | 正侧方 | 半脸亮、半脸暗，纹理与轮廓被强化 | 冲突、秘密或犹豫；柔和窗边侧光也可是日常与生活感 |
| 侧逆 / 逆光 | 后方 135–180° | 头发和身体边缘被勾亮，正面亮度取决于补光 | 登场、未知、回忆、离别或危险；逆光不自动等于剪影 |
| 顶光 | 人物上方 | 眼窝、鼻下和下颌阴影加深，可形成独立光区 | 硬顶光可用于压力与审视；柔顶光也可用于孤独、仪式或决断 |
| 底光 | 人物下方向上 | 阴影方向反转并向上延伸，五官结构被重塑 | 冷色手电/应急灯可不安或威胁；暖色篝火可亲密或秘密，不默认等于恐怖 |
| 环境混合 | 多点 | 层次丰富、写实 | 内景、夜戏 |

**位置不是情绪标签。** 光位只决定阴影和高光从哪里来；叙事意义还取决于硬软、反差、色温、补光、环境与上下镜。

### 2.1 六种常用叙事手段

六种手段不属于同一分类轴：顶/侧/逆/底光是**方向**，伦勃朗光是**面部明暗结构**，体积光是**光与空气介质的空间效果**。它们可组合，但每一项都要有可见原因与镜头任务。

| 手段 | 必须写清 | 常见叙事用途 | 失败判据 |
|---|---|---|---|
| 顶光 | 光在正上方；硬/软；眼窝、鼻下、下颌阴影 | 压力、审视、孤独、仪式或决断 | 只亮头顶，面部没有对应的向下阴影 |
| 侧光 | 左/右方向；明暗分界；暗部保留多少细节 | 冲突、秘密、犹豫，或自然窗光下的生活感 | 暗部全黑却仍要求读清表情；左右方向跨镜漂移 |
| 逆光 | 背后的具体光源；边缘光；正面补光或剪影选择 | 登场、未知、回忆、离别、危险或转折 | 又要完全剪影又要读清面部；边缘光没有来源 |
| 伦勃朗光 | 前侧上方主光；鼻影与背光侧面颊三角亮区 | 克制、迟疑、内心冲突或选择前的停顿 | 只写“半张脸暗”，没有可辨识的鼻影与面颊结构 |
| 体积光 | 雾、尘、烟、雨等介质；光束方向；落点人物/物件 | 空间纵深、入口、线索、启示、梦境或召唤 | 只写“光束”而无介质；光路没有引向叙事焦点 |
| 底光 | 场景内的低位光源；向上阴影；暖/冷色与反常程度 | 篝火秘密、停电、地下空间、威胁或不安 | 无合理低位光源；不分情境地做成廉价恐怖脸 |

## 三、光比

| 光比 | 观感 | 适用 |
|---|---|---|
| 1:1 | 无影、平 | 商业、古风轻喜、甜宠、**参考图与设定表** |
| 2:1 | 轻影，仍有立体 | 现代甜宠、家庭、治愈 |
| 4:1 | 立体明显 | 剧情叙事标准档 |
| 8:1 | 暗部压住，张力强 | 悬疑、刑侦、都市暗黑 |
| 16:1 以上 | 极端明暗 | 黑色电影、恐怖、舞台感 |

表中数值是前期沟通的近似档位，不是生成模型可精确执行的测光值。最终仍要写清“暗部有细节 / 接近黑位 / 完全剪影”等可见结果；需要读表情时，不得只给高光比而不说明暗部细节。

参考图与人物设定表优先使用便于读取多视图的版式，避免场景光污染身份；具体版式由 `zion-assets` 按实际视图数量和用途决定。

## 四、配光层级

| 层 | 职责 | 数量 |
|---|---|---|
| 主光 key | 决定光位与光比 | 1 |
| 补光 fill | 调暗部密度，不改光位 | ≤1，可省略 |
| 轮廓光 rim | 把主体从背景里拉出来 | ≤1 |
| 环境／背景光 | 建立空间与纵深 | 1 |
| 实用光 practical | 画面内可见或明确暗示的光源，提供动机 | 按场景实有数量 |

规则：

- 单镜优先只显式写影响主体、空间或剧情的主导光源；复杂场景可以超过 3 个，但要说明主次，不能把实景中每盏灯都堆成同等权重的指令。
- 光位与光比由主光决定；补光只调暗部，不新建光位。
- 实用光必须可见或被明确暗示（灯光律）；无动机的装饰光不写。
- 多光源场景先定主光，再决定哪些光源进入画面。

## 五、光质维度

| 维度 | 取值 | 写法 |
|---|---|---|
| 硬软 | 硬（边界锐利）／半硬／软（渐变包裹） | `hard-edged shadow` / `soft wraparound light` |
| 衰减 | 慢（大光源远距）／快（小光源近距） | `soft falloff` / `rapid falloff` |
| 光斑形状 | 窗格、百叶、树枝、栅格、水波 | `window-pane shadow` / `venetian slats` |
| 高光泛光 | 高光溢出、光晕 | `mild halation` / `blooming highlights` |
| 介质 | 雾、烟、尘产生体积光 | `volumetric shaft` / `dust-lit beam` |
| 闪烁 | 烛火、灯管、荧光不稳定 | `flickering candlelight` / `sputtering tube` |

## 六、色温

| 光源 | 色温 | 观感 |
|---|---|---|
| 烛火／油灯 | 1800–2200K | 深琥珀 |
| 钨丝灯 | 2700–3200K | 暖琥珀 |
| 家居暖灯 | 3000K | 浅暖 |
| 日间窗光 | 5000–5600K | 中性 |
| 荧光灯 | 4000–4500K | 偏绿、病态 |
| 阴天 | 6500–7500K | 冷灰蓝 |
| 屏幕／显示器 | 6500K | 冷白 |
| 蓝调时刻 | 8000K 以上 | 冷钢蓝 |
| 钠灯 | 约 2000K 窄谱 | 橙 |

**混合色温**是内景层次的主要来源：室内暖 + 窗外冷。必须写明哪一个是主光，否则模型会把两者平均成平淡中间调。

## 七、布光技术（18 项）

### 7.1 明暗结构

| 技术 | 结果 | 适用 |
|---|---|---|
| Rembrandt | 鼻影与面颊阴影相连，背光侧面颊保留三角亮区 | 人像剧情、人物登场、情绪访谈 |
| Butterfly / Paramount | 顶光在鼻下投影 | 魅力、时尚、经典好莱坞 |
| Split lighting | 半脸亮半脸暗 | 双面性、内心冲突、反派 |
| Rim / backlit | 边缘勾勒轮廓 | 神秘、史诗揭示 |
| Chiaroscuro | 极端明暗对比 | 绘画感、高戏剧性 |
| High-key | 明亮、极少阴影 | 喜剧、商业、生活方式 |
| Low-key | 深阴影主导，小片光池 | 黑色电影、惊悚、心理张力 |
| Silhouette | 主体简化为形状 | 强调形态、神秘、抽象揭示 |

### 7.2 光源性质与动机

| 技术 | 结果 | 适用 |
|---|---|---|
| Motivated lighting | 光源在场景中可见或被暗示 | 写实、叙事落地 |
| Practical lighting | 画面内可见光源：霓虹、烛、屏、招牌 | 夜景、赛博、亲密写实、酒吧餐厅内景 |
| Window | 有依据的窗光 | 内景日光、单一光源自然主义 |
| Soft Cross | 柔和交叉主光 + 补光 | 讨好的人像、对话、亲密剧情 |
| Contre Jour | 强逆光 | 剪影、黄金时刻揭示、人物登场 |
| Overhead Fall | 顶部硬光 | 审讯、孤立、戏剧舞台感 |

### 7.3 自然光时序

| 技术 | 结果 | 适用 |
|---|---|---|
| Golden hour | 暖琥珀方向光，长而柔的影 | 爱情、史诗、情绪节拍 |
| Blue hour | 日落后冷钢蓝环境光 | 忧郁、过渡、都市孤独 |
| Harsh midday sun | 硬顶光，边界锐利的影 | 沙漠、对峙、暴露的脆弱 |
| Overcast diffused | 均匀柔光，无硬影 | 人像、纪录、落地写实 |

> 一个场景优先锁定一套主导明暗结构和一把主光。多项技术可以组合，但必须共享同一光源逻辑，并能说清哪一项主导主体读取。

## 八、灯光律（写律不写描述）

项目级不变量，管辖每一镜：

```text
灯光律：[项目名]
光源：全部为实用光或有依据的光
光比：人脸允许落到 ___ 阴影（按题材档取值）
补光：无美化补光 / 允许柔和补光
色温：主光 ___ K，环境 ___ K
```

> `一盏路灯在发光` 属于某一镜的正文；`所有光都必须有依据` 属于项目律。二者不可混。

## 九、跨镜光源继承律

- **同场景内**：主光方向、光比、色温不得漂移。允许的变化只有人物移动造成的自然进入或离开光区。
- **反向机位**：光源在世界坐标中的方向不变，画面左右可以镜像；不得为了构图把主光换边。
- **时间推进**：变化必须由可见事件驱动——开灯、拉窗帘、日落推进、云遮日，并在画面里给出触发。
- **跨组继承**：上一组末态的光源状态写入下一组起始状态；换场重新建立光源。
- **自检**：同一场景相邻两镜的暗部方向应一致；不一致先查光位，不要靠调色掩盖。

## 十、光影叙事

- 一个转折优先安排一个主导光变化；若亮灯、开门和人物移动共同改变画面，要写清同一因果链及先后，而非把多种效果同时堆上去。
- 孤立光池比整体调亮更有效——关键道具单独落在光里。
- 出场与揭示可用轮廓光或剪影；只有需要暂时隐藏身份、强调形态或制造入口时才牺牲面部信息。需要辨认人物或表情时，应给正面补光或改用可读的边缘光。
- 光的变化要么由剧情触发，要么作为段落分界，不做无动机闪烁。

## 十一、提示词写法

导演稿先记录本镜的叙事任务和可读性要求；生成提示词只保留可见、可执行的灯光条件，推荐顺序：

```text
[有动机光源] + [光位] + [硬软与衰减] + [阴影位置与暗部细节] + [反差] + [色温]
```

示例：`画内台灯作为主光，从人物左前侧上方照入；柔和快速衰减，鼻影连接至背光侧面颊形成小三角亮区，暗侧仍可读眼神；中高反差，3000K 暖光，窗外冷蓝环境光仅勾出背景`

- 当灯光承担叙事、身份读取或连续性任务时，必须写清有动机光源、方向、硬软和阴影结果；普通承接镜可以继承已锁定的项目灯光律，避免机械复述。
- `压迫感`、`命运感`、`神秘感` 不能代替灯光指令；要转换成光位、介质、落点、暗部细节与反差。
- 体积光必须同时写空气介质与光束落点；逆光必须在“面部补光”与“完全剪影”之间作出明确选择；底光必须交代画内或被暗示的低位光源。
- 参考图与设定表：1:1 平光、均匀柔光箱、无场景光污染。
- 本档只定义镜头灯光；资产参考图的图像引擎写法由 `zion-assets` 的图像引擎档处理。

## 十二、检查清单

- [ ] 本镜光位已写，且与同场景相邻镜一致
- [ ] 本镜灯光的叙事任务已明确，但生成提示词没有只写抽象情绪词
- [ ] 反差档与阴影结果已选；需要读表情时，暗部细节足够
- [ ] 显式光源只保留影响主体、空间或剧情的部分，主次明确
- [ ] 每个光源都有动机，或明确为环境光
- [ ] 色温对比有主次，未平均化
- [ ] 逆光已明确面部补光或剪影；伦勃朗光有鼻影与面颊三角结构
- [ ] 体积光有雾、尘、烟或雨等介质且有落点；底光有合理低位来源
- [ ] 参考图用 1:1–2:1 平光，无场景光污染
- [ ] 光变化有触发事件，非无动机闪烁
