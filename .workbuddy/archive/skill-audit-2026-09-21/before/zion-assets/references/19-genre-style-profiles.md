# 题材风格预设：市面常见风格的可取用词库

核验日期：2026-09-20。题材分类参考 2026 年短剧市场常见赛道（古装权谋、古装探案、仙侠玄幻、年代现实、都市情感、都市职场、女性群像、悬疑推理、复仇虐恋、青春校园、家庭治愈、奇幻甜宠等）。

**本档是候选词库，不是必填清单。** 取用后收敛到「1 个主锚点 + 1–2 个支撑 token」，不把整块词表塞进提示词。

## 使用方式

本档共 **20 档**，分六族：东方古典 5 / 年代 2 / 现代 5 / 悬疑暗色 3 / 幻想未来 3 / 风格化 2。新增题材时同步更新此计数。

1. 先在需求确认阶段定题材与美术方向。用户未定且说“你定”时，从本档给 2–3 个最贴合剧本的题材档，标出推荐项。
2. 取该档的锚点 + 该场景真正需要的 1–2 个支撑项（材质、光、镜头）。
3. 服装、场景、道具资产按 [asset-prompt-builder.md](asset-prompt-builder.md) 建，锚点在本档取。
4. 图像引擎与文字通道见 [18-image-engines.md](18-image-engines.md)。

**三层分工**：本档定**美术体系**（形制、材质、器物、色板）；视觉语言（构图、镜头、调度、光色气质）取 [导演与摄影师视觉语言拆解](director-vision-language.md)；成像响应（颗粒、宽容度、黑位、色彩密度）取 [胶片与印片风格层](film-and-print-stocks.md)；调色与色彩配比取 `zion-storyboard` 的色彩分级档。四者可叠加，但同一张图内不叠加互相矛盾的美术体系。

**“锁定项”的落地方式按引擎不同**

- Midjourney：写进 `--no`。
- GPT Image 2：没有独立负面参数，改为正向写足材质与年代锚点，并在提示词里明确排除项（该类内容不要出现在画面）。

**通用纪律**：年代感靠材质与光写出，不靠报年代；一个镜头内不混两个题材的美术体系（例如古装场景不留现代光源痕迹）。各档“光源”字段只给倾向；正式镜头的光位、光比、配光层级与色温值由 `zion-storyboard` 的光影系统档落地。

**锚点冻结**：锚点进入项目后按 [资产提示词](asset-prompt-builder.md#项目风格骨架冻结段与变量段) 的「项目风格骨架」处理——同批资产逐字复用，不得逐张改写；替换锚点等于换档，需重新拍板并登记新版本。

## 一、东方古典族

**族级形制与器物词（先取词，再按题材档收成锚点）**

| 类别 | 可取用 |
|---|---|
| 唐制 | 高腰襦裙、齐胸襦裙、圆领袍、半臂、披帛、宝相花、卷草纹、飞檐、白玉柱、蓝釉瓦 |
| 宋制 | 褙子、抹胸、百迭裙、素色、极简线条、暗纹 |
| 明制 | 立领、袄裙、马面裙、织金、云肩、补子 |
| 材质与纹样 | 锦缎、纱、罗、缂丝、织金、暗纹提花、盘金绣 |
| 首饰 | 步摇、发冠、簪、钗、璎珞、臂钏、玉与珍珠、青金石 |
| 器物与植物 | 烛台、香炉、屏风、宣纸窗、苔石、桂花、白玉兰、古松 |

用法：用**形制名 + 材质 + 器物**代替“古风 / 高级 / 华美”这类形容词；一次最多取 3 个，收进该题材档的锚点句。

### 1. 古装权谋 · 宫斗宅斗
- **锚点**：`烛火暖点光 + 深色织锦`
- **服装材质**：真丝织锦、哑光缎面、暗纹提花、垂坠有重量感；不用亮片与反光化纤
- **场景器物**：深色木构、雕花格栅、青砖、铜器、宣纸窗、烛台、屏风
- **光源**：烛火或油灯单点暖光 + 窗格漏光
- **镜头**：稳、缓摇、隔窗隔纱构图、中长焦压缩空间
- **调色**：低饱和暖棕 + 冷青阴影
- **锁定项**：现代妆发、美瞳、假睫毛、塑料材质、影棚平光

### 2. 武侠江湖
- **锚点**：`尘烟斜光 + 粗布`
- **服装材质**：粗麻、旧棉布、皮革束带、磨损边缘
- **场景器物**：木桌长凳、粗陶碗、酒旗、竹篱、土墙、刀鞘
- **光源**：侧逆斜光穿过尘烟、篝火暖点光
- **镜头**：中近景手持跟随、快速摇摄收在动作末点
- **调色**：暖褐 + 压青，中低饱和
- **锁定项**：服装过于干净平整、现代织物质感、柔光美颜

### 3. 仙侠修真
- **锚点**：`云雾 + 冷玉光`
- **服装材质**：素色广袖、纱质叠层、云纹暗花、飘动有方向感
- **场景器物**：云海、危崖、古松、朴素道观、石阶、灵纹、蒲团
- **天城变体**：剧情需要仙界都城或白玉宫城时，先定主街/中轴、门楼、层叠台地、桥与水系的连接，再选白玉建筑、云海、灯笼、白花、仙鹤等少量识别物；人物活动用于标出城市功能和尺度，不默认把所有元素同镜堆满
- **光源**：冷玉色环境光、晨雾逆光、体积光柱
- **镜头**：大远景建立天地尺度 + 近景写气息；慢速升降
- **调色**：青白冷调、高光泛雾
- **锁定项**：现代器物、霓虹色、法术同镜堆多种效果

### 4. 东方玄幻 · 志怪探案
- **锚点**：`夜雾 + 暖灯与青冷交界`
- **服装材质**：圆领袍、官服织物、薄纱披帛（奇幻角色）
- **场景器物**：衙门、长街灯市、破庙、纸灯、符纸、铜铃
- **光源**：灯笼暖点光与月色青冷光对撞
- **镜头**：低调光比、遮挡前景、缓慢推进揭示
- **调色**：青冷主调 + 局部暖点
- **锁定项**：特效与实拍质感割裂、能力没有代价

### 5. 古风轻喜剧
- **锚点**：`高调日光 + 明亮木色`
- **服装材质**：棉麻、浅色系袍服、干净但不崭新
- **场景器物**：庭院、回廊、市集、纸伞、木案
- **光源**：整体高调日光，阴影浅，无重压暗部
- **镜头**：平视中景、固定机位居多、构图工整
- **调色**：明亮低反差、暖黄偏白
- **锁定项**：阴郁低调光、脏旧材质、悲剧式压黑

## 二、年代族

### 6. 民国
- **锚点**：`湿润青石 + 钨丝灯`
- **服装材质**：棉麻长衫、呢料西装、旗袍缎面暗纹、皮鞋
- **场景器物**：砖木洋房、百叶窗、铁艺栏杆、老式招牌、黄包车
- **光源**：钨丝灯琥珀、阴天散射、雨夜湿面反射
- **镜头**：浅景深中景、横向摇、略柔焦
- **调色**：低饱和暖褐 + 青灰阴影
- **锁定项**：塑料、不锈钢、现代印刷字体、现代服装剪裁

### 7. 年代怀旧与城乡现实（80–90 年代）
- **锚点**：`褪色暖黄 + 搪瓷水磨石`
- **服装材质**：的确良、针织毛衣、旧棉袄、帆布手套
- **场景器物**：搪瓷缸、水磨石地面、白瓷砖墙、铁皮柜、老式自行车、木窗
- **光源**：顶灯荧光偏绿 + 窗外过曝
- **镜头**：略软、轻微呼吸感、固定机位多、正反打朴实
- **调色**：暖黄褪色、高光溢出、轻微颗粒
- **锁定项**：智能手机、液晶屏、现代家装、当代品牌标识

## 三、现代族

### 8. 都市甜宠 · 治愈
- **锚点**：`柔和窗侧光 + 浅景深`
- **服装材质**：棉、针织、羊毛、低饱和配色
- **场景器物**：公寓、咖啡馆、雨街、便利店、绿植
- **光源**：窗侧柔光、蓝调时刻外景、暖色实用灯
- **镜头**：中近景、浅景深、轻微手持晃动
- **调色**：柔和暖粉金、抬起的阴影
- **锁定项**：影棚硬光、过度磨皮假面、荧光顶光

### 9. 都市职场 · 精英商战
- **锚点**：`冷玻璃幕墙 + 侧逆光`
- **服装材质**：精纺羊毛西装、丝质衬衫、无可见标识
- **场景器物**：玻璃幕墙办公室、地下车库、旋转门、会议长桌
- **光源**：冷白实用光 + 窗外强逆光剪影
- **镜头**：稳定器跟拍、长焦压缩、双人过肩
- **调色**：Cold Steel 或 Teal Orange
- **锁定项**：奢侈品堆砌、品牌 logo、塑料感家具

### 10. 女性现实群像
- **锚点**：`自然实用光 + 真实肤质`
- **服装材质**：日常通勤装、略有褶皱、非全新
- **场景器物**：出租屋、办公室、地铁、菜市场
- **光源**：窗光与室内实用光混合，不补光
- **镜头**：中景为主、手持纪实感、少修饰
- **调色**：中性自然、轻微去饱和
- **锁定项**：广告级美颜、奢华布景、悬浮无生活痕迹的空间

### 11. 青春校园
- **锚点**：`逆光尘埃 + 过曝白`
- **服装材质**：棉质校服、帆布鞋、书包
- **场景器物**：教学楼走廊、教室、操场、自行车棚
- **光源**：黄金时刻斜光、教室窗光、树影斑驳
- **镜头**：浅景深、低机位、跟拍背影
- **调色**：Bleached Warm
- **锁定项**：成人化妆感、时尚单品、过度精致发型

### 12. 家庭亲情 · 烟火治愈
- **锚点**：`灶台暖光 + 生活痕迹`
- **服装材质**：家居棉布、针织、围裙
- **场景器物**：厨房、饭桌、旧沙发、碗筷、晾晒衣物
- **光源**：单点暖光 + 窗光，制造明暗交界
- **镜头**：中近景、手部特写、平视不炫技
- **调色**：暖琥珀、低反差
- **锁定项**：样板间式整洁、冷调商业光、无使用痕迹的道具

## 四、悬疑与暗色族

### 13. 刑侦探案 · 悬疑推理
- **锚点**：`冷白荧光 + 湿沥青`
- **服装材质**：夹克、衬衫、风衣、深色低饱和
- **场景器物**：审讯室、雨夜街、走廊、档案室、证物袋
- **光源**：顶荧光 + 单一侧光，硬阴影
- **镜头**：固定机位、缓慢推进、构图留白与遮挡
- **调色**：青橙去饱和、高反差
- **锁定项**：暖色舒适光、美颜、明亮高调画面

### 14. 都市暗黑 · 复仇虐恋
- **锚点**：`霓虹反光 + 深压阴影`
- **服装材质**：丝质、皮革、深色西装、细高跟
- **场景器物**：玻璃写字楼夜景、地下车库、酒店走廊、雨窗
- **光源**：单一冷光源 + 霓虹反光，暗部压住
- **镜头**：近景压迫、遮挡前景、缓慢横移
- **调色**：高反差、去饱和、局部冷点色
- **锁定项**：均匀平光、甜美色调、明亮通透

### 15. 灵异惊悚
- **锚点**：`病态黄绿 + 压黑暗部`
- **服装材质**：旧棉布、制服、湿透的衣物
- **场景器物**：老楼走廊、楼梯间、镜子、白炽灯管、灰尘
- **光源**：单点冷光、灯管闪烁、走廊尽头光斑
- **镜头**：固定长镜、景深外模糊身影、极慢推进
- **调色**：病态黄绿、暗部压黑
- **锁定项**：依赖音效惊吓（模型不表现声音）、明亮安全光、可爱元素

## 五、幻想与未来族

### 16. 近未来科幻 · 赛博
- **锚点**：`冷钢 + 全息蓝`
- **服装材质**：哑光复合面料、拉丝金属件、无缝剪裁
- **场景器物**：拉丝金属墙面、无缝玻璃、嵌入面板、全息投影
- **光源**：内嵌面光 + 冷蓝边缘光，避免暖色
- **镜头**：稳定器长镜、单点冷白实用光、广角空间感
- **调色**：Cold Steel、冰蓝与银
- **锁定项**：当代消费电子外形、可见品牌标识、塑料质感

### 17. 末世废土
- **锚点**：`尘霾 + 去饱和橙棕`
- **服装材质**：破帆布、拼接皮革、灰尘与磨损
- **场景器物**：锈蚀金属、混凝土碎块、废弃车辆、临时棚屋
- **光源**：尘埃散射日光，无蓝调，天空压低
- **镜头**：手持、广角、低角度仰拍废墟尺度
- **调色**：去饱和橙棕
- **锁定项**：完好如新的现代物件、干净平整的服装

### 18. 西幻 · 异世界
- **锚点**：`体积光 + 浓郁宝石色`
- **服装材质**：粗麻、皮革、锻铁、羊毛斗篷
- **场景器物**：石砌城堡、森林、酒馆、火把、铁艺、木桶
- **光源**：森林体积光、火把暖点光、窗洞光束
- **镜头**：大远景建立世界 + 中景人物关系
- **调色**：Teal Orange Epic 或浓郁宝石色 + 深阴影
- **锁定项**：中式元素混入（除非设定要求）、现代织物、塑料

## 六、风格化族

### 19. 国漫 · 3D 动画风格化
- **锚点**：`风格化 3D + 强化轮廓光`
- **服装材质**：简化块面、非写实织物、可夸张剪裁
- **场景器物**：概括化建筑与陈设，保留关键识别特征
- **光源**：强化轮廓光与高光点，简化中间调
- **镜头**：允许夸张运镜、速度线与粒子
- **调色**：高饱和、干净色域
- **锁定项**：半写实恐怖谷、照片级肤质与写实比例混用

### 20. 古风美食 · 田园烟火
- **锚点**：`柴火暖光 + 食材质感`
- **服装材质**：粗布、棉麻、袖口挽起、略有油渍
- **场景器物**：粗陶、木案、竹器、灶台、铁锅、粗碗
- **光源**：灶火单点暖光 + 窗光侧入
- **镜头**：微距特写食材与手部动作、俯拍案板、蒸汽可见
- **调色**：暖琥珀、低反差
- **锁定项**：现代厨具、塑料容器、不粘锅涂层质感

## 跨题材共用规则

- 同一项目题材不一致时（如古装 + 穿越现代），按场景分别取档，并在参数摘要记录切换点，不让两套美术在同一空间并存。
- 题材档只解决“美术与质感”。事件、动作、连续性仍由 `zion-storyboard` 的导演决策标准与动作编排档处理。
- 任何题材的动作幅度都可以按风格调整，但事件先后、空间关系与末态必须可读。
- 本档不含剧情套路建议；剧情结构交给 `zion-script`。
- 新增题材档时，沿用同一字段结构（锚点 / 服装材质 / 场景器物 / 光源 / 镜头 / 调色 / 锁定项），并在“来源”注明依据。
