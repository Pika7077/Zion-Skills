# 人物设定表模板（参考资产版式）

核验日期：2026-09-20。素材来源：用户提供的公开平台古风女主生成提示词（约 1600 字符），按 Zion 标准筛选后只吸收其骨架。

本档只管**设定表的版式与一致性写法**，不提供长相配方。外形来自人物卡与剧本；同项目内不同角色必须主动拉开差异，照搬同一套外形描述会造成角色同质化——**先读第九节**。

身份怎么写进人物卡见 [character-extraction-rules.md](character-extraction-rules.md)。跨模型使用时保留同一身份锚点和状态命名，再按已确认的目标模型改写语法。

## 一、吸收与剔除

| 该提示词的元素 | 判定 | 理由 |
|---|---|---|
| 四视图及严格角度定义（正脸半身 / 正面全身 / 90° 侧身 / 180° 背面） | **吸收** | 角度可量化，便于后续分镜按观察方式引用 |
| 脚底同一水平线、不裁切、人物间留距 | **吸收** | 版式约束，直接决定参考图可用性 |
| 一致性锁定清单（脸型/五官/妆容/发型/发饰/服装/刺绣/腰封/首饰/材质/色彩） | **吸收** | 身份锁定的正确做法，改为一段锁定句 |
| 材质分离（丝/缎/纱/金属/珍珠/玉；金属不过曝、纱料层次自然） | **吸收** | 参考图能否被视频引用，取决于材质是否可读 |
| 影棚浅暖灰背景、均匀高调光、无场景杂物 | **吸收** | 与“参考图不污染身份”原则一致 |
| 比例定义（九头身、头小肩宽、避免大头娃娃） | **吸收**（去掉具体数字） | 体态要求有效，`180cm` 是给人读的，模型不执行 |
| 多美术体系叠加（3D 半写实国漫 + 顶级 CG + BJD + 乙女游戏质感 + 电影级 CG） | **剔除** | 一个资产只留一个主锚点 |
| 抽象气质词（清冷、矜贵、端庄、华丽、仙气不俗艳、灵动） | **剔除，转可见特征** | 形容词不可渲染，改用材质、姿态、光位、构图表达 |
| 刺绣与纹样全解（胸前白鹤 + 裙摆云海山水水波 + 袖口牡丹祥云兰花 + 灵芝云纹） | **收缩** | 参考图不是服装设计稿；按 piano test 只留剪影 + 一个识别特征 |
| 单条提示词约 1600 字符 | **剔除** | 风格 token 与细节同时过量，注意力被稀释 |

## 二、版式模板

### 2.1 四视图设定表（标准）

- 排列：左 → 右 = 正脸半身特写 / 正面全身 / 标准 90° 侧身全身 / 180° 背面全身。
- 左侧特写占较大画面比例，正脸正视镜头，头部水平，完整展示头顶发型、双耳、面部、肩颈、锁骨与上胸。
- 三个全身视图脚底处于同一水平线，完整显示头顶至鞋底与全部拖尾，不裁切。
- 视图之间留合理间距；纯净浅暖灰棚拍背景，无场景杂物。
- 柔和均匀高调光：大面积柔光箱 + 正面偏上主光 + 轻微环境补光，阴影克制。

### 2.2 三视图（轻量）

正脸 / 90° 侧身 / 背面，全身。用于只需确认体型、服装结构与背面设计的场合。

### 2.3 头三视图（转向与表情）

正脸 / 3/4 侧 / 正侧，仅头部与肩。用于表情与转向参考，避免全身图稀释面部精度。

**视图从实际分镜倒推**：分镜不会出现的角度不必制作。四视图是可选模板，不是默认配额。

## 三、一致性锁定句（可直接复制改写）

> 以下所有视图为完全同一人物，脸型、五官、妆容、发型、发饰、服装、刺绣纹样、腰封、首饰、材质与配色全部保持一致。

后面接一段**紧凑身份锚点**（形状与比例、面部与发型、服装结构与材质、辨识特征），不逐件罗列花型。

## 四、同图还是分图

| 做法 | 适用 | 代价 |
|---|---|---|
| 四视图同图 | 风格确认、比例确认、快速审稿 | 分辨率被四等分，面部精度下降；视图间仍可能互相漂移 |
| 面部特写单出 + 全身三视同图 | **推荐默认** | 需两次生成，换来可用的身份锚点 |
| 每视图各出一张 | 后续要作为视频参考图逐张引用 | 生成次数增加，需统一锁定句保证一致 |

## 五、比例与体态写法

写成可见关系，不写数值：高挑纤细、头小肩宽、颈部修长、腰线清晰、腿长占比大、比例协调。避免夸张胸部与幼态大头。

## 六、引擎适配

- **GPT Image 2（默认）**：结构化分句；参考图 ≤16 张，可一次给身份 + 风格 + 构图；要渲染的文字用引号写出。
- **Midjourney（仅用户主动提起）**：只使用当前已核验的参数与参考图方式，不沿用旧版本参数。

## 七、反模式清单

1. 一条提示词里混两个以上美术体系（半写实 + 娃娃感 + 电影级 CG 同时出现）。
2. 用气质形容词代替可见特征。
3. 纹样与刺绣逐处罗列，把生成预算从身份上挪走。
4. 单条资产提示词超过约 800 字符仍在堆细节——先分层，不硬塞。
5. 把参考图当服装设计稿交付：参考图的职责是锁身份，不是展示设计。
6. 默认四视图同图，却不检查面部精度是否够后续引用。

## 八、分层写法（原骨架的瘦身版）

按「身份锚点 → 视图/姿态 → 服装与状态 → 背景与光线 → 布局约束」分段，每段只放该段真正需要的词：

1. **用途与版式**：人物设定表 / 四视图 / 排列顺序 / 角度 / 同水平线 / 不裁切 / 背景与光。
2. **身份锚点**（≤3 个视觉特征 + 体态比例）：脸型轮廓、发型与发饰、服装结构与主色。
3. **材质**：丝缎 / 轻纱 / 鎏金金属 / 珍珠 / 玉，各自质感一句话。
4. **一致性锁定句**：见第三节。
5. **锁定项**：不混美术体系、不裁切、无场景杂物；按引擎写法落地。

## 九、反同质化（重要）

模板借的是**版式与锁定机制**，不借长相。同一套外形描述套到每个角色上，会让全项目长成一张脸；系列剧、多角色同框时尤其致命。

### 差异化维度（同项目内至少 3 项明显不同）

| 维度 | 可拉开的方向 |
|---|---|
| 面部骨相 | 鹅蛋 / 方下颌 / 圆短 / 长窄；颧骨高低；面部留白多少 |
| 眼部 | 杏眼 / 丹凤眼 / 圆眼 / 下垂眼；眼距；双眼皮形态；卧蚕有无 |
| 眉形 | 柳叶 / 剑眉 / 平直 / 稀疏 |
| 唇形 | 薄厚、唇峰明显度、唇色 |
| 肤色 | 冷白 / 暖白 / 小麦 / 蜜色；血色与通透度差异 |
| 发型逻辑 | 盘发 / 马尾 / 散发 / 编发；发量、发色层次 |
| 体态 | 身高感、肩宽、颈长、骨架粗细 |
| 材质偏好 | 锦缎 / 纱质 / 皮革 / 粗麻；以金属、玉或珍珠为主 |
| 配色体系 | 冷调 / 暖调 / 高饱和 / 低饱和；主色不重复 |

### 禁止默认值

不得把某个流行外形组合（例如小 V 鹅蛋脸 + 桃花杏眼 + 象牙白粉调瓷肌 + 金枝玉兰花冠 + 白鹤鎏金礼服）当成通用起点。这类描述只属于那个特定角色，且必须有剧本或用户设定支持。

### 同项目内检查

- 两个以上角色：逐项对比上表，至少 3 项明显不同。
- 差异要落在**骨相与体态**，不能只换发型和衣服。
- 主角与配角的区别优先在剪影上成立——远景、背影、过肩也要能区分。
- 一次生成多角色设定表时，把差异维度分别写进各自的锁定句，不让模型共用一张脸。

### 与一致性的边界

一致性 = 同一角色跨视图、跨镜头不变；同质化 = 不同角色之间趋同。两者不冲突：锁定句按角色分别写，绝不共用同一段。
