## 已实施项目与依据

| 范围 | 调整 | 依据与保留边界 |
|---|---|---|
| 通用入口 | 只追问阻断当前交付的缺口；沿用已有授权；局部任务按局部范围交付 | 消除逐项问卷与特定授权口令；不放松受保护的剧情、事实与业务要求 |
| 独立安装 | 四个入口补齐其他技能不可用时的处理方式 | 单独安装仍完成本职交付，明确后续需求；保留独立解析器完整副本 |
| 分镜导出器 | 焦段、光圈等字段按输入条件输出；移除缺省情况下擅加的风格、节奏及禁音乐/字幕等约束 | 可选字段不应触发失败，导出不能覆盖用户意图；保留既有字段兼容 |
| 分镜说明 | 区分粗分镜、导演稿、视频生成稿、局部优化；清理机械运镜与配色配额；合并对白专档 | 按镜头目的选择手段，保留对白、声音、连续性与模型预算规则 |
| 资产提取 | 保留旧 id，新增运行限定 extraction_id；未登记 asset_id 为 null；登记时记录 source_extraction_ids 映射 | 旧序号随排序变化且批间重复，不能充当稳定人物身份；不自动按姓名合并实体 |
| 资产内容 | 去掉强制人物差异数量、修改骨相与静帧动作禁令；精简来源沿革和重复交接说明 | 忠实保留双胞胎、制服等源事实；身份图与动作海报按用途检查 |
| 图像引擎 | 保留 GPT Image 2 默认及 MJ 显式选用；更新透明背景等能力，补官方链接与日期；删除无依据的准确率、价格、延迟和绝对锁定承诺 | 模型能力、项目文字制作约定及实际入口可用性分开；不自动升级或换通道 |
| QA 投喂前检查 | 合规扫描并入可生成性检查，分“明确冲突”和“生成风险”两阶段 | 保留项目规则来源与分级；默认模型不能冒充已核验入口或已生成验证 |
| QA 盲读与结果 | 盲读按题材目标判断；生成结果按证据选择保留、后期修、局部编辑、重生成或重写 | 删除“气爽急追”普遍门槛、两次失败即重写、固定延展层数与不存在的工具要求 |
| QA 资产准入 | 在本技能内完整写明正式稿仅接受 approved+真实 files 或 uploaded+实际 target_reference；生成提示词仅接受后一种 | 复核发现原简写会让独立安装漏判 candidate/deprecated 或无映射 uploaded，已补齐 |
| 剧本附件 | 合并三份薄附件；FACS 移为按需参考；保留自然语言表演、动作因果与可选人物设计方法 | 删除逐句三段式、AU/微动作数量、眼泪/静止/同步禁令、固定色值数量及世界先行的不可逆流程 |
| 剧本路由 | 简版镜头构想加载本技能 06/08；制作级逐镜稿交给 storyboard | 修复“只有制作级请求才能读分镜参考”的残留冲突 |
