# 生成提示词

仅在用户明确要求生成提示词时使用。纯剧本创作不默认附带。目标模型未指定时采用默认（**视频 Seedance 2.5、图像 GPT Image 2**）并在参数摘要记录，不为此单独追问；**Midjourney 仅在用户主动提起时使用**。不得声称提示词“已适配”或“可直接投喂”。

每个独立投喂块应包含完成该次生成所需的信息：

- 目标画幅和必要风格。
- 实际存在的资产引用或稳定身份描述。
- 场景与起始状态。
- 可见动作、摄影机行为、对白和声音。
- 关键物理反馈、切点与末态。
- 组时长及目标模型需要的参数。

项目级公共参数可以集中声明；独立生成所需的主体、状态、动作、声音和资产不能用“同上”省略。

摄影机、焦段、光圈、帧率、白平衡和负面提示词只在目标模型需要或它们会改变结果时加入。负面约束的表达方式按模型选择，并避免与正向目标冲突。

提示词写可见可听的内容。导演目的、心理分析、来源注释和审核结论留在代码块外。
