# 16 · 类型机制：兑现承诺而不套配方

类型不是美术标签，而是观众对信息、风险、关系和回报方式的预期。本档只在项目有明确类型或混合类型时读取；没有类型目标时不强行归类。

## 一、先锁定类型承诺

对当前项目回答三项：

1. 观众主要在等什么：答案、笑点、威胁兑现、关系落定、胜负或人物共同完成一件事。
2. 哪种证据会让观众相信承诺正在推进。
3. 最终回报怎样证明前面的等待值得。

类型承诺与情绪回报不同：前者规定“用什么机制看下去”，后者规定“最终得到什么感受”。两者结合使用，见 [受众期待与情绪回报](13-audience-and-payoff.md)。

## 二、悬疑与推理

把信息分成四类：事实、角色解释、观众推测、最终答案。作者可以控制披露顺序，不能把尚未给过的关键事实伪装成观众早该知道。

**线索链**：

`可见事实 → 至少一种合理解释 → 新证据改变解释权重 → 答案能回指前文事实`

- 公平不是让观众一定猜中，而是揭晓后能指出此前可获得的证据。
- 误导应利用真实但不完整的信息、角色偏见或合理默认；不能靠镜头撒谎或临时改规则。
- 红鲱鱼需要服务人物、世界或主线，即使不是答案也不能完全无后果。
- 揭晓分为“知道答案”和“证明答案”；推理故事通常还需要对证、行动或代价完成证明。
- 每次延迟答案时要加入新信息、新风险或关系变化；只把答案往后拖是停滞。

自检：删掉最终解释，前文是否仍存在足够证据范围？揭晓后重读，人物行为是否仍说得通？

## 三、喜剧

笑点依赖可理解的常态与偏差，不等于角色说俏皮话。

| 组件 | 作用 |
|---|---|
| 前提 | 建立人物、规则或观众预期 |
| 偏差 | 结果以具体方式违背预期 |
| 反应 | 让观众读到后果、身份或关系压力 |
| 升级 | 同一机制提高代价、扩大范围或换对象 |
| 回收 | 早先元素在新语境中再次生效 |

- 笑点应来自人物目标、身份策略或处境，不靠可互换段子贴在任何角色身上。
- 重复只有在第三次带来变奏、升级或反转时才有价值。
- 解释笑点会消耗节奏；确保前提可读后，让动作、停顿或反应完成含义。
- 尴尬、荒诞、语言、动作和情境喜剧所需时长不同，不套统一节拍。

## 四、恐怖与惊悚

先定义威胁规则：它能做什么、何时出现、人物怎样察觉、什么暂时有效。规则可以未知，但作品内部的证据不能任意改写。

- **预期**：给出威胁可能出现的证据。
- **延迟**：人物必须在风险中做事，不能只是等待惊吓。
- **兑现或落空**：兑现改变处境；落空也要产生新信息或暴露人物弱点。
- **余波**：惊吓后留下伤情、关系、资源或空间状态，不能下一场干净复位。

恐怖依赖失去控制的过程，惊悚更强调迫近压力与选择代价；项目可以混合，但要知道主要驱动力是哪一个。

## 五、爱情与关系叙事

关系推进需要可观察证据，不用“他们渐渐相爱”跨过过程。按项目选用：注意到对方、主动靠近、暴露脆弱、共同承担、发生误解或背叛、重新选择。

- 吸引点要与人物处境和价值判断有关，不只靠外貌宣布。
- 阻碍应影响双方选择；可以来自目标冲突、身份、责任或自我保护，不必强加误会。
- 误会只有在人物有理由不问、不说或不信时成立；一句话即可解除却长期不说，会削弱可信度。
- 关系落点用行动、承诺、边界或牺牲证明，不只用告白总结。

## 六、动作与冒险

动作段落先写胜负条件，再写动作。每一阶段都要改变位置、资源、伤情、信息或可用策略。

`目标 → 障碍规则 → 尝试 → 物理反馈 → 策略变化 → 胜负与代价`

- 能力展示必须影响后续判断，不做一次性炫技。
- 强敌不只“更强”，还应让主角原策略失效。
- 胜利来自已建立的能力、环境或选择；临时获得的新能力需要前置依据。
- 动作结果进入后续场次，具体编排与镜头执行交给 `zion-storyboard` 的动作编排档。

## 七、群像与单元故事

- 群像不是每个人戏份相等，而是主要人物都对共同事件造成不可替代的影响。
- 为每条人物线记录：当前目标、掌握信息、与共同事件的交点、这次出现造成的变化。
- 多线交叉应交换信息、资源、风险或关系；只在同一地点擦肩不算交叉。
- 单元故事每单元有独立完成度，同时至少通过人物状态、世界变化或长期问题连接主线。

## 八、混合类型

先定主类型负责“为什么继续看”，副类型负责调节体验或提供另一层回报。发生冲突时按主类型承诺取舍。

例如悬疑爱情中，如果核心承诺是查明真相，关系推进不能通过隐瞒关键公平线索来制造；若核心承诺是关系落定，谜题可以服务亲密与信任，而不必发展成完整推理链。

## 九、自检

- [ ] 能说出主类型的观看承诺、推进证据和最终回报
- [ ] 悬疑的答案能回指已给事实，误导没有依赖撒谎
- [ ] 喜剧的偏差建立在可读前提和人物处境上
- [ ] 恐怖威胁有可追踪规则，惊吓留下后果
- [ ] 关系推进有行动证据，误会符合人物选择
- [ ] 动作阶段改变了资源、空间、信息或策略
- [ ] 群像人物对共同事件各有不可替代的作用
- [ ] 混合类型已明确主次，机制没有互相抵消
