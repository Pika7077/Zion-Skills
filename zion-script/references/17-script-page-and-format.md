# 17 · 剧本正文：写可拍可听的一页

本档管**正文怎么写**：场标、动作行、对白标注与叙述语气。叙事视觉事实见 [叙事视觉意图](12-visual-style-and-grading.md)；镜头拆分、灯光、声音与调色的执行由 `zion-storyboard` 决定。

正文是给演员、美术与下游共读的工作文本，第一读者不是观众。因此判断一句话写不写的标准是**它能不能被拍到或录到**，而不是它读起来动不动人。

## 一、只写能被拍到和听到的

判据：**这句话能不能让摄影机看到、让麦克风录到？**

不能时，换成外在证据：

| 想写 | 换成 |
|---|---|
| 内心活动、想法 | 动作、延迟、选择、身体反应（见 [生理性叙事与表演词库](10-physical-acting.md)） |
| 判断与评价（他很虚伪） | 使这个判断成立的具体行为 |
| 比喻式形容（像被抽走空气） | 可拍到的物理事实（呼吸、手撑住桌沿） |
| 作者评论（不幸的是、令人震惊） | 删；由事件顺序与后果承担 |

需要向导演或演员说明意图时，另起一行标注（如括号备注），**不与动作行混排**。混排会让下游分不清哪句要拍、哪句是解释。

生理细节只为承载情绪而写，不把每句台词翻译成肌肉动作（见 [生理性叙事与表演词库](10-physical-acting.md)）。

## 二、正文不写摄影机

景别、机位、运镜、构图、焦段与剪辑点属于导演分镜，不写入剧本正文；即使用户只要求“简版镜头构想”，只要交付按镜号拆分并决定这些执行项，也归 `zion-storyboard`。

- 「镜头推近」「我们看见」「切到」不进入正文。
- **可以写的是谁在看什么**：视线落点、注意对象、谁被谁挡住。这些是叙事事实，不是拍法。
- 同理不写配乐、音效处理与调色意图；需要观众听到或看到的信息，写成事件本身。
- 用户要求的是剧本正文时，正文里的镜头描述按本节处理；用户点名要镜头稿时改走 06 号档的字段，两种交付不混装。

## 三、场标

场标给出三项：**场次 ID、地点、时间**。

- `scene_id` 用稳定编号（如 `SC001`），不随标题、顺序或增删场次变化；交接规则见本档所在的 `zion-script` 主文件。
- 时间写到项目需要为止：昼夜级别够用时不必写具体钟点；跨场的时间关系（连续／数日后／更早）会影响观众理解时必须写。
- 同场景的连续段落写「接上场」「同场」，不重复建立环境。
- 地点写对判断有意义的层级：「老楼三层走廊」比「某处走廊」有用；门牌号只在剧情用到时才写。

## 四、对白标注

- 说话人写在台词之上。同一段里换人必须写明，不靠读者推断。
- 声音来源要写清：画外、电话另一端、广播、群体、非人声（机械、录音）。声音层的处理归 `zion-storyboard` 的音频与对白档，剧本只负责标明来源。
- 同时说话、打断、抢话要写出来——不写会被下游读成依次发言。
- 说话方式只在**改变这句含义**时标注（停顿位置、重音落在哪个字、压低音量）。不标注的部分交给表演；人物的固定说话习惯写在人物备注里，不逐句复述（见 [对白设计与诊断](04-dialogue-design.md)）。

## 五、语气与人称

- 动作行不出现用「我」指主角的写法，除非作品本身采用主观叙述设计。
- 时态统一（通常现在时），不在同一场里混用过去与现在的叙述。
- 面向表演的说明与面向画面的描述分开写，不在同一句里同时交代两者。

## 六、长度与密度

- 长度按可实现的朗读、动作与停顿估算，与目标时长对得上（见 [故事设计与输出范围](03-story-requirements.md) 的时长与节奏）。
- 一个段落一个焦点。把两件同时发生的事压进一行，下游无法判断哪件在前。
- 密度按场次用途取舍：进入、布景与重复解释可以压缩；选择、结果与跨场因果要留够篇幅，不为匀称牺牲它们。

## 七、与下游的接口

- 正文里的人物、场景与道具用**稳定且唯一的称呼**，便于 `zion-assets` 建立 `asset_id`；同一事物不在不同场次换叫法。
- 影响画面的视觉事实按 [叙事视觉意图](12-visual-style-and-grading.md) 记录，不在正文里写风格、调色或模型要求。
- 修订后格式保持一致；版本号与受影响场次按 `zion-script` 主文件的交接规则登记。

## 八、自检

- [ ] 动作行里没有摄影机、剪辑、配乐与调色指令
- [ ] 没有心理活动与作者评论，心理内容已转成外在证据
- [ ] 意图说明与动作行分开标注，没有混排
- [ ] 每场有场标，含稳定 `scene_id`、地点与足够的时间信息
- [ ] 画外、电话、群体与非人声的来源已标明
- [ ] 同时说话、打断与抢话已写出
- [ ] 人称与时态统一
- [ ] 人物、场景、道具的称呼跨场一致
- [ ] 篇幅与目标时长对得上，选择与结果没有被压缩掉
