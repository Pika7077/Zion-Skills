# 21 · 可生成性对剧本的约束

本档管**剧本阶段的选择**：写的时候就把"下游做不出来"的成本算进去，而不是等提示词成形后才发现。

分工：提示词与生成结果的可生成性判定归 `zion-qa` 的投喂前检查档与生成结果处置档；模型侧的字段与限制归 `zion-storyboard` 的模型适配档。本档不裁定"能不能生成"，只帮剧本**把成本放在有叙事回报的地方**。

**本档不给数量上限**。每个要素的取舍依据是它的叙事任务，不是"模型可能做不到"——用量换来的谨慎会让故事先垮掉。剧本不因高风险场面而回避关键情节，但要在交付时标出它。

## 一、把"必须出现"与"可以替代"分开

逐场过一遍，把这一场里所有可见要素列出来（人、动物、载具、器械、特效、文字、特殊环境），逐个问：

**删掉它，这场的信息或情绪是否变化？**

- 不变化 → 它是生成成本，不是叙事需要：删、换成已有资产、或改为画外声与符号。
- 变化 → 保留，并写清它承担什么。

判据与"没有入站引用的文件不留"同理：**说不出任务的要素不进画面**。

## 二、同一场的人数

人越多，反打、视线与位置关系越难维持，跨镜一致性成本也越高。

- 能用两三人说清的事不写成四五人；每个具名者都要有独立目标或作用（见 [类型机制](16-genre-mechanics.md) 的群像节）。
- 群戏两种写法都成立：**一个人代表群体**（少数具名者＋其余作为环境），或作为整场的高成本项明写出来。
- 判据：**这场戏能不能用更少的具名人物说明同一件事？** 能，就减；减不下去，说明减掉的那个真有作用。

## 三、动物、儿童与非人角色

它们不是禁止项，但**一致性控制的难度高于成人**，动作的连续性与可预期性也更难保证。

- 给它们安排可预期、可重复的动作，不做连续复杂交互。
- 需要它们承担关键情绪时，先问有没有等效替代：声音、他人的反应镜头、留下的痕迹。
- 若必须出现，在剧本里标明它在哪几场承担什么，便于下游按高成本项安排。

## 四、物理交互与高风险场面

常见的高风险项：镜面与倒影、水下、火与烟、复杂手部操作、多人肢体接触、人与动物的互动、液体与布料的变形、透明与反射材质、精细的可读文字。

- 剧本不必回避，但要**标出它在本场的功能**，并给出替代或降级路径（手段归 `zion-storyboard` 的失败模式与后期档）。
- 判据：**这个画面能不能用另一种可见事实表达同一件事？** 能且叙事收益相同，换掉；不能，就保留并标记。
- 关键情绪顶点优先用可稳定实现的可见事实承载，不把整场的成败压在一个高风险镜头上。

## 五、画面内文字

先分清两种完全不同的需求：

| 需求 | 剧本要写的 |
|---|---|
| 观众必须读到**精确内容**（判决书、短信、签名、招牌） | 写明"文字内容需被读到"并给出内容 |
| 只需看出**这是什么东西**（一封信、一份合同） | 写明"只需看出是文件"，不规定内容 |

- 需要精确文字时，实现方式按引擎口径处理：可见中文文字在 GPT Image 2 通道可直接渲染，Midjourney 通道留空交后期合成（见 `zion-assets` 的图像引擎候选与规格档）。
- 不把关键信息做成"必须看清的极小文字"——那是取景与后期的双重风险。

## 六、跨场与跨集的一致性负担

剧本阶段建立的**人物数量、服装变化、伤情、道具归属与场景状态**，是下游一致性的成本来源（登记与治理见 `zion-assets` 的资产一致性档与场景一致性档）。

- 每一次外观或状态变化都要有剧情理由；不变化的部分保持稳定，减少变体。
- 判据：**观众能不能看出这个变化的意义？** 看不出意义的变化只增加了不一致的风险。
- 跨集项目尤其注意：新增人物的节奏、同一场景的状态阶梯度、伤情与时间的对应关系（见 [连载结构](14-serial-structure.md) 的长线三张表）。

## 七、交付时带上风险标注

剧本交付时，把需要下游特别注意的项单独列出，而不是埋在正文里：

- 高风险场面所在场次及其叙事功能。
- 需要精确文字的场次与内容。
- 依赖稀有资产（动物、载具、大型器械、特定环境）的场次。
- 已给出替代路径的项。

这份标注是给 `zion-assets` 与 `zion-storyboard` 的分工输入，也是 `zion-qa` 投喂前检查的对象。

## 八、自检

- [ ] 每场的可见要素都能说出叙事任务，说不出的已删或替换
- [ ] 每场的具名人物数量已问过"能否更少"，减不掉的都有独立作用
- [ ] 动物、儿童与非人角色的动作可预期、可重复，或有等效替代
- [ ] 高风险场面已标出功能，并给出替代或降级路径
- [ ] 画面内文字已区分"需精确读"与"只需看出是什么"
- [ ] 外观与状态变化都有观众能看出的理由
- [ ] 交付附了风险标注，覆盖高风险场面、精确文字与稀有资产
