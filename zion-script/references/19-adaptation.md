# 19 · 改编：从已有材料到剧本

本档用于把小说、真实事件、已有剧本、梗概或其他来源材料发展成剧本时的取舍。**来源、权利状态与允许用途的登记归 `zion-assets` 的来源与权利档**，本档只处理创作决定；两者不互相替代。

原作未提供、无法识别或只有二手转述时，先问核心材料，不虚构原作事实（见 `zion-script` 主文件的承接范围）。

## 一、先划定三类内容

动手前把材料分成三堆，写下来：

| 类别 | 含义 | 处理 |
|---|---|---|
| 必须保留 | 用户或项目指定的受保护事实：核心关系、关键事件、结局方向、不可改动项 | 不得暗改；与新要求冲突时先澄清 |
| 可以改写 | 顺序、场景、次要人物、台词、叙事方式 | 在授权范围内自由处理 |
| 建议舍弃 | 装不进目标时长、需要大段解释、与核心冲突无关的部分 | 按第三节顺序删 |

三堆没分清就开始写，最后必然在"改了什么"和"能不能改"上反复。

## 二、忠实度：先选一档，再谈取舍

| 档位 | 保留 | 可改 |
|---|---|---|
| 忠实 | 关键事件、人物关系、结局 | 顺序、场景、台词、叙事方式 |
| 借体 | 核心前提与主要人物 | 情节走向、次要人物、结局 |
| 借壳 | 类型、设定或气质 | 人物、情节、结局 |

- 选定后**写下来**，它是后续所有取舍的依据；中途换档要重做取舍，不能只改局部。
- 档位由用户要求与授权范围决定，不由作品名气决定。用户说"保留结局方向"时，档位已经落在忠实一侧。
- 忠实不等于逐句复刻：即使最忠实的档位，也要重做媒介转换（见第五节）。

## 三、取舍顺序：从最外层往里删

删东西的把握从大到小，按这个顺序动手：

1. **与核心冲突无关的支线**——删掉不影响主线的，先走。
2. **承担同一功能的场景与人物**——合并，而不是两件都留成半成品。
3. **需要大段解释才能成立的设定**——世界观细节若不能由画面物证与冲突自己长出来，删或降为背景。
4. **只在原作形式里有效、装不进成片时长的内容**——长段心理描写、作者的旁白、并行发生的多线叙事。
5. **最后才动核心事件与结局**，且必须在授权范围内，并让用户知道。

反面顺序（从核心改起、靠删次要内容补时长）最常导致"改到最后认不出原作、时长还是超"。

## 四、压缩的四种手段

- **合并人物**：两人承担同一功能时合并成一人；合并后要检查他的动机是否还成立。
- **前移信息**：原作后段才交代的，提前到能起作用的位置，不等它自己出现。
- **画面替代解释**：环境、物证、他人的反应替代成段的说明（见 [剧本正文](17-script-page-and-format.md)）。
- **内心改行为**：独白与内心描写改成可拍可听的选择与动作（见 [生理性叙事与表演词库](10-physical-acting.md)）。

压缩的判据：**删掉之后，这个人物或事件是否还有不可替代的作用？** 没有就该继续删或合并。

## 五、跨媒介转换要重做的东西

改编到剧本，有四件事必须重做而不是搬运：

- **叙述语言 → 场次与对白**：小说的时间跳跃、概述、议论在剧本里没有对应形式，要变成具体场次，或改用旁白并承担旁白的代价。
- **叙事者 → 一个决定**：原作有叙述者时，先决定在成片里它是什么——无人称（多数情况）、一个具体人物的画外音，还是群众声音。**叙述者的用法与边界见 [对白设计与诊断](04-dialogue-design.md) 的旁白节**；声音层的处理归 `zion-storyboard`。
- **内心 → 外在证据**：原作里最动人的往往是内心活动，它不能直接搬；找到使这份内心成立的外部行为。
- **并行信息 → 主次排序**：原作可以同时铺多条线，剧本的时长装不下；按主线、支线、背景排序，把后两类压成一场或一句。

## 六、与原作受保护事实冲突时

- 用户指定的受保护事实优先于创作便利；叙事上"更好写"不构成改动理由。
- 用户新要求与受保护事实冲突时，**说明冲突点并请用户选**，不以创作授权为由暗改。
- 原作自身前后矛盾时，选一条并写明选择依据，不在剧本里同时保留两个版本。
- 续写与改编已有剧本时，先确认继承的版本（见 [人物设计与世界构建法](11-character-and-worldbuilding.md) 的修订节）。

## 七、交付要点

- 改编交付附**改动说明**：保留了哪些受保护事实、改了哪些、为什么。
- 涉及敏感或需核实的真实事件时，标明哪些是记录事实、哪些是创作补全——这条是证据纪律，具体登记归 `zion-assets`。
- 若改编导致场次增删，按 `zion-script` 主文件的规则递增版本并列出受影响场次。

## 八、自检

- [ ] 三类内容（必须保留／可以改写／建议舍弃）已分清并写下来
- [ ] 忠实度档位已选定，取舍与档位一致
- [ ] 删减按从外层到核心的顺序进行，没有先动核心事件
- [ ] 合并人物后其动机仍然成立
- [ ] 叙述者、内心描写与并行信息已按跨媒介规则重做
- [ ] 与受保护事实冲突处已澄清，没有暗改
- [ ] 交付附了改动说明，版本与受影响场次已登记
