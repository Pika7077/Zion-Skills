# 13 · 受众期待与情绪回报

故事除了"讲什么"，还要回答"给观众什么"。这一层处理的是后者：观众选择看这一类故事时，在期待什么样的情绪经验，以及每一场用什么去兑现。

本档给的是判据与选择集，不是配方。**不预设观众群体**——"某类观众就是某几个痛点"属于项目级假设，由用户或项目提供，不由本档规定。

## 一、先回答一个前提问题

动笔前要能一句话说出：**这部戏让观众得到什么感受。**

- 这不是主题。主题是故事在讲什么（关于亲情、关于选择）；情绪回报是观众看完得到什么（出了一口气、被安抚、被证实、被震动）。
- 判据：把这条感受拿掉，故事还剩什么？如果什么都不剩，说明它就是这个故事的核心，后面所有安排都要为它服务。
- 一部戏可以不止一条，但要能排出主次。两条平级的核心感受会互相抵消。

## 二、情绪期待从哪里来

不靠猜，靠三个确定的来源：

| 来源 | 说明 |
|---|---|
| 题材与类型 | 观众对某类故事有既定期待：复仇要出气、悬疑要揭晓、情感要落定、困境要翻身 |
| 人物处境 | 人物的处境决定观众希望他得到什么：被压制的人该翻身、被误解的人该澄清、被忽视的人该被看见 |
| 用户与项目给定 | 目标观众、投放情境、平台要求是前提条件，直接继承 |

**不自行假设观众群体。** 观众画像缺失时，按"这个故事本身能给出的情绪经验"来确定，而不是套用某类观众的固定清单。写成规则就会被用错——不同的故事面对同一群人，给出的东西本来就不同。

## 三、情绪回报的类型

给一场戏问"这一场兑现什么"，从下面选，不是必用清单：

| 类型 | 观众得到什么 | 依赖的铺垫 |
|---|---|---|
| 逆转 | 被压制的处境翻过来 | 压制必须先被写足，观众要知道他失去了什么 |
| 揭晓与对证 | 真相或答案被摆到台面上 | 线索必须先给过，观众曾经有过猜测 |
| 意外所得 | 没得到期待的东西，得到另一种更好的 | 期待必须已被明确建立 |
| 关系推进 | 两个人之间的距离发生实质变化 | 距离必须先成立，且中途有阻力 |
| 被认可 | 人物的价值被公开确认 | 之前要有被低估、被否定的处境 |
| 失去与告别 | 通过失去确认了某个价值 | 失去的对象必须先有分量 |

- 可以叠加，但不是越多越好。一场戏通常兑现一到两个；塞进四五个，每个都兑现不彻底。
- **兑现依赖铺垫**：这一栏比类型本身更重要。没有铺垫的回报读起来像凭空发糖或硬转。

## 四、有效爆点的双条件

**满足期待 ＋ 出人意料**，两者缺一不可。

| 情形 | 结果 |
|---|---|
| 只满足期待 | 意料之中，观众满足但不会被震动 |
| 只出人意料 | 观众不服，觉得被耍 |
| 两者都有 | 有效——观众想要，但没想到是这样来的 |

两个前提：

- **结果符合逻辑**：前文给出的信息足以支撑这个结果。反转依赖的是"观众看到过但没串起来"的信息，不是新信息——具体纪律见 `zion-storyboard` 的层次感档（藏信息但不骗）。
- **期待被建立过**：观众必须明确知道自己想要什么，否则"满足期待"无从谈起。期待可以由处境、对白、目的或旁白建立，但必须建立。

## 五、大小情绪点的层次

| | 大情绪点 | 小情绪点 |
|---|---|---|
| 体量 | 全片或单集的高峰 | 密度更高、体量更小 |
| 前提 | 完整铺垫 + 足够时长 | 可快速兑现 |
| 作用 | 推动高潮、兑现核心感受 | 持续供能，让观众不走 |

铺法：

- 小点之间不要连续同类型。连续三次同一种小情绪会疲劳，需要换类型。
- 大点之前用小点把期待推到位；大点之后留回落，否则下一个大点不显高。
- 大小是相对关系，不是绝对时长。判断依据是这场比上一场更紧还是更松。

全片层的波峰波谷见 [故事设计与输出范围](03-story-requirements.md) 的张力分布；场次内的重点分配见 `zion-storyboard` 的三步引导法档。

## 六、反面清单

| 反例 | 自检句 |
|---|---|
| 情绪自嗨 | 这个情绪建立在观众已知的信息上，还是建立在我自己知道却没写出来的背景上？ |
| 情绪拉满 | 每场都用最强手段，观众失去参照，后面的高点不再有效 |
| 靠台词宣布情绪 | 说"他很痛苦"不等于观众感到痛苦；情绪要靠可见行为、处境与选择承载 |
| 情绪与处境不匹配 | 处境还没到那个程度，情绪先到了；反过来也一样是失真 |
| 只堆痛苦不给回报 | 观众可以承受痛苦，但要有理由相信后面会得到什么 |

## 七、自检

- [ ] 能一句话说出这部戏给观众的情绪经验，且拿掉它故事就站不住
- [ ] 观众的期待来自题材、人物处境或用户给定的画像，没有自行假设观众群
- [ ] 每场能说出兑现了哪一类情绪回报，且它依赖的铺垫已经写足
- [ ] 关键爆点同时满足期待与出人意料，结果由前文信息支撑
- [ ] 大小情绪点交替，没有连续同类型重复；大点之后有回落
- [ ] 没有情绪自嗨、情绪拉满、靠台词宣布情绪、情绪与处境不匹配的段落
