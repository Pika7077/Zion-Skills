# 15 · 分场结构：一场戏怎样发生变化

场次不是地点加对白，而是一段可以说明“为何现在发生、发生后什么不同”的叙事过程。本档用于写场、改场和删场；不要求每场都有争吵、反转或固定节拍数。

## 一、镜头—场—序列—幕

| 层级 | 处理什么 | 边界判据 |
|---|---|---|
| 镜头 | 一次连续观察；实拍通常对应一段连续拍摄，生成流程还要区分模型内切镜与真实剪辑 | 观察位置、时间连续性或真实剪辑发生变化 |
| 场 | 围绕同一段戏剧任务组织的一组行动与信息，通常共享相近时空与调度 | 时间、空间、主要焦点或戏剧任务发生足以重置观众理解的变化 |
| 序列 | 若干场次共同推进一个阶段性问题、目标或压力 | 阶段性问题得到回答、目标改变、代价升级或故事方向转折 |
| 幕/大段落 | 作品中的主要结构阶段 | 核心行动方向、人物处境或故事规则发生不可轻易撤回的变化 |

这些层级用于判断内容关系，不是固定模板：

- 地点改变通常提示新场，但长镜头调度、电话两端、交叉剪辑或有意的空间连续可以跨地点保持同一戏剧任务。
- 同一地点发生明显时间跳跃、人物焦点更替或任务重置，也可以进入新场。
- 一场不必独立拥有完整起承转合；短过渡场、余波场和信息场可以只完成必要功能，但进入与退出仍应有可说明的差值。
- 序列数量不固定，不因采用“八序列”“十序列”或三幕框架而自动成立。判据是这一组场次是否共同完成了可命名的阶段变化。
- 短片、实验叙事或单场戏可以没有显式幕划分，不为填结构新增层级。

写大纲时先给序列命名为它完成的变化，例如“筹药失败迫使主角越界”，不要只写“开场序列”“冲突序列”这类位置标签。分场后检查每场怎样推进、阻碍或改写该序列的问题。

## 二、场次发动机

先用一句话写清：

> 某人带着什么进入，为了什么采取什么策略；受到什么阻力后，在哪个可见时刻改变策略、认知或关系，最后带着什么新状态离开。

按当前场次需要选择五项：

| 项 | 要回答什么 |
|---|---|
| 进入状态 | 人物进入时已经知道什么、持有什么、处在什么关系与压力下 |
| 当场目标 | 此刻想让谁做什么，或想得到、隐瞒、确认、阻止什么 |
| 策略与阻力 | 人物实际怎样做；对手、规则、空间或自身怎样使原策略失效 |
| 转向 | 哪个新事实、行动结果或选择迫使场面换方向 |
| 退出状态 | 信息、关系、处境、持物、承诺或风险中至少一项发生了什么变化 |

氛围场、等待场和观察场也可以成立。它们未必有对手，但仍要改变观众的感受、预期或信息；拿掉后如果前后体验完全不变，就需要合并或删除。

## 三、目标、策略与阻力

- **目标写成可验证结果**：让对方签字、确认门后是谁、把话题拖到援兵到场，而不是“表达悲伤”或“发生冲突”。
- **策略是正在做的事**：讨好、试探、交换、威胁、拖延、回避、展示证据。只写态度，不算策略。
- **阻力要作用在策略上**：对方拒绝交换、空间不允许靠近、时间逼近、证据反咬本人。与目标无关的困难只是噪声。
- 策略失败后若人物仍重复同一种做法，只是台词变重，不算推进；应改变手段、筹码或承担的代价。

双方目标不能同时成立时，按 [故事设计与输出范围](03-story-requirements.md) 的冲突构造检查。没有对抗的场次不用强行制造双方目标。

## 四、升级不等于转向

| 变化 | 含义 | 场面表现 |
|---|---|---|
| 升级 | 原方向继续，但代价、压力或不可逆性提高 | 提出更重筹码、退路减少、风险逼近 |
| 转向 | 观众对“这场在发生什么”需要重新理解 | 新事实出现、权力易手、目标改变、关系立场改变 |
| 结果 | 本场行动获得可继承后果 | 得到/失去物件、承诺成立、秘密暴露、人物离开 |

一场可以只有升级而没有反转，也可以安静地转向。转向不能只靠作者宣布，须落在可见行动、可听信息或明确选择上。

## 五、进入—退出差值

写完后比较场首与场尾，至少指出一项差值：

- **信息**：谁新知道了什么，谁仍不知道；观众知道的是否不同。
- **关系**：信任、距离、权力、债务或承诺怎样变化。
- **处境**：目标更近还是更远，风险、时间或资源怎样变化。
- **物理状态**：位置、持物、伤情、服装、场景痕迹怎样变化。
- **情绪预期**：观众更期待、担忧、怀疑或释然什么。

差值不是要求每项都变。若一项也说不出，先判断这是否是有意留白；否则删、并、前移或改写。

## 六、场与场的因果接力

相邻场次用“因为—所以”检查，不只用“然后”：

1. 上一场的结果触发下一场行动；或
2. 上一场留下的问题在下一场被追查、回避或付出代价；或
3. 有意切到另一条线，但两条线在主题、信息或时间压力上形成可解释的关系。

下一场若不受上一场任何影响，检查是否只是同一信息换地点重说。时间跳跃、并行线与插叙可以断开表面行动，但仍要保留观众能追踪的因果或信息锚点。

## 七、修改操作

| 症状 | 优先操作 |
|---|---|
| 进入太早 | 从第一个不可逆行动、关键问题或异常结果附近进入 |
| 退出太晚 | 在结果已经成立、观众已理解后尽快离开 |
| 两场功能相同 | 合并场次，让同一空间承担两项相容功能 |
| 转向无铺垫 | 前移一条可见证据，不用临时新信息救场 |
| 只有解释 | 给说话者一个当场目的，使信息成为策略或代价 |
| 场次可删 | 删除；若缺少必要信息，把它迁移到真正产生后果的场次 |
| 次序无影响 | 按因果、悬念或情绪回报重新排序，直到换序会改变理解 |

压缩时优先保留选择、结果和跨场因果；布景进入、重复解释与无后果的寒暄可以缩短。扩写时补足缺失的策略、阻力和结果，不靠增加同义对白拉长。

## 八、自检

- [ ] 能一句话说清人物进入时带着什么、离开时改变了什么
- [ ] 当场目标是可验证结果，策略是可见行动
- [ ] 阻力确实使当前策略失效或变贵
- [ ] 升级、转向和结果没有混为一谈
- [ ] 相邻场次至少有因果、未决问题或明确的信息关系
- [ ] 场界由时空、焦点或戏剧任务的实际变化决定，不只按地点机械切分
- [ ] 多场组合时能说出序列共同推进的问题及其阶段性变化，不套固定序列数量
- [ ] 非冲突场仍改变观众体验或后续状态
- [ ] 删掉、合并或换序测试后，每场保留理由仍成立
