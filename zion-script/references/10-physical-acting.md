# 10 · 生理性叙事与表演词库

关键情绪需要可表演、可听见或可推断的依据。情绪标签可用来说明意图，再按场景需要补充行为；不强制把每句台词翻译成肌肉编码。

默认用自然语言。仅在用户要求 AU 或需要精确区分相似表情时，读取 [FACS 可选参考](facs-reference.md)。生成模型能否按编码控制表情须按实际入口验证。

## 一、从目的到可见行为

先确定角色此刻想做什么、面对什么阻力、如何应对，再选择身体、声音或静止来承载。检查行为是否有触发、有对象、能在当前景别中读到；没有作用的微动作可以省略。

下面都是表演候选，不是情绪诊断或数量清单：

| 表演方向 | 可选行为 |
|---|---|
| 愤怒 / 决绝 | 咬紧下颌、停下手中动作、在重音处收紧语气、持续看向对手 |
| 焦虑 / 紧张 | 开口前短吸气、吞咽、手指反复触碰同一物件、寻找出口 |
| 悲伤 | 视线下落、声音断开、唇轻颤、流泪或努力忍住泪水，按人物与时刻选择 |
| 掌控 / 冷静 | 稳定呼吸、放松手指、从容等待、主动选择何时回应 |
| 沉重 / 被压垮 | 肩部下沉、动作变慢、回答迟滞、借物支撑身体 |
| 震惊 / 僵直 | 暂时不动、唇微张、迟来的吸气、目光停留在触发物上 |
| 压抑 | 收紧后又松开的下颌、未说完的字、压住的呼吸、放下又收回的手 |

同一行为可能有不同含义，须放回情境判断。允许哭泣、夸张表情、长时间静止和有意同步的群体反应，不规定统一延迟或错峰时间。失焦听者只补充真正影响关系或连续性的反应。

## 二、八种观察通道

| 通道 | 观察什么 |
|---|---|
| 呼吸 | 速率、深度、屏息、呼气的性质 |
| 眼部行为 | 注视对象、眨眼、视线变化 |
| 下颌张力 | 咬紧、松弛、运动或定住 |
| 注意变化 | 视线漂移、注意滑脱、反应延迟 |
| 扫视路径 | 被追踪的目标、寻找顺序 |
| 恢复过程 | 刺激后如何回到基线 |
| 控制尝试 | 可见的压制、掩饰或重新组织 |
| 情绪余波 | 高潮过后仍影响行为的部分 |

只取能够推动本场或帮助表演的通道，不逐项填满。

## 三、身体、距离与状态

| 维度 | 可观察内容 |
|---|---|
| 重心 | 身体向前、向后、下沉或借物支撑 |
| 节奏 | 快慢、停顿、规律或慌乱 |
| 开合 | 躯干与四肢开放、收拢或防护 |
| 呼吸 | 身体负荷与说话方式是否相容 |

重心高低或动作快慢不直接等于性格、权力或心理状态。可用占据空间、抢先接物、等待回应等具体行为表现地位变化，避免给所有角色套相同动作。

距离可按贴近、伸手可及、隔桌、隔房间等关系写；只有精确走位影响事件时才使用米数。亲密、戒备与侵入的意义取决于人物、文化和现场关系，不用统一距离阈值定性。

动作可以包含连续过程。例如“伸手入包，握住刀柄，抽出刀后停在身侧”保留了获取物件的因果；不能为迁就未经核验的模型经验，直接跳成“手臂已展开”。下游可按时间与可读性拆镜，但须保留关键接触与结果。

疲劳、伤情和情绪余波按故事时间继承；有休息、治疗或时间跳跃依据时可以恢复，不要求每场都更沉重。

## 四、台词前、中、后的可选节拍

只有当停顿或行为改变台词含义时才展开：

| 位置 | 可写内容 |
|---|---|
| 开口前 | 决定是否说出、短吸气、停止手中动作 |
| 台词中 | 重音、语速、与对手的目光或物件互动 |
| 台词后 | 等待回应、转移注意、保持或释放动作 |

例：“别再问我了。”重音落在“再”；说完仍看着对方，直到对方放下录音笔。

无需每句都写三段，也不固定台词后停顿秒数。对白时长按朗读与真实停顿估算；可并行的动作不要重复计时。

## 五、表演端点词库

端点便于表达当前状态，不替代使状态成立的过程：

| 候选方向 | 可见描述或用途 |
|---|---|
| Deadpan Neutral | 有意保持无表情 |
| Fierce Focus | 目光锁定任务对象 |
| Subtle Arrogance | 以细微姿态或回应时机体现优越感 |
| Candid Profile | 自然侧面状态 |
| Post-Workout Fatigue | 运动后的呼吸与疲态 |
| Predator Glare | 紧盯目标、等待时机 |
| Sunblind Squint | 因逆光眯眼 |
| Total Dissociation | 用注意脱离现场的表演方向；不据外观作临床判断 |
| Controlled Breath | 有意控制呼吸 |
| Suppressed Smile | 嘴角将起又压住 |
| Quiet Devastation | 眼含泪光、下颌紧、仍在支撑 |
| Wary Recognition | 认出后先观察、暂不靠近 |
| Nervous Composure | 努力维持镇定 |
| Cold Calculation | 扫视目标、保持克制 |
| Bitter Amusement | 笑意与当前遭遇形成反差 |
| Exhausted Relief | 脱险后的松弛 |
| Frozen Shock | 唇微张、身体暂时静止 |
| Simmering Rage | 下颌收紧、注视稳定 |
| Vulnerable Openness | 放下防备、愿意回应 |

## 六、视线与表演问题诊断

眼睛可以追踪、回避、确认或停留在具体对象上。视线与转头先后按动机决定；眼神光服从光源，不能单独修复缺少注意对象的问题。受控静止可以有效，不强制眨眼率或微跳视字段。

| 症状 | 先检查，再选修法 |
|---|---|
| 表情像在展示标签 | 回到角色目的，给出与对手或物件有关的任务 |
| 听者像在等口令 | 判断反应应从哪条信息开始，也允许刻意不回应 |
| 情绪突然出现 | 检查触发与铺垫；突发消息本身也可构成依据 |
| 威胁动作套路化 | 按人物策略选迟疑、日常或爆发，不强制慢转头 |
| 强事件后立刻复位 | 检查余波与时间跳跃依据 |
| 特写动作过量 | 只保留承载此刻含义的变化，按项目风格调整幅度 |
| 目光无目的 | 写清注意对象，或明确失焦/游离的叙事意图 |

混合情绪是一种选择，单纯快乐、直接悲伤或平静同样可以成立，不用统一表演分数作为验收门槛。

## 七、可选人物表演档案

长期角色或需要试读时，可记录：

- 当前目标、心理策略与身体状态。
- 音色、语速、口音和压力下的变化。
- 有意义的动作习惯及其触发条件。
- 视线、倾听方式和步态。
- 遇到特定人或事件时的变化。

只写当前故事需要的部分；不要求固定字数、软化对象数量、反差句或每场节拍数。服装与摄影信息只有确实影响表演时才提及，完整设计仍交给相应制作技能。

## 八、表情的强度、时序与遮挡

除了“动哪块肌肉”，还有三件事决定表情在成片里读不读得出来。

**强度**：给表情一个幅度，不要一律拉满。

| 幅度 | 可读范围与用途 |
|---|---|
| 微弱 | 只在特写里可读；用于藏情绪、克制型人物、日常状态 |
| 明显 | 中景即可读；用于主要情绪与态度转折 |
| 强烈 | 远近都能感觉到；只给爆点，且即使最强也留余地——拉满容易变成鬼脸 |

默认取最弱的一档，需要时再往上加。

**时序**：表情有起、有停留、有回落，不全程绷在峰值。峰值对齐台词的重音字，句尾留一点余韵，防止“话没说完脸先松”。同时使用表情与台词时，两者的时间要一起算，不能让表情的停留挤掉说话的时间。

**遮挡**：眼睛被墨镜、侧脸、背影或阴影挡住时，眼周动作拍不到。这时改写露出来的部分——眉、下半张脸、下颌、头部角度；只在眼睛真的露出时才写眼部动作。背影、空镜与字幕卡可以完全豁免表情。

单侧动作（单边嘴角、单边挑眉）要写明是哪一侧，并与本场的轴线一致，不在同一场里中途换边；同一处不要叠互相矛盾的动势（同一侧嘴角既上扬又下压）。

同一类外观（例如笑）可以用眼周是否参与来区分不同写法，这是外观差异；不能据单个动作判定人物的真实情绪——情绪由台词、情境与上下文共同建立。

## 九、自检

- 关键情绪是否通过行动、声音或情境成立，标签是否有足够支撑？
- 行为是否符合人物目标与身体负荷，是否保留动作因果？
- 静止、同步、哭泣或夸张是否服务本场，而不是被模板强行改掉？
- 台词、动作与停顿是否满足时长，细节是否在预期景别可读？
- 跨场状态有无无缘由复位或无依据加重？
- 只有需要时才展开表演档案、三段节拍和 AU；没有数量配额。
