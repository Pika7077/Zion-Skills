# 14 · 连载结构：集与集之间

一部戏分集讲述时，每集要能独立看完，整体又要是一条连贯的线。本档处理这两者的关系——单集自足与长线连贯的平衡。

单集与全片的张力分布见 [故事设计与输出范围](03-story-requirements.md)；每集兑现的情绪回报见 [受众期待与情绪回报](13-audience-and-payoff.md)。分集结尾的镜头落点由 `zion-storyboard` 的开场与结尾档处理。

## 一、两条曲线要并行

| 曲线 | 管什么 | 失败成什么样 |
|---|---|---|
| 单集曲线 | 这一集自己的起、承、转、合 | 只有大线：每集都不好看，像长片被切成段 |
| 全剧曲线 | 跨集推进的主线 | 只有小线：单集热闹，整体散，看完记不住 |

两条都要有。最常见的错误是只顾一条。

## 二、一集要做完的四件事

1. **本集的核心事件**——有开始、有结束，在本集内闭合。
2. **推进全剧主线一步**——哪怕很小，不能原地。
3. **结尾留下继续看的理由**——见 §三。
4. **人物状态有可见变化**——处境、关系、认知至少一样与集初不同。

判据：**把这一集抽掉，全剧会缺什么？** 说不出具体缺什么，说明它是可删的填充集。

## 三、结尾切口的类型

| 类型 | 做法 |
|---|---|
| 悬念切口 | 把答案切断在揭示前 |
| 反转切口 | 给出一条能重新解释前文的信息 |
| 处境恶化切口 | 刚解决一个问题，立刻面对更糟的 |
| 新信息切口 | 出现一个此前不知道的要素 |
| 关系变动切口 | 两个人的关系状态在这一刻改变 |

纪律：

- **切口必须被下一集接着。** 开了头不接，比不开更伤——观众会开始不信你的钩子。
- **类型要轮换。** 连续用同一种（尤其是悬念切口）会让观众疲劳，久了会觉得“下一集也无所谓”。
- 切口是**信息的重新组织**（观众以为的和实际不同），不是单纯再加一个事件。

## 四、集与集的关系

| 关系 | 说明 | 适合 |
|---|---|---|
| 递进 | 每集推进同一条线，难度或代价递增 | 主线明确的复仇、追查、成长 |
| 并列 | 每集处理一个相对独立的单元，共享人物与主题 | 单元剧、行业剧 |
| 回环 | 每集回到同一处境但状态不同 | 悬疑、心理、困境类 |

实际项目多是混合：**主线递进 + 支线并列**。要写清哪条是主线、哪条是单元。

判据：**观众跳看几集，会漏掉什么？** 能说出漏掉的具体内容，说明结构清楚；说不出，说明这一段的推进不够硬。

## 五、长线弧线的三张表

跨集要维持的是三样，各记一张表：

| 表 | 记什么 |
|---|---|
| 人物状态 | 每集结束时主要人物的处境、身体状态、认知（不能原地，也不能无理由突变） |
| 信息掌握 | 谁在第几集知道了什么（观众知道的与角色知道的要分开记） |
| 关系状态 | 核心关系的距离、信任与权力位置 |

判据：**这三张表在集与集之间能不能对上。** 对不上，就会出现人物能力突变、角色说出他不该知道的事、关系凭空空转。

表要跟着交付走：跨集的人物状态进入资产与分镜的交接契约，不能只停留在编剧的脑子里。

## 六、单集内部的结构

一集有自己的小曲线：**起（建立本集处境）→ 承（推进）→ 转（本集的高点）→ 合（切口）**。

- 集内高点不必是全剧高点，但必须是**本集最强的那一下**。
- 单集时长有限时，优先保本集核心事件与结尾切口，压缩铺垫。
- 与全片曲线的关系：全片的高点落在某一集里，那一集的其他部分要为它让路。

## 七、钩子的分布

| 位置 | 作用 |
|---|---|
| 开场 | 接上一集的切口，或直接进入一个新的异常与冲突 |
| 中段 | 长单集需要第二次拉人；中段疲软是连载最常见的塌陷处 |
| 结尾 | 切口（见 §三） |

- 钩子不是“再加一件事”，而是让观众重新组织已经看到的信息。
- 每集要兑现的情绪回报按 [受众期待与情绪回报](13-audience-and-payoff.md) 确定，钩子不能代替回报——只吊胃口不给回报，观众会走。

## 八、常见问题与修法

| 问题 | 表现 | 修法 |
|---|---|---|
| 中段疲软 | 主线在中段停滞，靠支线撑 | 逐集检查是否推进主线一步 |
| 钩子失信 | 上集埋的下集不接 | 登记未兑现项，逐条回收 |
| 人物漂移 | 跨集性格或能力突变 | 用人物状态表逐集比对 |
| 信息混乱 | 观众搞不清谁在第几集知道什么 | 用信息掌握表；观众与角色分开记 |
| 单集可删 | 抽掉某集全剧不缺东西 | 并入相邻集，或补一条主线推进 |
| 切口同质 | 每集同一类型切口 | 轮换类型，或改为处境恶化 |

## 九、自检

- [ ] 每集能说出它推进了主线的哪一步
- [ ] 抽掉任一集，全剧会缺具体的东西
- [ ] 切口类型有轮换，且每条都被下一集接着
- [ ] 集与集的关系已明确（递进／并列／回环，及主线与单元的比例）
- [ ] 人物状态、信息掌握、关系状态三张表在集间对得上
- [ ] 每集有自己的高点，且不是全片高点的简单重复
- [ ] 未兑现的钩子已登记并有回收计划
- [ ] 每集的情绪回报已兑现，没有只用钩子吊胃口
