# 故事设计与输出范围

本参考用于剧本创作。输出范围服从 zion-script/SKILL.md：只交用户要求和完成任务所需的内容，不强制固定项目数或固定顺序。

## 故事判断

根据题材、时长和平台选择结构。重点检查：

- 主角或核心观察对象是否清楚。
- 人物想要什么，阻力来自哪里，选择产生什么代价。
- 观众获得信息的顺序是否形成理解、悬念或情绪。
- 关键事件是否改变局势、关系或人物认识。
- 结尾是否完成本次承诺；是否首尾呼应由故事需要决定。
- 人物行为是否符合身份、处境和已建立的性格。
- 台词是否自然，并避免重复解释画面。

钩子、反转、高潮和余韵是可用工具，不设统一的秒数或出现频率。短视频可更早建立冲突，慢节奏短片可以用气氛、异常或人物选择吸引观众。

## 张力分布

篇幅足够展开时，检查全片的紧张程度有没有起伏：

- 需要有若干次明显的高点，而不是全程中速推进。持续高压与持续平庸一样会让观众失去参照。
- 高点之间要有回落。没有低谷，高峰就不显出高度差。
- 决定性的反转或爆发落在全片偏后、但仍留有余地的地方，让收束有时间完成。
- 结尾留钩子时，钩子强度低于本次的高点，不与全片最强点争抢。

这是检查方向，不是分值模型：不需要给每一场打分，也不需要凑固定数量的高点和低谷。更实用的做法是逐场比较——这场比上一场更紧还是更松，为什么。

大小情绪点的层次（小点持续供能、大点推动高潮、大点之后留回落）与每场兑现的情绪回报见 [受众期待与情绪回报](13-audience-and-payoff.md)。

## 冲突的构造

冲突不是“吵架”，是**两个目标不能同时成立**。

四个必要要素，缺一个就会读成情绪发作而不是对抗：

| 要素 | 要写清什么 |
|---|---|
| 双方的目标 | 谁要什么，且这两样不能同时实现 |
| 筹码与代价 | 每方投入了什么、输了会失去什么 |
| 阻碍的可见形式 | 对方用什么挡住——人、规则、时间、空间，或自己的身体 |
| 退路 | 每方为什么不能退出（退了会怎样） |

**判据：这场冲突去掉台词，还读得出来吗？** 能读出来（姿态、距离、物件、谁在阻挡谁）说明它在画面与行动上成立；读不出来，说明它只是嘴上在吵。

**升级**：冲突要推进，不是重复。每一轮交手要让某一方更接近或更远离目标，或让代价变高、退路变窄。同一句话换个说法再说一遍，不构成推进。

**立场**：观众要能判断站在谁那边，或至少理解双方各自的理由。双方都没理由、或一方有理由而另一方纯粹作恶，张力都会掉——除非这正是要表达的处境（例如荒诞或制度性的无力）。

**空间参与**：冲突在什么空间里发生会改变它的性质——隔桌谈判、门口僵持、狭窄通道、公开与私下，各自允许的动作和代价都不同。场景要能承载这场冲突（见 `zion-assets` 的场景一致性与状态阶梯档）。

**作为钩子用时**：开场用冲突起手，要保证冲突的**具体形式在几秒内可见**（不靠台词解释）、观众立刻能分辨双方各要什么、悬念落在结果与代价上而不只是“他们在吵什么”。形式选择见 `zion-storyboard` 的开场与结尾档；兑现什么情绪回报见 [受众期待与情绪回报](13-audience-and-payoff.md)。

**两难困境**：与"双方目标不能同时成立"不同——那是两方对峙，这是**一个人**的两个选项都有代价，必须选一个。

- 判据：**去掉任何一个选项，人物都能轻松过关吗？** 能，说明这是假两难，其实只有一个真选项，另一个只是装饰。
- 两个代价都要**具体且在此前建立过分量**，观众得知道失去哪个都疼；现编的代价不算。
- 选择要留下痕迹：选了 A，失去的 B 要在后续场次里可感，否则观众读成"其实什么也没失去"。
- 升级方向：让两难在更短的时间里再次出现，且第二次的代价更高——这比把同一个两难拉长更有效。

## 可选设计模块

按任务选择：项目名、一句话故事、主题、人物目标与阻力、代价、悬念、情绪曲线、梗概、结构、场次表、人物关系变化、结尾设计、人物与场景设定、声音或视觉方向。

用户只要正文时，把必要设计融入剧本，不先输出大套分析。用户要方案审阅时，再显式列出相关模块。

## 结局

结局要完成本次承诺，并回答观众“这部戏给我什么”（见 [受众期待与情绪回报](13-audience-and-payoff.md)）。四种收束形态，按项目选择：

| 形态 | 做法 | 需要什么才成立 |
|---|---|---|
| 闭环 | 主要问题被回答，关系与处境落定 | 承诺在过程中已被明确建立 |
| 开放 | 停在选择发生的一刻或之后不久 | 此前信息足以让观众判断可能的走向，否则读成没写完 |
| 反转 | 末段给出一条能重新解释前文的信息 | 该信息此前必须可见（见 [叙事顺序与信息管理](20-narrative-order-and-information.md) 的披露纪律） |
| 苦甜 | 得到想要的同时失去同样重的东西 | 两端都要在此前建立过分量 |

纪律：

- **结局不引入新问题**。留钩子时钩子强度低于本片高点，不与全片最强点争抢（见上文「张力分布」）。
- **主线先收，支线后收**；支线有意留白时要写明是有意的，否则会被读成遗漏。
- 结局的**画面落点**（收束帧、视线落点）归 `zion-storyboard` 的开场与结尾档；剧本负责让那个落点有可指的东西。
- 检查一次：把结局拿掉，故事是否仍然成立？成立说明它只是停下来了，没有完成承诺。

## 时长与节奏

有目标时长时，估算对白朗读、动作、反应和必要停顿。镜头或场次时长由内容决定，不套固定区间。

蒙太奇、并行动作和连续动作可以在一个段落或镜头中表达；只有时间、地点、因果或生成可读性需要时才拆开。重要动作无需固定拆成“前—中—后”三镜，但动作起因、关键接触和结果必须能被观众理解。
