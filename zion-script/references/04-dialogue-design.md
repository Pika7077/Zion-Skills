# 04 · 对白设计与诊断

对白承担三件事：谁在说、说了什么、**怎么说**。前两项写在台词文本与人物设定里，第三项最容易被漏掉——怎么说，决定这句台词能不能落到这个人身上。

剧本阶段把说话方式当成人物的一部分记录下来（词汇、句长、语速、口癖、压力下的变化），写进人物备注。具体的生成字段写法由 `zion-storyboard` 的音频与对白档处理。

## 一、语言指纹

同一部戏里，不同人物不该说同一种话。建立语言指纹看四项：

| 项 | 看什么 |
|---|---|
| 词汇量 | 用词范围与常用词；是否用书面语、行话、方言词 |
| 句长 | 习惯短句还是长句，是否一次把话说完 |
| 口头禅与句式 | 反复出现的说法、称呼方式、爱用反问还是断言 |
| 身份语感 | 职业、教育、地域、年龄在说法上留下的痕迹 |

写完后遮住人名读一遍：如果几句台词互换说话人也照样成立，说明语言指纹还没建立。

## 二、潜台词层级

台词可以分几层：0 层把意图直接说出来（“我很愤怒，我要杀了你”）；一到三层则让说出口的话与真实动机错开，靠语境、动作或对象关系补足。

不是所有台词都需要潜台词。信息交代和过场应答直说就是效率。需要潜台词的是关系戏、博弈戏，以及人物不愿说或不能说真话的时刻。

写潜台词时，说出口的话仍要符合这个人此刻的处境与关系——潜台词不是谜语，观众应当能从上下文推出真实意图。

## 三、冲突推进力

每句台词至少改变一项：信息、立场、情绪或行动。

不推进的台词有几类：礼貌寒暄、重复观众已知、被动附和、只为了把场面撑长。这些不等于必须删——寒暄有时在建立关系，重复有时是刻意的强调。判据是它有没有产生变化；没有变化又占着时长，就该合并或删掉。

## 四、信息效率

避免两个反向：向观众交代双方都知道的事，以及把设定硬塞进对白。

设定优先由画面物证与冲突自己长出来；确需台词交代时，让说话人有说这句话的理由——对方不知道、需要当众挑明、故意试探。

## 五、节奏与气口

- 单句长度按朗读估算。过长的句子读不完，也演不完。
- 关键句之后留出气口，让反应有时间发生。
- 长短句交替读起来才有起伏；连续同等长度的句子会显得平。
- 对白时长必须落在本场可用时长内。装不下时按落点拆，不删原意、不加速。

## 六、记忆点

记忆点不是每部戏都必需，也不是每场都要。需要时，它通常出现在两个位置：把复杂处境压成一句话的地方，以及人物做出决定的地方。记忆点靠前面的铺垫成立，不能靠单独拎出来一句漂亮话。

## 七、诊断与改写

逐句过一遍上述维度，标出问题句。改写必须给出依据：

```markdown
- 原句：“……”
- 问题：属于哪一项（语言指纹／潜台词／推进力／语感／信息效率／节奏／记忆点）
- 改写：“……”
- 依据：改动解决了什么，为什么改写后仍符合人物与情境
```

只标问题不给改写，或只给改写不给依据，都不算完成诊断。改写不得改变人物动机、关键信息与结局；用户要求严格原文时只报告问题，不动笔。

## 八、自检

- [ ] 遮住人名后，台词仍能分辨出说话人
- [ ] 需要潜台词的地方，观众能从句境推出真实意图
- [ ] 每句台词至少改变信息、立场、情绪或行动之一
- [ ] 没有向观众交代双方已知信息的句子
- [ ] 单句读得完；关键句后有气口；长短句有交替
- [ ] 对白总时长落在本场可用时长内
- [ ] 改写附了依据，未改变人物动机、关键信息与结局
