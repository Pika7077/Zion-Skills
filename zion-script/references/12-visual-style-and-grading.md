# 叙事视觉意图

只在视觉变化会影响剧情、信息或人物选择时读取。本档记录“故事为什么需要这种视觉差异”，不制作资产美术、布光方案、摄影参数或模型提示词。

## 记录内容

- 时代、季节、昼夜或天气对事件的实际影响。
- 必须被观众识别的颜色、材质、空间或道具信息。
- 场次之间有叙事作用的明暗、冷暖、饱和度或媒介变化。
- 必须保留的文化、地域、职业和生活痕迹。
- 用户明确禁止改变的视觉事实。

跨场继承已确认的时代、主要色彩关系、人物与场景身份、光源逻辑和材质；有意变化需有叙事依据。画幅只有在影响构图或信息揭示时才需要决定。真实感或风格化遵循项目方向，不自动选择写实基线。

不要为了“电影感”预设调色、镜头、颗粒、光比、分辨率或固定风格词。完整视觉资产和图像提示词由 `zion-assets` 建立；镜头、灯光、调色执行和视频提示词由 `zion-storyboard` 决定。

## 交接格式

按场次写入简短的 `visual_intent`：

```text
scene_id: SC001
story_function: 让观众在签字前认出合同仍为空白
visible_facts: 深蓝封面；签字页无签名
change: 夜雨开始后纸面出现水迹
locked_constraints: 合同正文不在生成画面中精确呈现
```

上述内容随 `project_id`、`script_version` 和 `scene_id` 交给下游。资产与分镜可以选择不同实现方式，但不能改变锁定的故事事实。

## 自检

- 每条视觉要求都能说明它承载的剧情信息。
- 没有越权指定图像模型、视频模型或投喂写法。
- 没有把候选风格词写成不可修改的故事事实。
- 场次 ID 和剧本版本可追踪。
