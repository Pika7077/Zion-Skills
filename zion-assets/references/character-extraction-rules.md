# 人物提取详细规则

## 一、剧本格式识别规则

### 1.1 标准剧本格式

典型的影视剧本/短剧剧本格式特征：

```
【场景X：地点 - 时间】
角色A
对白内容第一行。
对白内容第二行。

角色B
（动作描述）对白内容。

【场景X+1：另一地点 - 时间】
...
```

识别要素：
- **场次标记**：以 `【` `第X场` `Scene` `场次` 开头的行为场景切换
- **角色行**：单独成行、不以标点结尾的短行，通常2-4个汉字
- **对白行**：紧跟角色行之后的段落
- **动作/描述行**：用括号 `（）` 包裹或独立成段的叙述
- **叙述段落**：较长的描述性段落，通常出现在每场开头

### 1.2 小说格式

小说的人物信息分散在叙述中：
- 首次出场通常伴随外貌/身份描述
- 对白以引号标记，说话人通过"XX说""XX道"等引导
- 需要通过命名实体识别 + 上下文关联提取人物信息

### 1.3 纯角色列表格式

部分输入可能本身就是角色列表：
```
角色名：性别，年龄，身份，性格描述，外貌描述
```

此时直接解析字段，不进行人物识别步骤。

## 二、人物识别与合并策略

### 2.1 人物实体识别优先级

1. **对白说话人**（置信度最高）
2. **叙述中明确命名的人物**
3. **通过称谓/代词可消解的人物**
4. **通过上下文推断的隐含人物**

### 2.2 同一人物合并规则

以下情况应合并为同一人物：

| 情况 | 示例 | 处理方式 |
|------|------|----------|
| 姓名+昵称 | "林婉儿"与"婉儿" | 合并，正式名=林婉儿，别名=婉儿 |
| 姓名+称谓 | "张总"与"张明远" | 合并，确认后统一 |
| 姓名+身份 | "林医生"与"林雪" | 合并，正式名=林雪，别名=林医生 |
| 姓名+关系称呼 | "妈妈""母亲"与"李秀兰" | 合并，标注不同语境使用不同称呼 |
| 同一身份多人 | "服务员"在不同场景出现 | 根据上下文判断是否同一人，无法判断时编号区分 |

### 2.3 合并依据验证

- 同一场景中，称呼在不同角色口中一致指向同一人
- 身份标签与姓名在叙述中可对应（如"林医生叹了口气...""林雪整理了一下白大褂"）
- 关系网络可闭合（如A叫B"老公"，C叫B"女婿"，则B为关系交汇节点）

## 三、人物信息提取细则

### 3.1 外貌特征提取

从原文提取外貌信息时的优先级：
1. 原文明写的具体描述（保留原文用语）
2. 从行为推断的静态特征（如"她需要踮脚才能够到顶层→身高偏矮"）
3. 从他人评价/反应推断（如"他的目光让人不敢直视→眼神有压迫感"）

**禁止行为**：
- 原文没写五官具体特征时，不自动填充模板词
- 原文没写年龄时，不随意猜测具体数字
- 原文没写发型/服装时，标注"原文未描述"

### 3.2 性格特点推断

性格特点从以下维度提取：

| 推断维度 | 证据来源 | 示例 |
|----------|----------|------|
| 行为模式 | 多次重复的行为 | "每次开会都最后一个发言→谨慎/观察型" |
| 対白风格 | 语气、用词、节奏 | "说话总是带反问→质疑型思维" |
| 他人评价 | 其他角色的评价 | "'你这个人就是太较真'→固执/认真" |
| 冲突处理 | 面对冲突的反应 | "被指责时沉默不语→内向/忍让型" |
| 决策方式 | 关键时刻的选择 | "毫不犹豫挡在前面→勇敢/冲动" |

**禁止行为**：
- 仅凭一次行为就下性格定论
- 将所有角色套入固定性格模板
- 冲突人格特质不标注（如"表面温柔内心冷酷"需从原文直接证据支持）

### 3.3 关系提取规则

关系类型分类：
- **血缘关系**：父子、母女、兄弟、姐妹、祖孙等
- **婚姻/恋爱关系**：夫妻、情侣、前任、暗恋对象等
- **职业关系**：上下级、同事、客户、竞争对手等
- **社会关系**：朋友、邻居、同学、师生等
- **对立关系**：敌人、仇人、对手等
- **其他**：救命恩人、债主、委托关系等

提取时注意：
- 关系是双向的，在两端人物记录中必须对称
- 同一对人物可能有多重关系（如"既是同事又是情敌"）
- 隐含关系需要标注推断依据

### 3.4 台词风格提取

分析维度：
- **语气特征**：命令式/请求式/反问式/陈述式/感叹式
- **用词偏好**：高频率词汇、口头禅、行业术语
- **句长与节奏**：长句连贯/短句跳跃/长短交替
- **礼貌程度**：敬语使用情况、称谓习惯
- **情感外露度**：直白/含蓄/讽刺/反语

提取时摘录 2-3 句代表性台词原文作为示例。

## 四、忠实提取与授权设计

- 提取时保留原作明示的外貌、性格和相似设定，包括双胞胎、统一制服或刻意同貌。原文出现的常见形容词可以照录，不为“去模板化”改写事实。
- 检查描述是否有来源，是否把推断或设计冒充原文；无依据的模板化补词应删除或标为待设计。
- 不因单次行为给角色定性；人物可以善良、单纯或类型化，复杂度按原作与任务决定。
- 区分困难时记录混淆点。只有授权设计时，才提出适合实际镜头的识别锚点，例如声音、位置、服装细节或动作习惯；不规定差异数量，不强制修改骨相。
- 源材料明确需要角色相似时，保留相似性，并把可观察的区别或暂时无法区分的情况交给下游。

## 五、视频输入特别规则

### 5.1 语音识别质量标注

对视频来源的每个人物，标注 ASR 质量：

```
asr_quality: high | medium | low | unavailable
- high: 对白清晰完整，说话人可明确区分
- medium: 对白可识别但可能有遗漏或说话人混淆
- low: 对白片段化，大量内容无法识别
- unavailable: 无法进行语音识别
```

### 5.2 视觉补充规则

从视频画面提取的视觉信息：
- 服装颜色、款式（可作为"原文明确"级别）
- 发型、体型（可作为"原文明确"级别）
- 面部特征（受限于视频分辨率和角度）
- 场景中的人物互动关系

### 5.3 视频人物识别特殊性

- 同一演员可能饰演不同角色 → 通过服装/场景切换区分
- 远景/背影可能导致人物混淆 → 标注不确定性
- 群演/路人需标注为"功能角色"或"龙套"
- 声音特征可辅助区分说话人
