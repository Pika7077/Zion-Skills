# 人物设定表模板（参考资产版式）

版式服务于身份、比例和材质的可读性。外形取自人物卡与源材料；忠实提取与授权设计的边界见 [人物提取规则](character-extraction-rules.md)。跨模型时保留已确认的身份锚点与状态命名，再适配语法。

## 二、版式模板

### 2.1 四视图设定表（标准）

- 排列：左 → 右 = 正脸半身特写 / 正面全身 / 标准 90° 侧身全身 / 180° 背面全身。
- 左侧特写占较大画面比例，正脸正视镜头，头部水平，完整展示头顶发型、双耳、面部、肩颈、锁骨与上胸。
- 三个全身视图脚底处于同一水平线，完整显示头顶至鞋底与全部拖尾，不裁切。
- 视图之间留合理间距；纯净浅暖灰棚拍背景，无场景杂物。
- 柔和均匀高调光：大面积柔光箱 + 正面偏上主光 + 轻微环境补光，阴影克制。

### 2.2 三视图（轻量）

正脸 / 90° 侧身 / 背面，全身。用于只需确认体型、服装结构与背面设计的场合。

### 2.3 头三视图（转向与表情）

正脸 / 3/4 侧 / 正侧，仅头部与肩。用于表情与转向参考，避免全身图稀释面部精度。

**视图从实际分镜倒推**：分镜不会出现的角度不必制作。四视图是可选模板，不是默认配额。

## 三、一致性锁定句（可直接复制改写）

> 以下所有视图为完全同一人物，脸型、五官、妆容、发型、发饰、服装、刺绣纹样、腰封、首饰、材质与配色全部保持一致。

后面接一段**紧凑身份锚点**（形状与比例、面部与发型、服装结构与材质、辨识特征），不逐件罗列花型。

## 四、同图还是分图

| 做法 | 适用 | 代价 |
|---|---|---|
| 四视图同图 | 风格确认、比例确认、快速审稿 | 分辨率被四等分，面部精度下降；视图间仍可能互相漂移 |
| 面部特写单出 + 全身三视同图 | **推荐默认** | 需两次生成，换来可用的身份锚点 |
| 每视图各出一张 | 后续要作为视频参考图逐张引用 | 生成次数增加，需统一锁定句保证一致 |

## 五、比例与体态写法

按角色设定描述比例与体态，例如肩宽、头身关系、重心和姿势。需要精确设计时保留数值并补充可见关系；不把高挑、纤细或特定头身比作为所有角色的默认外形。

**步态与行走特征**：不露脸镜头多的角色（背影、远景、隐藏型人物）应在本节补一行步态——步幅大小、落步轻重、重心位置、手臂与习惯动作。它是**背影镜头唯一的识别锚点**，写不出来的人一旦转过身或走出画面，观众就认不出。写法只写可见事实（"步幅偏小、落步轻，重心微前倾，双手习惯插兜"），不用"气质沉稳"这类形容词。字段位置见 [人物 JSON](json-schema.md) 的 `visual_dna.gait`。

## 六、引擎适配

- **GPT Image 2（默认）**：结构化分句，说明各参考图承担身份、风格或构图的职责；输入限制按 [图像引擎](18-image-engines.md) 的官方资料与实际入口核验。要渲染的文字用引号写出。
- **Midjourney（仅用户主动提起）**：只使用当前已核验的参数与参考图方式，不沿用旧版本参数。

## 七、反模式清单

1. 一条提示词里混两个以上美术体系且**无主从结构**（半写实 + 娃娃感 + 电影级 CG 同时出现，每套都想要）。**有意融合**按题材档 §跨题材融合方法 建立主从后可成立，不算此类。
2. 用气质形容词代替可见特征。
3. 纹样与刺绣逐处罗列，把生成预算从身份上挪走。
4. 单条资产提示词超过约 800 字符仍在堆细节——先分层，不硬塞。
5. 把参考图当服装设计稿交付：参考图的职责是锁身份，不是展示设计。
6. 默认四视图同图，却不检查面部精度是否够后续引用。

## 八、分层写法

按「身份锚点 → 视图/姿态 → 服装与状态 → 背景与光线 → 布局约束」分段，每段只放该段真正需要的词：

1. **用途与版式**：人物设定表 / 四视图 / 排列顺序 / 角度 / 同水平线 / 不裁切 / 背景与光。
2. **身份锚点**（保留足以识别的视觉特征与体态比例）：脸型轮廓、发型与发饰、服装结构与主色；不露脸镜头多时加步态（见第五节）。
3. **材质**：丝缎 / 轻纱 / 鎏金金属 / 珍珠 / 玉，各自质感一句话。
4. **一致性锁定句**：见第三节。
5. **锁定项**：不混美术体系、不裁切、无场景杂物；按引擎写法落地。

## 九、反同质化（重要）

模板借的是**版式与锁定机制**，不借长相。同一套外形描述套到每个角色上，会让全项目长成一张脸；系列剧、多角色同框时尤其致命。

### 授权设计时可选的差异维度

| 维度 | 可拉开的方向 |
|---|---|
| 面部骨相 | 鹅蛋 / 方下颌 / 圆短 / 长窄；颧骨高低；面部留白多少 |
| 眼部 | 杏眼 / 丹凤眼 / 圆眼 / 下垂眼；眼距；双眼皮形态；卧蚕有无 |
| 眉形 | 柳叶 / 剑眉 / 平直 / 稀疏 |
| 唇形 | 薄厚、唇峰明显度、唇色 |
| 肤色 | 冷白 / 暖白 / 小麦 / 蜜色；血色与通透度差异 |
| 发型逻辑 | 盘发 / 马尾 / 散发 / 编发；发量、发色层次 |
| 体态 | 身高感、肩宽、颈长、骨架粗细 |
| 材质偏好 | 锦缎 / 纱质 / 皮革 / 粗麻；以金属、玉或珍珠为主 |
| 配色体系 | 冷调 / 暖调 / 高饱和 / 低饱和；主色不重复 |

### 同项目内检查

- 先核对源材料：双胞胎、统一制服、刻意同貌等设定照实保留，不为凑差异数量改造角色。
- 授权设计且实际镜头需要区分时，从表中选择有效锚点；服装、位置或动作习惯已经足够时，无需改变骨相。
- 按会使用的景别检查识别度，必要时分别制作视图。
- 多角色设定表各自写身份锁定句；共用特征可保持一致。

### 与一致性的边界

一致性检查针对同一角色的已确认锚点。不同角色相似是否构成问题，取决于原作和镜头意图，不以固定差异数量验收。
