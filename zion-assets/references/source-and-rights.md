# 来源、许可与使用边界登记

本档建立制作追踪，不提供法律结论。使用外部图片、文字、字体、音乐、声音、角色形象、商标或用户上传素材时，记录已知来源、用户声明和允许用途；无法确认的部分标为未知或待确认，不自行推断“网上找到即可商用”。

## 一、何时登记

- 外部素材会进入提示词参考、训练/微调、编辑、合成或最终成片；
- 素材包含可识别人物、声音、角色形象、品牌、字体、音乐或作品片段；
- 用户要求公开发布、商业交付、跨平台复用或交给第三方继续制作；
- 同一文件存在不同许可、期限、地域或使用版本。

完全由项目自制且已有内部登记的资产，只保留来源记录与登记指针，不重复编写权利说明。

## 二、最小字段

| 字段 | 记录内容 |
|---|---|
| `source_provenance` | 来源文件、提供者、链接或项目内登记位置；未知则明确写未知 |
| `rights_status` | confirmed / user-asserted / pending / restricted / unknown |
| `permitted_uses` | 已明确允许的参考、编辑、生成、发布、商业使用或其他用途 |
| `restrictions` | 禁止传播、仅内部、不可改编、需署名、期限/地域等已知限制 |
| `identity_consent` | 涉及可识别人物或声音时，已知同意状态与来源；不适用则省略 |
| `attribution` | 需要保留的署名文字或登记位置 |
| `review_needed` | 交付前仍需谁确认什么 |

状态只描述现有证据：用户声明可使用可以记为 `user-asserted`，但不自动升级为已独立核验的 `confirmed`。

## 三、设计参考与成品使用分开

- **参考用途**：只用于分析视觉特征或指导设计，不等于允许复制身份、构图或受保护内容进入成品。
- **编辑用途**：允许修改某文件，不等于允许公开发布修改结果。
- **生成用途**：允许作为生成入口参考，不等于允许训练、长期存储或转交第三方。
- **发布用途**：按项目实际声明记录平台、商业性、期限或地域，不补写未知条件。

影人、作品名或风格俗称只用于理解用户意图时，最终资产应落到可描述的构图、色彩、材质和摄影特征；若用户要求复制可识别人物或受保护角色，保留请求与素材来源，缺少必要授权证据时标为待确认并交由项目负责人决定。

## 四、文件与变体

- 权利状态随具体文件和版本走，不只随显示名走。
- 裁切、调色、去背或格式转换后的派生文件保留父文件来源。
- 多语言、不同音乐、不同人物声音等版本分别登记，不能用一个总状态覆盖。
- 替换来源后，检查所有引用该文件的资产、分镜、提示词和交付包。

## 五、交接边界

`approved` 和 `uploaded` 表示制作准入，不自动表示权利已确认。正式交付时同时检查资产可用状态与权利状态：制作上可用但 `pending`、`restricted` 或 `unknown` 的项目，进入待确认清单；不得把制作验收通过写成法律或商业使用已经确认。

## 六、自检

- [ ] 外部素材能追溯到具体来源或明确标为未知
- [ ] 参考、编辑、生成、发布与商业使用没有混成一个“可用”
- [ ] 可识别人物与声音记录了已知同意状态
- [ ] 派生文件保留父来源，替换来源后检查下游引用
- [ ] `approved/uploaded` 与 `rights_status` 分开判断
- [ ] 待确认项写清负责人和需要补的证据，不自行作法律结论
