# 其他资产设计：结构、状态与下游用途

本档处理人物、场景和普通道具之外的资产：服装独立款、生物、载具、武器、图形文字、特效元素和声音身份。只读取当前类别；不为了完整而填满所有字段。

## 一、共同方法

每项先回答四件事：

1. **如何被认出**：跨角度、跨状态仍稳定的轮廓、结构、材质或声音锚点。
2. **能做什么**：动作能力、功能范围、触发方式与不能自行假设的能力。
3. **怎样变化**：使用、损坏、开合、变形、耗尽或阶段状态。
4. **怎样被下游使用**：哪些场次、镜头、角度、距离、声音或合成层真正需要它。

资产卡记录身份与状态；具体动作过程、使用结果和镜头调度仍由剧本与分镜决定。

## 二、生物与怪物

按需要记录：

- 尺度参照、整体轮廓、肢体数量与关节方向；
- 主要支撑点、重心、常态姿态和可行动范围；
- 表面材质、软硬组织、毛发/甲壳/鳞片等交界；
- 识别器官及其位置，遮挡后靠什么继续辨认；
- 步态、飞行、爬行、游动或变形时哪些结构保持不变；
- 幼体、成年、受伤、湿润、蜕变等需要持续继承的状态。

奇幻能力只继承源材料或已确认设计。不会因为外形像某种动物，就自行补入相同的骨骼、速度或攻击方式。

参考需求优先覆盖实际动作：静态身份角度、关节极限、与人物的尺度同框、关键动作起止态。无法在一张参考图同时说明的结构，拆为身份板与功能板。

## 三、载具与机械

- 外形轮廓、前后与左右识别点；
- 门、舱、轮、翼、履带、机械臂等可动结构及转轴；
- 驾驶位、乘员位、货物区、出入口和人物尺度；
- 正常、启动、运动、停机、损坏、缺件等状态；
- 转弯半径、离地间隙或活动范围等会影响场景空间的条件；
- 灯光、仪表、排气、声音和接触反馈的来源。

资产不自行决定速度、路线或事故结果；向分镜交接结构上允许怎样运动、运动后哪些状态需要继承。

## 四、武器与功能性道具

除普通道具字段外，记录：

- 握持区、操作件、作用端与安全/待机/使用后状态；
- 尺寸、重量感及使用者是否能合理操作；
- 装填、开合、启动、耗尽、损坏等可见阶段；
- 使用时与手、服装、场景表面的接触点；
- 源材料明确的功能与限制。

资产卡只说明结构和状态，不编造使用教学或剧情伤害。具体动作强度、物理反馈和结果由项目内容与分镜负责。

## 五、图形、文字与界面

把“长什么样”和“写什么”分开：

| 层 | 记录内容 |
|---|---|
| 视觉身份 | 版式、形状、色彩、材质、图标体系 |
| 准确内容 | 必须逐字一致的文字、数字、日期、名称 |
| 可变内容 | 因语言、版本、剧情状态而变化的字段 |
| 载体关系 | 屏幕、纸张、招牌、服装或空间中的尺寸与位置 |
| 制作路径 | 直接生成、后期合成或两者结合 |

精确文字不能只依赖参考图外观。进入后期合成的内容应保留可编辑文本、透明层或明确的替换区域；多语言版本登记独立变体，不覆盖原版。

## 六、特效元素

按“来源—发展—交互—结束”记录：

- 发生源、触发条件与初始位置；
- 范围、方向、速度、密度和持续阶段；
- 与人物、场景、光线、空气和表面的交互；
- 遮挡前后关系、投影或交互光；
- 消散、残留、损伤或场景痕迹；
- 是否需要独立前景层、背景层、遮罩、透明通道或 clean plate。

只写“魔法感”“爆炸感”不能形成稳定资产；至少要落到可辨认的形态、运动和交互证据。

## 七、声音身份

声音身份不是一段具体台词。按需要记录：

- 音域与明暗、粗糙/气声/鼻腔等可听质感；
- 语速范围、停顿习惯、重音和句尾趋势；
- 呼吸习惯：气口位置（句前／句中／句尾）、换气声轻重与是否可闻、紧张时的屏息或浅促倾向；
- 年龄感、地域或语言特征，仅继承已确认信息；
- 情绪变化时仍保持的声音锚点；
- 非语言声、机械声或生物声的发生方式与距离变化；
- 参考文件、版本、允许用途及实际入口引用。

具体台词表演由 `zion-storyboard` 的声音层处理。没有真实音频文件时只能交声音设计描述，不能标记为已批准声音资产。

## 八、自检

- [ ] 资产身份锚点与动作/功能没有混写
- [ ] 可动结构、作用范围与持续状态足以支持下游使用
- [ ] 生物和载具有人物或环境尺度参照
- [ ] 精确文字有独立内容字段和可编辑路径
- [ ] 特效写清来源、发展、交互、结束及所需层
- [ ] 声音身份与具体台词、当前情绪分开登记
- [ ] 所需参考覆盖实际用途，不为凑模板制造无用视图
